# PuriActives® 海藻糖硫酸酯钠 10% 技术总结（2026-09-27）

> 来源：浦瑞医药公众号

## 1. 基础信息

| 项目 | 内容 |
|---|---|
| 商品名 | PuriActives® Sodium Trehalose Sulfate 10% |
| INCI | SODIUM TREHALOSE SULFATE（海藻糖硫酸酯钠） |
| 供应商 | PuriPharm Co. Ltd. 浦瑞生物医药 |
| 类别 | 低分子硫酸化双糖活性物 |
| 功能定位 | 保湿活性 / 屏障护理 / skin conditioning |
| 分子特征 | 海藻糖骨架 + 3/4 位硫酸化 + 钠盐，MW≈694 Da |
| 原料形态 | 10% 活性水溶液 |
| 中国目录 | 《已使用化妆品原料目录》No.02746 |

## 2. 与普通海藻糖的差异

- 普通海藻糖：MW 342，非还原双糖，仅 humectant 吸水
- 硫酸化后：阴离子、低分子（<1000 Da），可作用于角质形成细胞
- 文献结论：未硫酸化海藻糖在 3D 模型中对 TEWL 无显著改善；硫酸化双糖（MW<1300）才有效

## 3. 作用机制（去营销化）

核心不是"补水"，是**内源屏障系统支持**：

- **角质包膜**：IVL、TGM1 ↑ → 角质包膜形成
- **脂质运输**：ABCA12 ↑ → 层板颗粒装载 → 神经酰胺屏障组织
- **NMF 通路**：FLG / CASP14 / CAPN1 / BLMH ↑ → 游离氨基酸 ↑ → NMF

证据链：3D 表皮 qPCR + 免疫荧光 + 游离氨基酸检测 + 人体双盲

## 4. 关键数据

### 4.1 3D 表皮模型

- 0.05–0.20% 处理：TEWL ↓、ABCA12 / FLG / TGM1 mRNA ↑
- 游离氨基酸比例显著上升
- 免疫荧光：TGM1、ABCA12、Ceramide、FLG 信号增强

### 4.2 人体短期（n=5）

0.05–0.2% 溶液：15 min 起角质层含水量显著提升，30 min 维持

### 4.3 4 周人体双盲（活性 n=13 / 安慰 n=11）

| 指标 | 变化 |
|---|---|
| TEWL | 17.3 → 16.1 g/m²·h（Δ −1.2 vs 安慰 +3.2） |
| 含水量 | 81.3 → 105.5 μS（Δ +24.2 vs 安慰 +4.2） |

伴随观察：血氧指数↑、黑素指数↓（**不作强美白宣称**）

## 5. 配方应用参数

| 参数 | 建议 |
|---|---|
| 原料添加量 | 0.50%（10% 活性液） |
| 实际活性浓度 | 0.05%（对应文献人体剂量） |
| 适用 pH | 5.5–7.0（文献口径 4–8） |
| 溶解性 | 水溶性，水相或降温后加 |
| 温度 | 避免长期高温 |
| 驻留类上限 | 活性 0.05%（《已上市产品使用信息》） |
| 淋洗类上限 | 3% |

## 6. 适用体系

- 护肤：化妆水、精华、乳液面霜、面膜、眼霜、敏感肌
- 头皮：洗发水、护发素、头皮精华、scalp tonic
- 概念：屏障修护、换季干燥、视黄醇/酸类伴侣、医美后

## 7. 复配建议（机制互补）

- +HA：即时水合 + 内源 NMF
- +神经酰胺：内源运输 + 外源补充
- +泛醇/依克多因/烟酰胺：屏障协同

实际功效需配方验证。

## 8. 法规与安全

- 中国目录 02746，非禁用
- 驻留全身 0.05% / 淋洗 3%（参考历史使用量）
- CIR / SCCS 暂无正式结论
- 头皮"生发"不属于该原料人体证据（仅硫酸化糖类平台专利）
- 血氧/黑素指数为伴随观察，不宜强宣称美白

## 9. 技术评估

- **差异化**：硫酸化双糖 + ABCA12 通路，有文献支撑
- **证据等级**：3D 模型 + 4 周小样本人体（n≈24）
- **定位**：屏障保湿活性，非传统 humectant 替代
- **配方价值**：低添加、水溶、易入体系
- **注意点**：功效依赖终产品基质与测试验证；宣称别超证据
