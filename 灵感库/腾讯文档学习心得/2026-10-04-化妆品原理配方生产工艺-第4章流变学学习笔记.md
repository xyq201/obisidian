## 二、知识点拆解

### 2.1 流动方式（牛顿 / 非牛顿）

化妆品几乎不全是牛顿流体。

- **牛顿流体**：剪切速率↑黏度不变（纯水、低浓度甘油水）
- **非牛顿**：假塑性（剪切变稀，膏霜/乳液/凝胶最常见）、胀塑性（剪切变稠，含高量粉体/硅弹体偶发）、宾汉塑性（有屈服应力，黄油/高蜡基膏体）、触变性（结构恢复有时间差）

现场判断方法：取样品涂玻璃板——一推就摊开、无回缩→低屈服值、假塑性强；静止后边缘不回流、有"墩实感"→有三维结构；搅拌后明显变稀、放5 min又稠回去→触变；搅拌后一直稀→乳化剂不足或增稠剂被盐/醇破坏。

| 流动类型 | 典型化妆品 | 配方含义 |
|---|---|---|
| 牛顿 | 纯露、部分水剂 | 不需结构稳定 |
| 假塑性 | O/W乳液、凝胶、精华乳 | 需剪切变稀利于铺展 |
| 宾汉塑性 | 唇膏、高蜡W/O膏 | 需屈服应力防垂流 |
| 触变 | 面膜膏、底妆、修护霜 | 静置稳、涂抹化开 |

### 2.2 触变性（本章最实用一节）

触变 ≠ 假塑。假塑是"剪切即稀"，触变是"稀了之后恢复慢"。

配方岗操作定义：
- **触变环面积大**：结构破坏后重建慢→抗沉降好，但泵头二次出料可能不均
- **触变环面积过小**：像溶液，易分层
- **触变过强**：涂开有"拖滞"、复配增稠剂打架

常见调控路线：
- 加黄原胶/Clay：触变↑，但可能有颗粒感
- 卡波姆：假塑强、触变弱，依赖中和度
- 纤维素（HEC/MC）：中剪黏度高，低剪支撑一般
- 鲸蜡醇+单甘酯：靠结晶网络给乳液"骨架"，不是纯增稠
- 气相SiO₂（W/O）：固相网络，触变硬

### 2.3 流变性质测定

| 项目 | 要点 | 配方误用点 |
|---|---|---|
| 毛细管黏度计 | 适合牛顿/低黏水剂 | 测乳液会堵、不反映结构 |
| Brookfield RV | 化妆品主线工具 | 必须记转子号、转速、温度、时间 |
| 应力控制流变仪 | 屈服应力、储能模量G′ | 研发端做触变环才准 |
| 离心辅助 | 看分层不是测流变 | 不能替代黏度 |

Brookfield读数规则（现场写法）：例——25℃、4号转子、20 rpm、读取第60 s数值。**不写条件=数据不可比。**

### 2.4 流变与感官评价对应

书里这节最容易被跳过、但最影响复购。

| 流变特征 | 感官表现 |
|---|---|
| 低剪黏度低 | 稀、水感、易泵出 |
| 屈服应力适中 | 膏体不塌、不挂壁 |
| 高剪黏度低 | 涂开顺、不搓泥 |
| 触变恢复快 | 涂完不泛油、膜感紧 |
| G′ >> G″ | 啫喱感、成膜感 |
| G′≈G″ | 乳感、半流动 |

配方判断动作：
- "假滑"→常是高剪黏没降下来（聚合增稠剂过量）
- "搓泥"→屈服太高或黄原胶+卡波互斥
- "下午泛油"→不是黏度不够，是油相连续或乳化膜弱，流变救不了
- 泵头喷柱断料→低剪黏不够或触变过强

### 2.5 计算路线（乳化体流变估算）

不是严格理论计算，是配方岗用的"经验校核"：

- 油相体积分数 Φ = 油相质量 /（油相质量 + 水相体积近似）；Φ>0.6 时需蜡/增稠给网络
- 乳化剂/油相比 = 乳化剂质量 /（乳化剂+油相）≈ 10–20%（膏霜经验）
- 假塑体系黏度匹配：低剪（0.5–1 rpm）防沉；中剪（20–50 rpm）看铺展；高剪（500+ s⁻¹）看搓泥
- 触变恢复时间：搅拌后0/5/30 min测同条件黏度，恢复率=η₃₀/η₀；修护霜宜>70%，清爽乳可<50%

## 三、联网延伸（4项）

1. **高脂乳液界面层对失稳的调控综述**｜Advances in Colloid and Interface Science，2026，IF≈23.7｜结论：絮凝/聚并/乳析本质是界面膜黏弹失效，不是单纯"太稀"｜配方岗结论：流变增稠前先看界面膜，膜弱时加黄原胶只是拖慢分层。
2. **DAG与酪蛋白在部分结晶充气乳液中的界面机制**｜Food Hydrocolloids，2025｜结果：适量DAG增界面膜厚，过量竞争吸附反而降黏弹｜配方岗结论：油脂里少量高熔点是"结构助剂"，多加会反噬肤感。
3. **果胶酯化程度调控豌豆蛋白复合物构建机制**｜湖北工业大学，2026｜数据：高酯果胶TSI 0.4 vs 低酯3.6｜配方岗结论：植物蛋白做天然乳化剂，必须配高酯多糖才有空间位阻。
4. **羊奶基复配乳液体系中磷酸盐作用影响及其稳定机制**｜食品与发酵工业，2025｜DOI：10.13995/j.cnki.11-1802/ts｜结果：0.06 g/100g三聚磷酸钠离心稳定系数72.77%｜配方岗结论：离子强度是流变隐形变量；化妆品里EDTA、柠檬酸钠同理影响界面电性。

## 四、时事结合

**新原料端**：
- 植物甾醇、卵磷脂、豌豆/大米蛋白走向"天然乳化+流变调节"双角色
- 液晶乳化体系不是靠高黏，而是靠层状相给剪切恢复→触变柔和、不假滑
- 聚合增稠剂转向黄原胶+结冷胶+改性淀粉协同，降涩感

**新技术端**：
- 低温乳化保留流变网络，减少蜡完全熔化后的重新结晶不均
- 高内相乳液（HIPE）靠Φ和界面粒稳定，流变仪G′判断比目测靠谱
- 次抛/泵瓶要求低剪黏度稳定，触变环不能太大

**中国消费者趋势（2025–2026）**：乳液面霜从"基础保湿"转"轻抗老+屏障修护"；油皮要空气感（低屈服、高剪低黏），干敏要包裹感（中剪高、触变恢复快）；医美术后群体拒酒精、拒强表活、拒搓泥。

配方师视角判断：本章理论落地不是"调黏"，而是——敏感肌乳用非离子乳化+甾醇+低黄原胶、触变别过重；抗老精华乳多肽/胶原怕剪切，均质时间按G′恢复曲线定；男士控油乳用低G′、硅油连续感，别用蜡堆稠；泵装乳液低剪黏度优先、触变环面积控中小。

## 六、本章自检题（7题）

1. 为什么O/W乳液黏度合格仍会分层？从流变与界面膜两端解释。
2. 假塑性和触变性区别？各举一个化妆品例子。
3. Brookfield测膏霜只写"黏度3200 mPa·s"为什么不合格？补哪些条件？
4. 某乳液搅拌后变稀，放置2 h不恢复，是触变吗？可能原因？
5. 配方加黄原胶后不分层但搓泥，流变上怎么判？怎么改？
6. 泵头乳液出料断断续续，低剪黏度180 mPa·s，触变环大，如何调？
7. 计算：油相质量12 g，乳化剂1.8 g，求乳化剂/(乳化剂+油相)比，判断是否落经验区。

第7题答案：1.8/13.8=13.0%，落10–20%，但还要看HLB与膜强，不等同稳定。
