# 护肤类新产品开发提案 ·「面部抗氧化修护笔」

**概念**：一块像润唇膏的「面部抗氧化修护笔」——早八 / 地铁 / 工位可补涂，不叠瓶、不花妆、不黏手
**切口**：城市通勤场景 × 非涂抹精华 × 可补涂（避开「日夜霜 / 次抛 / A 醇 / 补骨脂酚 / 山茶油 / 红蛮腰」老叙事）

## 1. 立项背景

### 1.1 行业圈在聊什么

- 小红书 / 视频号高频词：「别再买护肤品」、换季泛红、早 C 晚 A 做减法、双 11 不瞎囤
- 公众号侧：PDRN、可循环眼膜、Rhode 痘痘贴出圈——本质是「小物、可见效果、不交溢价」
- 行业侧：从「成分内卷」转向**场景长期管理**——熬夜、换季、通勤、医美后、生理期成为购买触发器

### 1.2 消费者洞察（25–35 岁通勤党）

| 行为特征 | 具体表现 |
|---|---|
| 时间紧张 | 早上没空叠 5 步，晚上怕闷痘不敢厚敷 |
| 问题画像 | 脸的问题不是「老」，而是**暗、黄、油光、鼻翼红、口罩区糙** |
| 信任逻辑 | 信检测报告，但更信「下午 3 点照镜子没那么灰」 |

**核心痛点**：抗氧精华早上用、下午失效；修护霜晚上用、白天不敢补；次抛便携但还要洗手挤

### 1.3 市场空白点

| 现有品类 | 存在痛点 |
|---|---|
| 抗氧精华 | 居家涂抹，难补涂、易染黄、怕见光 |
| 修护面霜 | 夜间逻辑，白天用＝油光 / 搓泥 |
| 次抛精华 | 功效强但开包即用完，不适合工位补涂 |
| 防晒棒 | 只防紫外线，不解决污染 / 蓝光 / 泛红 |

**空白机会**：白天可重复补涂的「面部抗氧化 + 泛红安抚」**固体护理品**

## 2. 相关原料数据分析

### 2.1 主活性矩阵：不堆料，走「日间续航」

| 原料 | 推荐添加 | 功效数据要点 | 供应 / 成本 | 合规 |
|---|---|---|---|---|
| 麦角硫因 | 0.2–0.5% | 清除自由基、抗蓝光氧化、敏肌耐受好 | 合成生物量产，1–2 万/kg 级 | 已有行标 / 大量备案 |
| 依克多因 | 0.5–1.5% | 抗污染、稳屏障、减少泛红 | 国产发酵成熟，性价比高 | 已规模使用 |
| 乙酰基六肽-8 | 0.005–0.02% | 降低表情纹张力，非 A 醇不刺激 | 国产生物酶催化破专利，成本下行 | 多肽类常规备案 |
| 红没药醇 + 神经酰胺 NP | 0.2% + 0.3% | TRPV1 安抚、砖墙补脂 | 供应链极稳 | 敏感肌配方标配 |
| 微囊 VC 衍生物（AA2G） | 1–2% | 提亮不染黄、避光依赖低 | 比原型 VC 稳，比乙基 VC 便宜 | 美白 / 抗氧双路径可用 |

> 💡 **与自家原料库的关系**：乙酰基六肽-8 = **LT18**；神经酰胺 NP = **L126**。本提案可直接复用现有核心原料，无需新增供应商

### 2.2 不选什么

- **不选 A 醇 / HPR**：白天补涂＝光敏争议，孕妇 / 敏肌劝退
- **不堆 PDRN**：医美叙事重，固体棒载体相容性差
- **不追 tFNA / 外泌体**：故事新但成本离谱、消费者无体感

### 2.3 成本粗算（出厂口径）

- 原料占比：8–12%
- 固体棒基质（凡士林替代型 + 植物甾醇 + 硅弹性体）：6–9%
- 包材（抗菌旋转笔 + 磁吸盖）：3.5–5 元/支
- **单支 3.5g 出厂成本：约 9–13 元**

## 3. 对标竞品分析

| 产品 | 卖点 | 定价 | 渠道表现 | 我们的差异 |

| 薇诺娜特护霜 | 青刺果 + 屏障 | 188–268 | 换季刚需 | 霜体白天油，我们哑光不花妆 |

**结论**：目前市场尚无人把「麦角硫因 + 依克多因」做成通勤固体笔，存在品类空白。

## 4. 项目落地方案

### 4.1 产品定位

- 「通勤氧化脸急救条」——下午不暗、鼻翼不红、口罩区不糙
- 品类名建议：固态日间修护笔 / 面部抗氧化棒
- 人群：22–34 岁通勤、打车地铁骑车、坐班盯屏、淡妆/素颜
- 使用场景：早出门前涂一次 → 午饭后补一次 → 下班前补一次

### 4.2 配方方向

- **基质**：植物甾醇/角鲨烷替代矿物蜡；硅弹体做哑光丝绒，不迁移到眼妆；微晶纤维素吸附油光但不吸到起皮
- **活性层**：麦角硫因 + 依克多因 + AA2G 微囊 + 六肽-8
- **舒缓层**：红没药醇、泛醇、神经酰胺 NP
- **体感指标**：不黏头发、不搓泥、不泛白、淡柑橘木质香（无酒精香精）

### 4.3 包装设计建议

- 口红大小，单手旋出
- 笔身半透磨砂，可见「橙芯＝抗氧 / 蓝芯＝修护」双色料体
- 磁吸盖，「咔」一声＝补妆仪式
- 可换芯：外壳 39 元，替换芯 29 元（踩中「可循环眼膜」环保趋势）
