# 知识库周期迭代协议（第三层 · 让知识复利）

> 本文件定义「周期迭代引擎」怎么跑、产出什么。它是姜胡说三原则里此前唯一没落地的环节——**素材相互链接 / 成长飞轮（做链接、融合新东西）/ 经验复利**——的补完。
> 配套：权威提示词 `_周迭代提示词.md`（定时任务 #迭代任务 使用）、游标 `_迭代状态.md`、连接网络 MOC `连接网络.md`、每轮产出 `周迭代洞察-YYYY-Www.md`。

## 一、为什么需要这一层

现有两层流只做"生成 / 归档 / 加工"，是**线性**的：

```
每日学习→灵感库/  ─┐
每周归档→灵感库/腾讯文档心得/ ─┤→ [你读+我加工]→ Topics/（经验复利）
```

问题：新内容与 `Topics/`、彼此之间**从没建连接**，也**没有跨笔记综合出新观点**。知识库因此是一堆孤岛，离姜胡说的"会复利"还差最后一步。本层把每周增量**连成网 + 迭代出新观点**，让知识库从"收藏夹"变成自我强化的网络。

## 二、迭代引擎四步（每个周期跑一遍）

| 步 | 动作 | 自动/提议 | 产物 |
|---|---|---|---|
| ① 摄取增量 | 读 `_迭代状态.md` 游标；首轮全量，之后按 mtime 取增量 | 自动 | 待处理笔记清单 |
| ② 连接建网 | 全库扫描实体/关键词重叠 → 双向 `[[wikilink]]` + 反向链接 + 刷新 `连接网络.md` + 检测张力/缺口 | **自动（机械低险）** | 织密的关联网络 |
| ③ 迭代新观点 | 综合被连接簇，产出 2–5 条**新观点**（非摘要）+ Topics 修订建议 | **生成提议（不直接改 Topics）** | `周迭代洞察-*.md` |
| ④ 落盘推送 | 写洞察 + 更新游标 + `sync` 推送 | 自动 | GitHub 同步 |

## 三、治理边界（扳机在你）

- **自动做**：建双向双链、刷新连接网络 MOC、写洞察提议、更新游标。这些是机械的、可回滚的。
- **只提议、不直写**：迭代出的新观点、对 `Topics/` 卡片的修订建议，一律写进 `周迭代洞察-*.md` 等你确认后并入。**绝不自动改写 `Topics/` 已确认结论**——守住姜胡说"投喂 ≠ 外包思考 / 扳机在你"的铁律。
- **不删除**任何文件；不伪造内容；连通性失败即停报。

## 四、连接网络怎么织

- **节点**：`灵感库/`（含腾讯文档心得）、`Topics/`（经验复利卡片）、`知识迭代/` 自身。
- **边**：成分（神经酰胺家族、肽类、PLLA、视黄醇…）、靶点/机制（TRP 通道、TSLP/IL-33、胶原再生、终末分化…）、产品概念（神经美容、医美术后、屏障修护…）、INCI 交叉。
- **张力检测**：把看似冲突的视角并置（如 神经美容"感官刺激激活" ↔ 屏障修护"舒缓降刺激"），标记为待综合，而非强行统一。
- **缺口检测**：笔记中反复出现但 `Topics/` 尚无卡片的概念，列为待建卡建议。

## 五、首轮与增量

- **首轮（`needs_full: true`）**：把 `灵感库/` 里 PLLA、神经美容等尚未连 `Topics/` 的长文，与 `Topics/` 全部互相建链，一次性补齐"吃灰"素材。
- **之后**：`_迭代状态.md` 记录 `last_run` 与 `processed`，只处理增量，保持轻量。

## 六、节奏

- 定时任务：**每周一 08:00**（捕获上周每日学习 + 周日 23:00 归档后的全部增量），对齐"周拱一卒"。
- 你也可随时对我说「**迭代一轮知识库**」，我按本协议的同款逻辑立即跑一遍。
