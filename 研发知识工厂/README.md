# 🧪 研发知识工厂 · 总入口

> 口号：**不是在收藏知识，而是在搭建一个「研发知识自生长工厂」。**
> 分工：**你负责判断科学取舍与配方决策；WorkBuddy 负责整理、连接、检索、生成初稿。**

## 一、工厂流水线（输入 → 理解 → 沉淀 → 生产 → 输出 → 复盘 → 再输入）

| 层 | 目录 | 作用 |
|---|---|---|
| 0 收件箱 | [[00_收件箱/README|00_收件箱]] | 一切信息统一入口，**先收集、不分类** |
| 1 理解层 | —（由 WorkBuddy 处理） | 判断类型 / 提取机制参数 / 标注可用价值 |
| 2 原料库 | [[01_原料库/README|01_原料库]] | 原料档案：机制·规格·配伍·法规·证据 |
| 3 配方库 | [[02_配方库/README|02_配方库]] | 配方档案：结构·工艺·参数·稳定性·成本 |
| 4 法规合规 | [[03_法规合规/README|03_法规合规]] | 禁用限用·备案·功效宣称·标签红线 |
| 5 功效评价 | [[04_功效评价/README|04_功效评价]] | 实验记录·数据判读·证据等级 |
| 6 竞品市场 | [[05_竞品市场/README|05_竞品市场]] | 竞品拆解·趋势·消费者洞察 |

| 8 复盘迭代 | [[07_复盘迭代/README|07_复盘迭代]] | 周复盘·月度盘点·知识升级 |

## 三、与现有 vault 的关系

- **原料库** ↔ [[Topics/原料学习知识]]、[[Topics/原料资料]]（已有原料档案可双链引用）
- **法规合规** ↔ `_IMA同步/知识库/法规备案/`（已归档的 NMPA 6 号公告、合规排查清单）
- **功效/机理** ↔ [[Topics/皮肤科学]]（屏障、光老化、美白、痤疮等机理笔记）
- **收件箱** ↔ [[灵感库]]（原始素材共用，读完在收件箱登记，由 WorkBuddy 加工成正式档案）

> 原则：**原始素材进灵感库/收件箱，加工后的成品进本工厂各库，用双链连接，不重复抄写。**

## 四、立刻上手的 3 步

1. 把一份原料 TDS 或论文丢进 [[00_收件箱/README|收件箱]]，对 WorkBuddy 说「按原料档案模板加工这篇」。
2. 打开 [[01_原料库/_模板-原料档案]]，复制一份，填入机制/规格/配伍/法规，双链到相关配方。
3. 每周五花 10 分钟填 [[07_复盘迭代/_模板-周复盘]]，让数据回流、知识自生长。
