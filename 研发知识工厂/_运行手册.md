# _运行手册 · 让知识库自生长

## 一、黄金分工（照抄博主的核心理念）

> **你负责**：判断科学价值、做配方取舍、拍板合规结论。
> **WorkBuddy 负责**：清洗、结构化成 Markdown、提取机制与参数、建立双链、检索比对、生成初稿、定时提醒。

## 二、运行节奏（原图第 7 层：让知识库自己长大）

### 每日（约 15 分钟）
- **收集**：把看到的法规公告 / 论文 / 原料 TDS / 竞品 / 实验现象，随手丢进 [[00_收件箱/README|收件箱]]（语音、链接、截图都行，**先收集不分类**）。
- **整理**：对 WorkBuddy 说「清理今天收件箱，按类型加工成档案」。它会清洗、去重、结构化、标注价值。
- **产出**：至少让 1 条知识形成可用产出（一条配方思路/一个机制结论/一个合规提醒）。

### 每周（约 30 分钟）
- **复盘**：填 [[07_复盘迭代/_模板-周复盘]]——本周输入数、新增档案、关键发现、待验证假设。
- **连接**：检查新笔记是否有双链，无链接的孤立节点补上（打开 [[_知识图谱]] 看）。
- **回流**：把实验结果 / 备案反馈 / 客诉结论写回对应原料或配方档案，更新"证据等级"。

### 每月（约 1 小时）
- **盘点**：填 [[07_复盘迭代/_模板-月度盘点]]——知识库健康度、法规更新、项目进展。
- **升级**：哪些结论被新证据推翻或强化？更新档案并标注日期。
- **优化**：盘点新的高质量信息源，补充 [[_知识与工具清单]]。

## 三、WorkBuddy 指令模板（直接复制用）

| 场景 | 指令 |
|---|---|
| 原料 TDS 加工 | 「按原料档案模板加工这篇 TDS：提取 INCI/CAS、机制、规格、添加量、配伍禁忌、法规状态，双链到相关配方」 |
| 论文解析 | 「用 Crossref/PubMed 取这篇 DOI 的官方摘要，提炼核心机制与证据等级，写入原料/机理笔记」 |
| 法规跟踪 | 「检索本月 NMPA 化妆品公告，比对 03_法规合规 现有清单，标出变更项」 |
| 竞品拆解 | 「按竞品拆解模板分析这个产品的全成分表，推断配方架构与主打活性」 |
| 配方草案 | 「基于 01_原料库 中屏障修护相关原料，出一版温和洁面配方草案，标注添加量与工艺」 |
| 周复盘 | 「读取本周收件箱与各库新增，生成周复盘草稿，列出关键发现与待验证假设」 |
| 知识体检 | 「扫描全库，列出没有双链的孤立笔记和建议的关联」 |

## 四、质量红线（防编造）

- 所有功效数据必须来自原始资料（TDS/论文/检测报告），标注来源与日期，**不许推测数值**。
- 法规条款以 NMPA 官方发布件为准，本库归档为二手速记，标注"待核原文"。
- 供应商自述功效（人体试验/稳定性）默认"待索取第三方报告"，不作为定论。
- 每条档案保留"证据等级"字段：文献 / 供应商自述 / 内部实验 / 第三方报告。
