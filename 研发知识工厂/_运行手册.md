# _运行手册 · 让知识库自生长

## 一、黄金分工（照抄博主的核心理念）

> **你负责**：判断科学价值、做配方取舍、拍板合规结论。
> **WorkBuddy 负责**：清洗、结构化成 Markdown、提取机制与参数、建立双链、检索比对、生成初稿、定时提醒。

## 二、运行节奏（原图第 7 层：让知识库自己长大）

### 每日（约 15 分钟）
- **收集**：把看到的法规公告 / 论文 / 原料 TDS / 竞品 / 实验现象，**直接发给 WorkBuddy**（链接 / PDF / 图片 / 截图 / 语音 / 复制正文均可）。WorkBuddy 代你写入 [[00_收件箱/README|收件箱]] 并登记，**先收集不分类**。
- **整理**：对 WorkBuddy 说「清理今天收件箱，按类型加工成档案」。它会清洗、去重、结构化、标注价值。
- **产出**：至少让 1 条知识形成可用产出（一条配方思路/一个机制结论/一个合规提醒）。

### 每周（约 30 分钟）
- **① 前置·腾讯文档同步**：先读取腾讯文档本周更新的文档，按「最近编辑时间」筛增量、去重后落入 [[00_收件箱/README|收件箱]] 的「今日待处理」（详见下方「三·再补」）。通道不可用时标注「待同步」、不中断后续步骤。
- **② 前置·IMA 增量同步**：检索 IMA「化妆品知识库」本周更新内容（`UPDATE_TS_DESC_SORT_TYPE` / `update_time_filter`），与已入库档案比对去重后有选择地加工入对应库，保留双链回流；**只增量、不全量搬运**（详见下方「三·补」）。
- **③ 清理收件箱**：把上述同步进来的条目 + 本周直接投喂的资料，按类型加工成档案。
- **④ 复盘**：填 [[07_复盘迭代/_模板-周复盘]]——本周输入数、新增档案、关键发现、待验证假设。
- **⑤ 连接**：检查新笔记是否有双链，无链接的孤立节点补上（打开 [[_知识图谱]] 看）。
- **⑥ 回流**：把实验结果 / 备案反馈 / 客诉结论写回对应原料或配方档案，更新"证据等级"。

### 每月（约 1 小时）
- **盘点**：填 [[07_复盘迭代/_模板-月度盘点]]——知识库健康度、法规更新、项目进展。
- **升级**：哪些结论被新证据推翻或强化？更新档案并标注日期。
- **优化**：盘点新的高质量信息源，补充 [[_知识与工具清单]]。

## 三·补、IMA 增量同步规则（每周复盘附带执行）

- **知识库**：IMA「化妆品知识库」（`ima_kb_BoQkXLT2`，当前约 385 条，含保湿屏障/原料商目录/原料代码库/抗衰紧致等文件夹）。
- **增量识别**：用 `get_knowledge_list` 的 `UPDATE_TS_DESC_SORT_TYPE` 排序，或 `search_knowledge_chunk_pro` 的 `update_time_filter` 过滤本周（周一~周日）更新；与 `研发知识工厂/` 现有档案比对，**只处理新增/实质更新的条目**，不全量搬运。
- **加工方式**：按资料类型走对应模板（原料 TDS→原料档案、法规→法规速记、竞品→竞品拆解、实验→功效记录），照录原文数值与来源日期，**不许推测**；建立双链并更新库 README 索引。
- **同步方向**：IMA → 研发知识工厂为主（增量迭代）；需要反向沉淀时，用 `add_knowledge` 把加工后的成品写回 IMA，保持双向一致。
- **去重锚点**：以标题 + 来源 + 关键数值三要素比对，避免同一资料重复入库。

## 三·再补、腾讯文档增量同步规则（每周整理前置，先于 IMA）

- **执行顺序**：每周整理**第一步**——腾讯文档同步 → IMA 同步 → 落入 [[00_收件箱/README|收件箱]]「今日待处理」→ 再清理加工 → 最后复盘。**先同步、后整理**，不要跳过前置。
- **增量识别**：读取腾讯文档「最近编辑」列表，筛出本周（周一~周日）有更新的文档；与 `研发知识工厂/` 现有档案按「标题 + 来源 + 关键数值」三要素比对，**只取新增或实质更新**，不全量搬运。
- **落入方式**：每条更新按 `[日期] [同步:腾讯文档] 一句话主题 — 文档名/更新时间` 追加到收件箱「今日待处理」，再走正常清理加工流程（按类型套对应模板、照录原文数值与来源日期、建双链、更新库 README 索引）。
- **通道依赖**：腾讯文档读取依赖 `tdocs-app` 连接器读取工具（已验证可用，2026-11-28）。**关键运维经验**：连接器在 App 端授权后，其 MCP 工具只在**新会话启动握手时**加载——同会话内连接不会热刷新。若发出「腾讯文档同步」时工具未暴露，应提示用户新开会话执行，而不是反复重试。凭证（token）保存在 artifact 目录，通道打通后直接复用。
- **同步方向**：腾讯文档 → 研发知识工厂为主（增量迭代）；需要回写时走 `saveContent`。每次同步在收件箱登记来源与更新时间，便于溯源去重。
- **去重锚点**：标题 + 来源文档名 + 关键数值三要素，避免与 IMA 来源或历史档案重复入库。

## 四、质量红线（防编造）

- 所有功效数据必须来自原始资料（TDS/论文/检测报告），标注来源与日期，**不许推测数值**。
- 法规条款以 NMPA 官方发布件为准，本库归档为二手速记，标注"待核原文"。
- 供应商自述功效（人体试验/稳定性）默认"待索取第三方报告"，不作为定论。
- 每条档案保留"证据等级"字段：文献 / 供应商自述 / 内部实验 / 第三方报告。
