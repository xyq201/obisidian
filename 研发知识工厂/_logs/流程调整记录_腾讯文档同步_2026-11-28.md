# 流程调整记录 · 腾讯文档同步（2026-11-28）

## 需求
用户要求：每周整理之前，先把腾讯文档的更新同步到收件箱，再整理。

## 诊断（通道探测）
| 检查项 | 结果 |
|---|---|
| 连接器列表 `tdocs-app` | 显示 `connected` |
| `reconnect_plugin("tdocs-app")` | 返回「未连接，请在连接器设置中连接」——状态矛盾 |
| `workbuddy_request_mcp_connection(["tdocs-app"])` | 被系统拒绝：「本轮已请求过该连接器，勿重试」 |
| ToolSearch 腾讯文档读取工具（列表/最近编辑/内容） | 未暴露，仅返回 GitHub / IMA / sheetagent 工具 |
| 设备侧 `mobile_tencentDocs_*` | 仅有授权与写入（saveContent）能力，无读取列表工具 |

结论：**腾讯文档「读取」通道当前不可用**；「写入」（保存内容到腾讯文档）通道可用。
