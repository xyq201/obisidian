# 00_收件箱 · 统一入口

> 原则（原图第 1-2 层）：**先收集，不纠结分类；这里不做深度整理。**

## 收集什么
- 法规公告链接、论文 DOI、原料 TDS/COA、竞品链接、实验现象速记、客户/市场问题截图。
- **腾讯文档本周更新**（每周整理前由 WorkBuddy 自动同步落此，见下方「自动同步来源」）。
- **IMA 知识库本周更新**（每周整理前由 WorkBuddy 增量同步落此）。

## 自动同步来源（每周整理前置步骤）
> 顺序：**先同步腾讯文档 + IMA 更新 → 落入本收件箱 → 再清理整理**。

| 来源 | 触发时机 | 增量识别 | 当前通道状态 |
|---|---|---|---|
| 腾讯文档 | 每周整理前 | 按文档「最近编辑时间」筛本周更新，与已入库档案按标题+来源比对去重 | ✅ 可用（需在能加载腾讯文档工具的会话执行；连接器授权后须新开会话） |
| IMA 化妆品知识库 | 每周整理前 | `UPDATE_TS_DESC_SORT_TYPE` / `update_time_filter` 筛本周更新 | ✅ 可用 |

- 同步进来的每条同样追加到下方「今日待处理」，格式：`[日期] [同步:腾讯文档/IMA] 一句话主题 — 文档名/更新时间`。
- 通道不可用时**不中断流程**：按「待推送」标注，等恢复后补同步；也可由用户把文档内容直接发来代填。

## 怎么处理
1. **直接把资料发给 WorkBuddy**（链接 / PDF / 图片 / 截图 / 语音速记 / 复制粘贴的正文均可），WorkBuddy 会代你写入本收件箱并登记到「今日待处理」。
2. 对 WorkBuddy 说「清理收件箱」→ 它按类型判断、结构化成档案、标注价值、写入对应库。
3. 处理完的条目移到对应库，收件箱保持清空。

## 资料登记格式（WorkBuddy 代填）
每条按如下格式追加到下方「今日待处理」，处理完即移除：
- `[日期] [类型:URL/PDF/图片/文字] 一句话主题 — 来源/文件名`

## 今日待处理

- `~~[2026-11-28] [待同步:腾讯文档] 本周更新拉取失败~~ → 已解决：新会话同步成功，占位清除`
