# 知识加工规范（灵感 → 知识库 的中转桥）

> 来源：姜胡说「投喂 ≠ 外包思考」「灵感 ≠ 知识库」。自动学习长文只是**灵感/素材**，必须经你阅读 + 我加工，才变成可运行的**知识**。本文件定义这座桥怎么走。

## 触发方式

你读完 `灵感库/` 里某篇后，用以下任一方式触发我加工：

- 「加工这篇」/「提炼成知识块」/「把 PLLA 那篇内化一下」
- 「把灵感库/2026-09-14-PLLA... 整理成简洁笔记」
- 也可以批量：「把本周灵感库里没加工的都提炼一遍」

## 加工原则（对齐姜胡说）

1. **你掌握扳机**：我加工的前提是你已读、有判断。我不替你决定哪些值得进知识库。
2. **结合你的档案**：自动调用 `学习需求画像.md` 与 `Topics/` 已有知识，从**工程师 × 产品经理双视角**产出，不写泛泛摘要。
3. **可运行优先**：每条知识必须能落到"配方 / 产品 / 沟通 / 行动"，否则只是收藏夹。
4. **去冗存精**：长篇海报(2000字)→ 简洁 md(通常 300–600 字)，只留你用得上的骨架与钩子。
5. **保留来源**：原稿的 references 链接要带到知识块，方便回溯与引用。

## 成品落点（下一级）

加工确认后，知识块写入 **`Topics/` 对应主题子目录**（即姜胡说的"经验复利 / Areas"）：

- 原料机制 → `Topics/原料学习知识/`
- 皮肤科学 / 屏障 / 渗透 → `Topics/皮肤科学/`
- 配方 / 产品 / 市场 → `Topics/化妆品护肤/`

并在 `知识加工/待加工清单.md` 把对应行标记为「已加工」。

## 自检

- 加工稿是否带「双视角一句话结论」？否 → 补。
- 是否带「配方落地表」或「行动清单」？否 → 退回灵感库。
- 是否双链回灵感库原文？否 → 补 `[[ ]]`。
