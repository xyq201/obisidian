# 海藻糖硫酸酯钠（SODIUM TREHALOSE SULFATE）

## 一句话

海藻糖经硫酸化后的阴离子低分子双糖（MW≈694），定位**内源屏障系统支持**而非传统保湿剂——核心通路是 **ABCA12 / FLG / TGM1**，中国目录 No.02746，非新原料。

## 与普通海藻糖的本质区别

| | 普通海藻糖 | 海藻糖硫酸酯钠 |
|---|---|---|
| MW | 342 | ≈694（硫酸化后 <1000） |
| 电性 | 非离子 | 阴离子 |
| 作用 | 仅 humectant 吸水 | 可作用于角质形成细胞 |
| 文献 | 3D 模型对 TEWL 无显著改善 | 硫酸化双糖（MW<1300）才有效 |

## 三条作用通路

1. **角质包膜**：IVL、TGM1 ↑ → 角质包膜形成
2. **脂质运输**：ABCA12 ↑ → 层板颗粒装载 → 神经酰胺屏障组织
3. **NMF 通路**：FLG / CASP14 / CAPN1 / BLMH ↑ → 游离氨基酸 ↑ → NMF

## 关键数据

- **3D 表皮模型**（0.05–0.20%）：TEWL ↓，ABCA12/FLG/TGM1 mRNA ↑，游离氨基酸比例上升，免疫荧光四指标增强
- **人体短期**（n=5）：15 min 起角质层含水量显著提升
- **4 周双盲**（活性 n=13 / 安慰 n=11）：TEWL 17.3→16.1 g/m²·h（Δ−1.2 vs 安慰 +3.2）；含水量 81.3→105.5 μS（Δ+24.2 vs 安慰 +4.2）
- 证据等级：3D 模型 + 4 周小样本人体（n≈24），有文献链（Skin Res Technol 2024 等）

## 配方参数速查

| 参数 | 建议 |
|---|---|
| 原料添加量 | **0.50%**（10% 活性液）→ 实际活性 0.05% |
| pH | 5.5–7.0 |
| 工艺 | 水溶，水相或降温后加；避免长期高温 |
| **驻留类上限** | **活性 0.05%**（《已上市产品使用信息》） |
| **淋洗类上限** | 3% |

## 复配（机制互补）

+HA（即时水合+内源 NMF）｜+神经酰胺（内源运输+外源补充）｜+泛醇/依克多因/烟酰胺（屏障协同）——与自家 KG08/LT18 肽类、L126 神经酰胺 NP 均可组合进屏障修护体系。

## 注意点

- 功效依赖终产品基质与测试验证，宣称别超证据
- 血氧/黑素指数为伴随观察，**不宜强宣称美白**
- 头皮"生发"不属于该原料人体证据
- CIR/SCCS 暂无正式结论
