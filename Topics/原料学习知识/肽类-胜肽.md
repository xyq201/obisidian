# 肽类（胜肽 / Peptides）配方档案

> 学习笔记：抗衰"信号类"活性物的核心族群——分子量小、易透皮、温和。**配方核心难点在"娇贵"**：酶解/热/金属离子/极端 pH/氧化易失活（蓝铜肽最敏感），须后段低温加入、避螯合剂与强酸、双剂分装。按机制分三类：信号肽、神经递质抑制肽、载体肽。

## 1. 基础认知
- **什么是胜肽**：多肽=蛋白质碎片，无毒、高活性、易吸收的小分子活性成分（来源[15] 贤集网 2026-06-03，https://www.xianjichina.com/news/details_286460.html）。
- **三大类（配方按机制选）**（综合[3][6][11]）：
  1. **信号肽（Signal peptides）**：刺激成纤维细胞合成细胞外基质（胶原/弹性/透明质酸）。代表：棕榈酰五肽-4（Matrixyl / KTTKS）、棕榈酰三肽-1。
  2. **神经递质抑制肽（Neurotransmitter-inhibiting）**：阻断神经-肌肉信号、放松表情肌、平动态纹。代表：乙酰基六肽-8（Argireline / 类肉毒）。
  3. **载体肽（Carrier peptides）**：输送微量元素（多为铜）参与修复。代表：三肽-1 铜（GHK-Cu / 蓝铜肽）。

## 2. 代表成分与机制（落到配方启示）
### 2.1 信号肽：棕榈酰五肽-4（Matrixyl / Palmitoyl Pentapeptide-4 / KTTKS）
- 机理：作用于成纤维细胞，促进 ECM 重建——I/III/IV 型胶原、纤维连接蛋白、多糖；棕榈酸化（与棕榈酸酰胺键连接）增强皮肤穿透；加速伤口修复基因表达（来源[1] 济南多聚元 棕榈酰五肽-4，https://www.zyzhan.com/st92478/product_2660069.html；[2] 搜狐 配方师培训 2025-02-19，https://www.sohu.com/a/859744547_100111144：肽序 Pal-Lys-Thr-Thr-Lys-Ser-OH 即 KTTKS）。
- 法规状态：在 NMPA《已使用化妆品原料目录（2021 版）》中记为"棕榈酰五肽-4"（2006 年前称棕榈酰五肽-3）（来源[4] 百度百科·棕榈酰五肽 2022-03-18，https://baike.baidu.com/item/棕榈酰五肽/18600150）。
- 功效：明确抗老，改善粗糙度、减少细纹数量/深度/面积，温和不刺激，大量基础研究及文献证实（来源[4][5] 知乎·Matrixyl 2020-09-29，https://zhuanlan.zhihu.com/p/260363483：2000 年西班牙厂商推出，商标 Matrixyl，应用最早最广的抗皱多胜肽）。
- 配方启示：信号肽类稳定度较好，可常规水相/后段加入；与视黄醇"抗老双通道"（刺激胶原 vs 类视黄酸促胶原）协同但错时浓度。

### 2.2 神经递质抑制肽：乙酰基六肽-8（Argireline / Acetyl Hexapeptide-8）
- 机理：结构类似 SNAP-25，竞争占有 SNARE 结合位点，**抑制乙酰胆碱释放** → 放松表情肌 → 平抚动态纹（前额/眼周表情纹）、静态纹、细纹（来源[6] 百度百科·乙酰基六肽-8 2023-06-07，https://baike.baidu.com/item/乙酰基六肽-8/19271214；[9] zhaoyl 乙酰基六肽-8 液体，http://www.zhaoyl.com/store/10445/goods/20006820.html；[10] 合肥国肽 2020-05-28，https://www.zyzhan.com/st81883/product_2789781.html）。
- 定位："类肉毒素"、免注射、温和安全不僵硬（来源[7] zhaoyl 2026-04-20，http://www.zhaoyl.com/store/11485/goods/20130070.html；[8] zhaoyl 南京莱昂 2026-04-23，http://www.zhaoyl.com/store/10935/goods/20037936.html：CAS 616204-22-9，模仿 SNAP-25 N 端 6 氨基酸）。
- 规格：INCI Acetyl Hexapeptide-8，常以白色粉末（有效物 98%–99%）或溶液（有效物 450–550 ppm 澄清液体）供应（来源[6][7][9]）。
- 配方启示：针对"表情纹"主打成分，与信号肽（静态纹/胶原）互补；溶液形态可直接后段加入；稳定性较好。

### 2.3 载体肽：蓝铜肽（GHK-Cu / 三肽-1 铜 / Copper Tripeptide-1）——配方最娇贵
- 身份：甘氨酰-L-组氨酰-L-赖氨酸三肽（GHK）络合二价铜离子 = GHK-Cu；INCI 名"三肽-1 铜 / COPPER TRIPEPTIDE-1"；须与"丙氨酸/组氨酸/赖氨酸多肽铜盐酸盐"等含铜物质区分（来源[11] 今日头条·蓝铜胜肽 2021-11-01，https://www.toutiao.com/article/7025534708234928677/）。
- 机理：GHK 序列广泛存在于血液/唾液/尿液，随年龄下降；铜离子亲和力促伤口愈合、激活皮肤再生、促上皮/纤维母细胞增生、增厚皮下组织、改善弹性（来源[13] 什么值得买 2024-10-16，https://post.smzdm.com/p/a7ppdwll/；[14] 化工仪器网 2025-09-11，https://www.chem17.com/offer_sale/detail/15412253.html；[12] 固拓生物 CAS 49557-75-7 分子量 340.378，http://www.cnreagent.com/product/pro_36715.html）。
- ⚠️ **低浓度可能更高效率**：研究提示蓝铜胜肽低浓度护肤效率可能高于高浓度（来源[11]）。
- 配方启示（核心痛点）：**极易失活**——铜离子遇强酸/维生素 C/果酸/螯合剂（EDTA）/金属离子会氧化变蓝、失活、变色；建议**双剂分装**（分别含三肽-1 与葡糖酸铜，使用前混合生成 GHK-Cu），保存更久（来源[11]）。

## 3. 配方核心痛点（为何"娇贵"）
- 多肽为蛋白质碎片，对**热、酶（蛋白酶降解）、金属离子、极端 pH、氧化**敏感（综合蛋白类活性通性；蓝铜肽尤甚，[11] 明确失活机制）。
- **蓝铜肽配伍禁忌（最严格）**：避强酸（AHA/果酸）、原型 VC（低 pH + 还原）、EDTA/螯合剂、多价金属离子、离子强度高的体系；须弱酸-中性、低温后段加入、双剂分装现混（来源[11]）。
- 乙酰基六肽-8、棕榈酰五肽-4 相对稳，但仍建议避高温长时间、后段加入。

## 4. 方案 / 配方技术
- **加入阶段**：所有肽类建议**后段 / 降温后加入**（尤其热敏感与蓝铜肽），避免均质高温与长时间剪切降解。
- **缓冲与 pH**：蓝铜肽体系用弱酸缓冲（如柠檬酸/磷酸盐）维持 pH ≈ 5.5–7；避免与强酸活性（VC、AHA）同罐，或分罐/分时。
- **双剂/包裹**：蓝铜肽双剂分装（三肽-1 + 葡糖酸铜）或脂质体/环糊精包裹降低失活（与神经酰胺 NDS 递送思路呼应）。
- **协同**：信号肽（胶原）+ 神经递质肽（表情纹）+ 视黄醇/玻色因（抗老矩阵）；蓝铜肽配泛醇/神经酰胺修护。

## 6. pH / 配伍矩阵
- ✅ **信号肽、神经递质肽**：配伍广，常规 pH（5–7）稳定，与多数活性物兼容；可与其他抗老成分复配。
- ⚠️ **蓝铜肽**：仅弱酸-中性稳定；**禁配** 原型 VC、AHA/BHA、EDTA/螯合剂、多价金属、强碱；与泛醇/神经酰胺/透明质酸友好。
- 通用：肽类均建议避高温均质、后段加入、充氮/避光保存以延稳定期。

## 8. 功效评价（研发可用）
- 抗皱/紧致：PRIMOS/VisioScan 皱纹参数、Cutometer 皮肤弹性、胶原 I/III 免疫组化或探针。
- 蓝铜肽修护：伤口愈合模型、TEWL、红斑/屏障恢复；人体影像分级。
- 神经递质肽：面部动态纹肌电/影像评估（表情肌收缩幅度）。
