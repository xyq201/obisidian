## 使用方法（上传到知识库）
1. 将桌面 `原料资料知识库` 文件夹整体（或至少其中的 `原料档案` 文件夹）放入你的知识库系统导入目录。
2. 知识库系统会自动对 65 份 Markdown 进行切分与向量化。
3. 之后即可用自然语言提问，例如：
   - “传明酸的建议添加量和禁忌是什么？”
   - “哪个原料最适合控制油脂分泌、抑制痤疮菌？”
   - “二裂酵母 L185 的人体功效测试数据？”
   - “有哪些原料通过了无农残/无激素检测？”
