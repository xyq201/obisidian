# 神经酰胺系列

> 类别：保湿 / 功效宣称（屏障修护） ｜ 相关编号：L126（扫描件附注） ｜ 来源资料目录：原料资料

## 概述
神经酰胺是皮肤角质层"砖墙结构"中主要的细胞间脂质成分（角质层脂质由神经酰胺、脂肪酸、胆固醇、胆固醇酯等构成），参与形成阻渗层以防水分流失并抵御外界侵袭。神经酰胺 3（Ceramide 3，即 Ceramide NP，以植物鞘氨醇为基础）是皮肤中含量最多的神经酰胺，因洗涤剂清洗、年龄增长等而流失，其缺乏会导致干燥、异位性皮炎等皮肤问题。本系列涵盖"神经酰胺 3 脂质体"（苏州纳康）与"第三代神经酰胺 EcoCeramide"（含多种链长脂肪酸的 Ceramide NP）两类技术路线。

## 核心功效
- 保湿：补充因年龄增长/外因而流失的神经酰胺，强力缔合水分子、形成网状结构维持水分与弹性。
- 屏障修护：缔结完善"砖墙结构"（神经酰胺:胆固醇:脂肪酸最佳比例是健康皮肤基础），抵御外界刺激，形成天然防御机制。
- 抗敏：增厚角质层，提高皮肤耐受力。
- 粘合：神经酰胺与细胞表面蛋白质通过酯键连接，粘合细胞形成"脂质-细胞-蛋白质"包裹物，减少脱屑、改善干燥。
- 抗衰老：提高皮肤持水能力、减少皱纹、增强弹性。
- 第三代神经酰胺（EcoCeramide）"进出效应"：植物鞘氨醇经表皮层（Epidermotheraphy）+ 角质层植物神经酰胺（Corneotheraphy），即时与长效兼备、深层保湿与脂质重建。

## 特性指标 / 建议用量
- 神经酰胺3脂质体制备：严格筛选酵母发酵高纯神经酰胺3，高纯度磷脂制备类细胞膜结构的脂质体；双分子层结构，类皮脂、纳米粒径，粒径小、分布窄、无结晶，易渗透吸收、存储稳定。
- 神经酰胺3 以植物鞘氨醇为基础、生物发酵，纯度高于 95%，为人体皮肤天然存在结构，亲和度高。
- 神经酰胺3 脂质体配方建议：降温阶段以 1:3 或 1:5 的水混溶后加入；配方 pH 5.0～7.0；水相有一定悬浮增稠。
- 推荐用量——2% 神经酰胺脂质体：受损肌肤 2-10%、普通肤质日常 1-3%、干性肌肤 2-5%；6% 神经酰胺脂质体：受损肌肤 2-5%、普通肤质 0.5-2%、干性肌肤 1-2%。

## 相关功效与安全测试
- 神经酰胺 3 降低 TEWL（经表皮水分流失）并有渗透数据支持（见文本图表，未给出具体数值——资料未提及具体实测数值）。
- 第三代神经酰胺（EcoCeramide）：10 名志愿者胶带剥离急性屏障恢复测试——EcoCeramide 在受损屏障恢复方面优于 C18 Ceramide NP；人体前臂（N=5）测试显示 EcoCeramide M 显著增加角质细胞凝聚力；Corneometer 测量显示 Eco/SB、LCS 增强皮肤水合作用优于 C18 Ceramide NP，且保湿时间更长；局部使用 EcoCeramide SB/LCS 后天然保湿因子 PCA、UCA 含量显著增加。
- 添加量 1.0% 神经酰胺乳霜可改善过敏性皮肤屏障性能并降低 SCORAD 炎症指标。

## 合规 / 认证 / 法规
- 神经酰胺3脂质体经 SGS、CTI 检测，符合化妆品安全技术规范要求；神经酰胺3含量有外检报告佐证；为专利产品，多次获行业奖项。
- EcoCeramide：环保 100% 绿色工艺，获 COSMOS 认证；产品信息注明"来源于品牌网站或 TMALL、JD，仅供参考"。

## 使用场景 / 应用建议
- 适用于屏障修护、保湿、抗敏类护肤产品；市场应用示例：珀莱雅神经酰胺面膜、欧诗漫肌源修护珍珠水、薇诺娜柔润修护霜/屏障修护精华液等。
- 全球神经酰胺市场持续增长（中国市场 2019 年底约 5210 万美元，复合年增长率 8.8%，2029 年预计 1.216 亿美元）。
