# 馨敏舒 100（SymRelief® 100）

> 类别：抗敏舒缓（红没药醇 + 姜根提取物复配）｜ 相关编号：L129 / Symrise 367692 ｜ 来源资料目录：原料资料

## 概述
SymRelief® 100 是 Symrise（德之馨）的抗刺激复配活性物，由**天然 (-)-α-红没药醇**（Dragosantol® 100）与**姜（Zingiber Officinale）根提取物**按特定比例组成。两条通路分工明确：红没药醇主攻白三烯 LTB4，姜根提取物主攻前列腺素 PGE2 与白介素 IL-1α，二者在花生四烯酸级联反应的不同节点同时下压，从而对刺激性/炎症性皮肤反应实现"双靶点"舒缓。定位为敏感肌、防晒、剃须后、婴童等需要降低刺激感知的配方。

## 核心功效
- **抑制 IL-1α**：阻断角质形成细胞在刺激下的白介素释放，从源头降低炎症放大。
- **抑制 PGE2**：抑制环氧合酶（COX）通路产生的前列腺素 E2，减轻红、热、痛感知。
- **抑制 LTB4**：抑制脂氧合酶（LOX）通路的白三烯 B4，减少趋化与炎症细胞浸润。
- **下调 TNF-α 与 NF-κB**：减轻 UV 诱导的炎症信号级联与 DNA 损伤后的继发反应。
- **抑制 PLA2**：在级联最上游减少花生四烯酸的释放，是上述三条通路共同的"总闸"。
- 作用链路可概括为：UV / 化学刺激 → ROS → PLA2 → 花生四烯酸 →（COX）PGE2 +（LOX）LTB4，同时激活 NF-κB → IL-1α / TNF-α；SymRelief® 100 在 PLA2、COX、LOX、NF-κB 多个节点均有下压。

## 特性指标 / 建议用量
- **建议用量：0.05%–0.2%**（部分页面标注 0.1%–0.2%）。
- 红没药醇单品参考纯度：>95%；天然 (-)-α-红没药醇来源于巴西 Candeia 木。
- LTB4 抑制的 IC50：30 µM/L，折合约 **0.02% (-)-α-红没药醇**。
- 单品对照信息：660338 为天然 (-)-α-红没药醇；600115 Dragosantol® 100 为合成 d,l-α-红没药醇，纯度 >95%，副产物 <0.2%。

## 相关功效与安全测试
**体外 · IL-1α（HaCaT 角质形成细胞）**
- 以 A23187（Ca²⁺ 离子载体）诱导 IL-1α 释放，红没药醇在 0.25 / 2.5 / 25 µM 呈剂量依赖抑制，高浓度下降幅超过 25%（ELISA 检测，MTT/LDH 同步确认非细胞毒性导致）。

**体外 · IL-1α 与 LTB4（SkinEthic® 3D 皮肤模型）**
- 以 PMA（佛波醇-12-十四酸酯-13-乙酸酯）诱导炎症，测试浓度梯度 0.01% / 0.1% / 1.0% / 10%，暴露时长 0–12 小时。
- 两种成分（Dragosantol® 与天然 (-)-α-红没药醇）对 PMA 诱导的 IL-1α 与 LTB4 释放均呈剂量依赖抑制。
- 起效浓度低：**0.01% 即观察到抑制趋势，0.1% 效果明确**；1%–10% 浓度区间出现作用平台/回落（提示不必超量添加）。

**体外 · PGE2（NHEK 原代角质形成细胞）**
- 姜辣素类单体对 PGE2 的抑制：[6]-姜烯酚在 0.05 / 0.5 / 5.0 µM 下抑制 >30%；[8]-姜烯酚在 0.2 / 2.0 / 20 µM 下抑制 >70%；姜辣素混合物在 20 / 100 ppm 下显著抑制（阳性对照 1000 µM）。
- 文献支持：姜辣素可抑制 TNF-α / COX-2 表达、抑制 PGE2 释放（Penna 2003、Kim 2004、Frondoza 2004、Surh 1999、Jolad 2004）。

**体内 · SDS 刺激红斑模型（人体）**
- 分组：空白对照、1000 ppm 红没药醇、1000 ppm 姜根提取物、500 ppm 红没药醇 + 500 ppm 姜根提取物（即 SymRelief 复配）。
- 以 SDS 造模后连续观察 Day 0 / 1 / 2 / 3 / 5 / 7 的红斑 a 值变化，以"SDS 组 = 100%、未处理 = 0%"归一。
- 结果显示各活性组红斑 a 值较安慰剂显著下降（*p<0.05），**复配组在多个时间点优于单用**。

**应用验证（防晒体系）**
- 在 SPF30+、PA+++ 防晒配方中添加 SymRelief®，与不含 SymRelief® 的同配方对照，可见红斑/刺激指标改善（MNCs 分组 A/B/C 图像对比）。

## 使用场景 / 应用建议
- 敏感肌护理、晒后修护、剃须/脱毛后舒缓、果酸或视黄醇等刺激性配方的"降刺激搭子"。
- 防晒与日霜体系：资料中明确给出 SPF30+/PA+++ 体系的应用验证，适合作为防晒品的抗刺激添加。
- 与神经美容/抗刺激概念契合：PGE2、LTB4、IL-1α 均属可被神经末梢感知的致痒致痛介质，抑制它们对"刺痛、灼热、瘙痒"主观感受的改善有直接支撑。
- 配方提示：0.05%–0.2% 即可，不必追高；3D 皮肤模型显示 1%–10% 未带来额外收益。
