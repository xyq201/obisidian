# 甘草酸二钾功效与安全
> 类别：功效宣称/安全检测 ｜ 来源资料目录：原料资料

## 概述
本档案汇总甘肃泛植制药有限公司送检的甘草酸二钾（Dipotassium Glycyrrhizinate，INCI 泛植商标）的 5 项第三方检测/评价报告：多次皮肤刺激、急性眼刺激、皮肤变态反应（豚鼠 BT 法）、抗过敏功效（斑马鱼 Tryptase 抑制模型）、以及抗过敏功效测试报告。结论显示甘草酸二钾在测试条件下无皮肤刺激性、无眼刺激性、无致敏性；同时具备显著的抗过敏功效——在 100 和 200 μM 浓度下对 Compound 48/80 刺激产生的 Tryptase 分泌有显著抑制作用。

## 关键数据 / 主要结论

### 1. 多次皮肤刺激性试验
- 报告编号：H201820649b
- 检验日期：2018-12-10 至 2019-01-03
- 检验依据：《化妆品安全技术规范》2015 年版 皮肤刺激性/腐蚀性试验方法
- 受试对象：新西兰兔，4 只（2 雄 2 雌），体重 3.31-3.40 kg
- 给药：约 0.5g 受试物涂抹于动物左侧皮肤（约 2.5×2.5 cm），每天 1 次，连续 14 天
- 关键结果：观察期内受试兔皮肤均未出现红斑和水肿；样品组每天每只动物积分均值为 0
- 结论：多次皮肤刺激强度为"无刺激性"

### 2. 急性眼刺激/腐蚀性试验
- 报告编号：H201820649c
- 检验日期：2018-12-10 至 2019-01-03
- 检验依据：《化妆品安全技术规范》2015 年版 急性眼刺激性/腐蚀性试验方法
- 受试对象：新西兰兔，3 只（1 雄 2 雌），体重 3.31-3.40 kg
- 给药：0.1g 受试物直接涂入右侧眼睛结膜囊，左侧作自身对照
- 观察时点：1h、24h、48h、72h
- 关键结果：3 只受试兔右眼均未出现刺激性反应
- 结论：对新西兰兔急性眼刺激强度为"无刺激性"

### 3. 皮肤变态反应试验（豚鼠 BT 法）
- 报告编号：H201820649d
- 检验日期：2018-12-10 至 2019-01-23
- 检验依据：《化妆品安全技术规范》2015 年版 皮肤变态反应试验方法
- 受试对象：白化豚鼠，购自南方医科大学实验动物中心（SCXK(粤)2016-0041，合格证 44002100018096）
- 方法：局部封闭涂皮试验法（BT 法）——诱导接触（受试物约 0.2g/6h，第 1、7、14 天重复），激发接触（0.2g/6h）
- 关键结果：两次激发接触后皮肤均未出现红斑或水肿；致敏率 = 0
- 结论：未见皮肤变态反应，过敏率为 0

### 4. 抗过敏功效——斑马鱼 Tryptase 抑制模型
- 报告编号：H201820649e
- 检验日期：2018-12-17 至 2018-12-27
- 测试原理：Compound 48/80 刺激斑马鱼分泌类胰蛋白酶 Tryptase（肥大细胞脱颗粒标志物），通过 BAPNA 底物法检测吸光值（OD405）
- 受试样品：甘草酸二钾（白色粉末，水溶，4℃ 避光保存）
- 阳性对照：色甘酸钠（50/100/200 μM）
- 关键结果：
  - 阳性对照 色甘酸钠：50 μM 抑制率 17.32±5.17%，100 μM 25.59±7.98%（与模型对照无显著差异 P>0.05），200 μM 61.15±11.53%（P<0.05）
  - 甘草酸二钾 50 μM：抑制率 25.42±7.92%（P>0.05）
  - 甘草酸二钾 100 μM：抑制率 53.67±6.97%（P<0.05）
  - 甘草酸二钾 200 μM：抑制率 94.07±3.39%（P<0.05）
- 结论：
  1. 阳性对照色甘酸钠在 200 μM 对 Compound 48/80 刺激的 Tryptase 分泌有显著抑制作用（P<0.05）
  2. 甘草酸二钾在 100 和 200 μM 测试浓度下对 Tryptase 分泌均有显著抑制作用（P<0.05），具有潜在抗过敏功效
  3. 在相同测试浓度下，甘草酸二钾对 Tryptase 分泌的抑制率均比阳性对照色甘酸钠强
