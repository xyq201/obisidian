# 维生素C乙基醚

> 类别：美白 / 功效宣称（抗氧化、淡斑） ｜ 相关编号：Gwhite® VCE ｜ 来源资料目录：原料资料

## 概述
维生素 C（抗坏血酸）具美白、祛皱、抗氧化三大功效，但作为水溶性物质渗透性弱，且连烯二醇式结构在氧、光、热、碱、氧化酶及金属离子条件下易氧化。维生素 C 乙基醚（Gwhite® VCE）即 3-邻-乙基抗坏血酸，通过乙基化得到既亲水又亲油的两性结构，克服了维生素 C 稳定性与渗透性缺陷，稳定性好（耐光、耐热、耐离子和氧化）、易于吸收且直接作用无需代谢，是面向"新生代护肤需求"的安全高效美白剂。

## 核心功效
- 美白：抑制酪氨酸酶（黑色素合成限速酶）活性；降低黑色素细胞合成及分泌黑色素；抑制 UV 诱导黑化。
- 抗氧化：显著还原性，清除 DPPH、ABTS 自由基。
- 作用机理独特（Intramelanocytic acidification）：使黑色素细胞内 pH 由 6.8 降至 5.5，胞内酸化从而抑制黑色素合成，同时发挥抗氧化作用。

## 特性指标 / 建议用量
- 与同类对比：分子量 204.18，维生素 C 含量 86.3%，pH 稳定性 4–6（vs 维生素C葡糖苷 338.27/52.0%/pH 6-7、维生素C磷酸酯镁 303.5/49.3%/pH 7-9、维生素C磷酸酯钠 358.08/46.55%/pH 8-10）；VCE 分子量最小、VC 含量最高、亲水亲油，有利于透皮吸收。
- 产品指标：pH 值（3%水溶液）3.0–4.5；含量（HPLC）≥99.5%；熔点 112–115℃；保存期限 2 年。
- 推荐用量：0.1～3.0%。
- 注意：维生素 C 乙基醚水溶液 pH＞5.5 时高温会出现变黄现象，可添加适量抗氧化剂（如焦亚硫酸钠）解决。

## 相关功效与安全测试
- 酪氨酸酶抑制（体外，蘑菇酪氨酸酶）：具有有效抑制活性（IC50 0.7128 mg/ml）。
- 黑色素生成抑制（B16F1 细胞，72h）：有效抑制黑色素细胞合成及分泌黑色素（各浓度 P<0.01）。
- UV 诱导 DHICA 黑化抑制（体外）：0.1% 用量下 VCE 黑化抑制率 80%，在所测 VC 衍生物（维生素C 70%、磷酸酯镁 20%、葡糖苷 20%）中效果最强。
- 临床美白（n=40，分 4 组，每日 3 次、21 天，UVA 模拟照射）：5% 与 1% VCE 的 UVA 诱导黑化抑制效果均为"非常好"，同等用量下优于其他 VC 衍生物。
- 临床美白（8 人，2% VCE 美白霜，早晚 2 次、30 天）：皮肤黑色素值（R 值）第 0/7/15/30 天分别为 39.4/37.0/33.6/26.6，黑色素值降低幅度达 32.5%。
- 抗氧化：DPPH IC50 0.1007（vs VC 0.01787）；ABTS IC50 0.0007185（vs VC 0.0003677）。
- 安全性（HET-CAM 鸡胚绒毛尿囊膜模型）：10% Gwhite® VCE 刺激指数低，刺激性分类为无刺激（对照：0.9% NaCl 无刺激、1% SLS 强烈刺激、30% 乙酸中等刺激）。

## 使用场景 / 应用建议
- 适应用于水剂至防晒多种体系的美白原料；市场案例包括：兰蔻臻白焕亮精华水（水剂）、科颜氏集焕白净润保湿乳液（乳液）、阿玛尼至臻焕颜面霜（面霜）、肌肤之钥光透白精华液（精华）、FANCL 集中祛斑精华膜（面膜）、安耐晒小金瓶（防晒）。
- The Ordinary 15% VC 乙基抗坏血酸即采用乙基化形式维生素 C，直接作用、分子量与维生素 C 相近、可见效果更快，稳定性优于已知的直接作用形式的维生素 C。
