# 燕麦葡聚糖

> 类别：植物多糖/活性成分 ｜ 相关编号：β-Glucan（燕麦β-葡聚糖） ｜ 来源资料目录：原料资料

## 概述
燕麦 β-葡聚糖（Oat Beta-Glucan）是存在于燕麦胚乳与糊粉层细胞壁的非淀粉多糖，由 D-葡萄糖以 β-(1-4)、β-(1-3) 糖苷键连接而成的线性多糖，糖苷键比例约7:3，具有独特直链结构，与酵母、蘑菇等葡聚糖的支链结构相比具更优透皮吸收性能。定位为天然植物来源的抗炎抗刺激、祛皱保湿的活性添加剂（提出厂商：塞纳真（韩国）株式会社，无添加版本）。

## 核心功效
- 促进角质细胞生长与再生，加快修复和伤口愈合，修复头皮敏感与损伤
- 保护皮肤细胞免受 UV 照射氧化型伤害，也用于头发 UV 防护
- 促进透明质酸和胶原蛋白生成，紧致皮肤、抚平细纹、淡化皱纹
- 激发皮肤免疫系统，卓越抗敏功效
- 对角质细胞超强保湿
- 消炎抗过敏、抵御外界机械和化学刺激

## 特性指标/建议用量
- 建议用量：0.1～5.0%
- 功效验证浓度：燕麦提取液 1%、2%、5%
- pH（25℃）：5.5-8.5
- 重金属 <20ppm，砷 <2ppm
- 闪点 250℃
- 微生物 <100 cfu/ml
- 防腐剂（苯氧乙醇）0.65%
- 存储：15~25℃，阴凉通风干燥处，开封后尽快使用

## 相关功效与安全测试
- UV 损伤保护（角膜上皮细胞 UV-B 302nm 照射，Giemsa 染色计数）：1%、2%、5% 燕麦β-葡聚糖对 UV 照射受损细胞有强保护能力。
- 抗炎（小鼠耳肿胀诱导，抗炎效果%）：燕麦β-葡聚糖对皮肤炎症有较好抑制效果；β-葡聚糖在 0.2% 浓度时与含 1.0% 氢化可的松化妆品具同样消炎作用，并明显降低果酸等活性成分引起的皮肤发炎。
- 细胞增殖测试（人纤维母细胞 MTT 法）：燕麦葡聚糖对纤维母细胞增殖能力远优于酵母葡聚糖和蘑菇葡聚糖。
- 细胞培养：应用1%燕麦提取物可测得细胞内透明质酸含量明显增加。

- 添加于护肤品、发用产品、洗护用品作活性成分，起消炎舒敏、超强保湿、抗皱抗衰、愈合伤口、抵御紫外线伤害等多重作用。
