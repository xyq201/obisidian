# YK 白细胞提取物（干细胞外泌体 / 细胞外小囊泡）

> 类别：细胞级抗衰 · 修护再生（外泌体类新原料）｜ 相关编号：YK ｜ 来源资料目录：原料资料

## 概述
YK 白细胞提取物是优科生物主推的细胞级抗衰原料，本质为**干细胞在正常生理状态下分泌的细胞外小囊泡（即干细胞外泌体）**，直径约 **50–150 nm**，来源为**牛脐带血**。资料将其定位为"纳米级细胞信号传递者"：通过囊泡携带的蛋白质、RNA、脂质与代谢物，在细胞间传递调控指令，从细胞层面实现抗衰、修护与屏障改善。2025 年前后备案数同比增长显著（资料引用数据 **2335%**），属当前高热度仿生原料。

## 生产工艺流程
资料给出的无菌生产工艺链：
```
健康脐带血
   ↓ 分离
大量白细胞及培养液 → 白细胞群
   ↓ 细胞扩增培养
细胞及上清液提取液
   ↓ 间歇式高频声波处理 + 刺激物
   ↓ 0.45 μm 膜过滤 → 0.22 μm 膜过滤
YK白细胞提取物浓缩液
   ↓ TFF（切向流过滤，可分离不同大小生物分子、澄清细胞裂解液）
YK白细胞提取物纯化液
   ↓ 柱层析纯化
YK白细胞提取物浓缩纯化原料液体
```

## 囊泡结构与内容物
- **包裹的胞内物质**：可溶性蛋白、miRNA、双链/单链 DNA、游离脂质。
- **膜相关物质**：跨膜蛋白。
- **膜脂组成**：磷脂酰胆碱（PC）、磷脂酰丝氨酸（PS）、磷脂酰乙醇胺（PE）、磷脂酰肌醇（PIs）、磷脂酸（PA）、胆固醇、神经酰胺、鞘磷脂、鞘糖脂及多种低丰度脂质。
- **四类功能分子分工**：蛋白质 = 细胞间信号传递的"分子信使"；RNA = 基因活动的"调控指令"（表观遗传修饰）；脂质 = 膜结构单元 + 细胞识别与信号转导；代谢物 = 生化反应催化剂。

## 作用机制
三条进入受体细胞的路径：
1. **表面识别**：通过表面蛋白或生物活性脂质配体与受体细胞表面受体结合，实现信号转导。
2. **内吞**：受体细胞通过内吞作用吸收，进入细胞后再释放内容物。
3. **膜融合**：与受体细胞膜直接融合，将 mRNA、miRNA、蛋白质等直接导入受体细胞。

下游生物学效应：
- **抗光老化**：UV 诱导 ROS → DNA 损伤、炎症、MMPs 产生、胶原降解（SASP）；YK 提取物通过进入靶细胞并转移内容物减少光老化。
- **抗衰**：激活细胞活力，促进肌肤细胞增殖新生，促进胶原合成，提高肌肤保水量。
- **修护再生**：激活成纤维细胞，促进 **I 型与 III 型胶原蛋白**合成；平衡 **MMPs** 活性，维持胶原生成/降解动态平衡。
- **保水**：通过激活 **TGF-β、MAPK/ERK、PI3K/AKT** 等通路刺激透明质酸生成；含 **SOD、GPX** 等抗氧化酶及降低 ROS 的 miRNA。
- **免疫/微环境调节**：含纳米级免疫调节因子、血管内皮修复因子、趋化因子，对受损组织有定向修复功能。

## 应用场景
资料给出的医美/护肤应用方向（按因子组合划分）：
1. 改善敏感肌肤（KGF + FGF + VEGF 增加真皮层厚度）
2. 消除痘痘、红血丝（KGF + VEGF）
3. 修复疤痕、痘印（PDGF + FGF + FN + EGF）
4. 淡化色斑、色素（HGF + EGF）
5. 增加皮肤弹性（DGF）
6. 修复受损肌肤（PDGF + TNF）
7. 促进毛发生长（DPC 刺激毛囊细胞增殖分化）

功效—因子对应（资料原文整理）：
- **抗皱**：Collagen、Fibronectin、TGF-β、PDGF、bFGF → 提升成纤维细胞增殖活跃度，促进胶原蛋白合成
- **生发**：激活休止期毛囊真皮乳头细胞，诱导成长阶段毛发生长
- **美白**：降低酪氨酸酶及相关酶活性，抑制黑色素生成
- **修复/舒敏**：促成纤维细胞向成肌纤维细胞转变，促进肉芽组织生长与新生血管形成
- **抗氧化**：SOD、维生素 C/E 等
- **去痘印**：VEGF、PDGF、HGF 等
