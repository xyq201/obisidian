# 神经酰胺3脂质体6% 专利与资料

> 类别：专利 / 功效宣称 ｜ 来源资料目录：原料资料

## 概述
神经酰胺3脂质体是由苏州纳康生物科技有限公司推出的脂质体包裹型神经酰胺3原料，分为2%和6%两个含量规格。其核心技术获得中国发明专利授权（CN 103690391 B），采用高压均质工艺将神经酰胺3制备成纳米级乳液。该原料强调皮肤屏障修复、保湿、降低TEWL三大方向，并被纳入第三代神经酰胺（EcoCeramide）发展框架中。

## 产品概况
- 神经酰胺3来源：植物鞘氨醇为骨架，生物发酵获得，纯度高于95%（来源 095）。
- 脂质体形式：双分子层结构，与皮脂结构相似，纳米粒径（来源 095）。
- 含量规格：2% 或 6% 神经酰胺3脂质体；外观"均一近白色稠厚液体"（来源 095）。
- 配方建议：
  - 配方pH：5.0–7.0
  - 加入方式：降温阶段以1:3或1:5水混溶后加入
  - 推荐用量：2%神经酰胺脂质体——受损肌肤2–10%、普通日常1–3%、干性2–5%；6%神经酰胺脂质体——受损2–5%、日常0.5–2%、干性1–2%（来源 095）。
- 第三方检测：产品经SGS、CTI检测，符合化妆品安全技术规范要求（来源 095）。
- 市场应用示例（来源 095）：珀莱雅神经酰胺面膜、欧诗漫肌源修护珍珠水、薇诺娜柔润修护霜、薇诺娜屏障修护精华液。
- 神经酰胺研究背景（来源 096）：Ceramide NP（Ceramide 3）占人体角质层神经酰胺比例最高（>22%），其水平与TEWL值负相关；干性皮肤、过敏性皮炎、牛皮癣中Ceramide NP水平显著降低；含神经酰胺3 1.0%+植物鞘氨醇0.5%的乳霜可显著改善特应性皮肤TEWL与SCORAD评分。
- 三代神经酰胺发展脉络（来源 096）：1990~ 动物来源；1995~至今 二代（发酵Ceramide 3/6、合成Ceramide 2，单一脂肪酸）；2018~ 三代（EcoCeramide，多链长脂肪酸Ceramide NP，绿色工艺COSMOS认证）。

### 技术方案（权利要求1）
- 组分与质量百分比：水 1–25%；甘油 10–67%；胆固醇 0.1–4%；神经酰胺 0.1–6%；氢化磷脂 0.1–3%；辛基十二醇 1–12%。
- 制备步骤：
  1. 将甘油、胆固醇、神经酰胺、氢化磷脂、辛基十二醇在 70–90°C 混合均匀；
  2. 加入1–25%水搅拌均匀，通过高压均质机处理；
  3. 高压均质压力 600–1000 bar，循环 2–5 次，得到半透明或透明的神经酰胺纳米乳液；
  4. 平均粒径 100–500 nm。

### 权利要求（来源 050）
1. 上述制备方法；
2. 神经酰胺为神经酰胺3（优选）；
3. 氢化磷脂纯度>70%（优选）；
4. 神经酰胺纳米乳液用于化妆品的制备（用途限定）。

### 与现有技术差异
- 对比文件提及：CN 101214198 A（2008）、CN 101707900 A（2010）、Erol Yilmaz等关于含植物鞘氨醇阳离子纳米乳液的研究、张乾顺"新型复合脂质体Cerasome稳定性的研究"（2008）。
- 本发明以甘油/胆固醇/神经酰胺/氢化磷脂/辛基十二醇/水特定配比，结合600–1000 bar高压均质工艺制备稳定纳米乳液，平均粒径100–500 nm，强调常温下与化妆品配方任意互配，生物相容性好（来源 050）。
