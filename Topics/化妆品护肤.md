# 化妆品护肤（MOC）

> 原料、配方、递送、稳定性、功效与合规。聚焦"可指导产品配方设计与开发"的知识点。

## 笔记清单
- [神经酰胺（油溶性 · PuriActives® / 浦瑞医药）](原料学习知识/神经酰胺-油溶性-PuriActives.md) — 屏障成分；NDS 纳米递送；规格与配方黄金比例 3:1:1
- [烟酰胺（Niacinamide / 维生素 B3）](原料学习知识/烟酰胺-Niacinamide.md) — 百搭活性；屏障(促内源神经酰胺)/控油/淡斑；2%–5%，pH 5–7，与原型 VC 错时
- [视黄醇（Retinol / A醇 / 维生素A）](原料学习知识/视黄醇-Retinol.md) — 抗衰黄金标准；类视黄酸促胶原；不稳定+刺激为配方核心难点；欧盟 SCCS 限用(待核文号)
- [维生素C（抗坏血酸 L-AA 及衍生物）](原料学习知识/维生素C-抗坏血酸.md) — 抗氧化/美白/促胶原；原型不稳定需无水+低pH+复配(15/1/0.5)；衍生物 MAP/SAP/酯化VC 稳
- [酸类（AHA / BHA · 果酸 / 水杨酸）](原料学习知识/酸类-AHA-BHA-果酸水杨酸.md) — 角质剥脱焕肤；中国《规范》α-羟基酸 ≤6% / pH ≥3.5、水杨酸 ≤2%；缓释+中和+神经酰胺修护
- [泛醇（维生素原 B5 / Panthenol）](原料学习知识/泛醇-维生素原B5.md) — 渗透保湿+舒缓修护万金油；D-泛醇分子205易透皮转泛酸→辅酶A；0.1–5%、pH6.8–7.2、配伍广；酸/VA后舒缓搭档
- [乳化体系与稳定性（O/W·W/O·凝胶·悬浮）](乳化体系与稳定性.md) — 配方骨架技术；HLB选型(O/W 8–18、W/O 3–6)、破乳两步(絮凝→聚结)、均质小粒径、卡波中和/黄原胶悬浮
- [肽类（胜肽 · 信号肽/神经递质肽/蓝铜肽）](原料学习知识/肽类-胜肽.md) — 抗衰信号活性物；KTTKS/Matrixyl促胶原、Argireline放松表情肌、GHK-Cu修护但极娇贵（禁配VC/果酸/EDTA、双剂分装）
- [玻色因（Pro-Xylane / 羟丙基四氢吡喃三醇）](原料学习知识/玻色因-羟丙基四氢吡喃三醇.md) — 欧莱雅原创C-糖苷抗衰成分；刺激GAGs、增强ECM；水溶性配伍广；陷阱=高浓度结晶/搓泥、30%溶液≠纯活性
- [递送系统专题（脂质体·纳米乳·纳米液晶·微囊）](化妆品护肤/递送系统-脂质体纳米乳液晶微囊.md) — 透皮递送技术；脂质体（磷脂:Chol≈3:1, 薄膜/注入/高压均质工艺）；纳米乳（10–100nm, 高压均质/微射流）；纳米液晶（聚甘油-10二硬脂酸酯, NDS桥接神经酰胺提升2.3×生物利用度）；多层乳剂与壳聚糖包覆
- [皮肤屏障生理学（砖墙模型·细胞间脂质）](皮肤科学/皮肤屏障-角质层砖墙模型-细胞间脂质.md) — 屏障结构科学；角质层砖墙模型(Elias/UCSF)；细胞间脂质 Cer 40–50%/Chol 20–30%/FFA 20–30%；屏障修复 3:1:1(化妆品) vs 1:1:1(生理)；与神经酰胺/递送/乳化闭环
- [功效评价方法（仪器/人体试验/法规）](皮肤科学/功效评价方法-仪器-人体试验-法规.md) — 在体仪器(TEWL/Corneometer/Cutometer/PRIMOS/Visia)；体外(Franz+人工膜)；人体试验(≥30人/28天/乳酸刺痛筛选)；中国《功效宣称评价规范》红线
- [化妆品法规·宣称合规·INCI·备案体系](化妆品法规-宣称合规-INCI-备案体系.md) — 特殊/普通化妆品分类；禁用目录+限用清单(α-羟基酸≤6%/pH≥3.5)；功效宣称第9-10条(祛斑美白/防晒/防脱发/祛痘/修护须人体试验)；INCI标签红线；2026新规(原料报送码取消/免动物试验)
- [色素沉着与美白机理·黑色素合成·美白成分配方](皮肤科学/色素沉着与美白机理-黑色素合成-美白成分配方.md) — 黑素5步合成(TYR核心酶)；5干预点(抑酶/还原/阻断转运/代谢/抗炎)；PIH机制；美白成分(377≤0.5%/熊果苷/曲酸/光甘草定/VC/烟酰胺/氨甲环酸)；氢醌禁用；祛斑美白=特殊化妆品
- [敏感皮肤机理与舒缓成分·TRPV1/神经源性敏感/屏障受损](皮肤科学/敏感皮肤机理与舒缓成分-TRPV1-神经源性敏感-屏障受损.md) — 敏感三重机制(屏障缺失+TRPV1+神经源性炎症)；舒缓三靶点(修护/抑TRPV1/抗炎褪红)；成分(红没药醇/甘草酸二钾/积雪草苷/4-叔丁基环己醇/神经酰胺)；配方红线(无皂基酒精香精强防腐/pH5-6/精简)；修护须人体试验
- [皮肤老化与光老化机理·自由基·MMP·抗氧化抗糖化成分配方](皮肤科学/皮肤老化与光老化机理-自由基-MMP-抗氧化抗糖化成分配方.md) — 光老化4通路(UVA→ROS→MMP/抑胶原/脂质氧化/DNA+炎症)；糖化AGEs；成分(CEF/白藜芦醇/麦角硫因/虾青素/肌肽/谷胱甘肽/二裂酵母)；抗光老化铁律=防晒+抗氧化+修护；视黄醇+玻色因+胜肽+玻尿酸抗衰矩阵
- [痤疮与油性皮肤机理·毛囊角化·皮脂氧化·痤疮丙酸杆菌·控油祛痘成分配方](皮肤科学/痤疮与油性皮肤机理-毛囊角化-皮脂氧化-痤疮丙酸杆菌-控油祛痘成分配方.md) — 痤疮四因素(皮脂分泌/毛囊角化/丙酸杆菌/炎症)五位一体；成分(水杨酸/果酸/壬二酸+壬二酰二甘氨酸钾/BPO/皮傲宁/季铵盐-73/烟酰胺/PCA锌/辛酰甘氨酸)；抑5α-还原酶控油；油痘敏感肌配方；法规祛痘属第10条须人体
