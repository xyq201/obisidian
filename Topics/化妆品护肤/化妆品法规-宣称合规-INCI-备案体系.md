# 化妆品法规 · 宣称合规 · INCI · 备案注册体系

> 学习笔记：把配方师必备的**法规合规底线**梳一遍——产品分类（特殊/普通）、原料合规（禁用/限用）、宣称边界、标签规范、功效评价要求、2026 新规变化。对接功效评价方法笔记的法规部分，支撑"配方设计→备案注册→合规宣称"全链路。

## 1. 化妆品分类管理（中国现行体系）
中国按**风险程度**对化妆品实行分类管理（来源[1] 腾讯网·2026年五类化妆品禁产禁售；[3] Reach24h·化妆品注册备案服务）：

| 类别 | 范围 | 管理方式 | 核心文件 |
|---|---|---|---|
| **特殊化妆品** | 染发、烫发、**祛斑美白**、防晒、**防脱发**、新功效 | **注册制**：须取得注册证后方可生产/进口 | 《化妆品监督管理条例》(2021) |
| **普通化妆品** | 特殊类目以外的品类 | **备案制**：上市前完成备案，接受备案后核查 | 同上 |
| **儿童化妆品** | 适用于<12 岁儿童 | 按普通或特殊化妆品管理，特殊要求更多 | 《儿童化妆品监督管理规定》(2022) |

> ⚠️ 2026 年新规：部分原特殊化妆品（防断发类、美乳塑身类等配方稳定、风险可控者）过渡期结束后可调整为普通化妆品备案；配方师需关注过渡截止时间点（来源[1] 腾讯网 2026-01-07）。

## 2. 原料合规：禁用原料 / 限用组分（配方红线）
- **《化妆品禁用原料目录》**（NMPA 动态更新）：不得检出任何禁用物质。植物提取物尤需注意夹带天然禁用成分（如马兜铃酸类）；配方师须对每批次原料报马拉硫磷、邻苯二胺等做筛查（来源[5] 今日头条·备案雷区 2025-02-19，https://www.toutiao.com/article/7472967882868130338/）。
- **《化妆品安全技术规范》限用组分**（表3）：按 INCI 名称英文字母顺序列，注明最大允许浓度、pH 限制、使用条件。典型案例：
  - α-羟基酸（AHA）≤**6%**（以酸计），pH≥**3.5**（淋洗类发用产品除外）；若含≥3%AHA 或标签宣称 AHA，须标注"与防晒化妆品同时使用"（来源[6][7] 原创力/道客巴巴·限用组分表）。
  - 水杨酸≤**2%**（限用列表持续更新，以 NMPA 最新原文为准）。
- **《已使用化妆品原料目录（2021 版）》**：目录外原料 = 新原料，须注册/备案后方可使用；目录内原料须按目录收载的名称（INCI + CAS）使用（来源：与视黄醇/肽类笔记中"棕榈酰五肽-4 在册"一致）。
- ⚠️ 原料合规是**最优先红线**：禁用目录+限用清单+已使用目录三表联查，缺一不可；植物提取物/发酵产物尤其要关注天然禁用成分（标"来源[5] 今日头条"）。

## 3. 功效宣称评价规范（第9-10 条 — 关键分类）
《化妆品功效宣称评价规范》（NMPA 2021-04-09 发布，05-01 施行）第9-10 条将功效宣称分为两类（来源[8] 豆丁·NMPA 功效宣称评价规范原文；[9] 11467/原创力功效宣称评价摘要）：

### 须人体功效评价试验（强制，不能用文献替代）
| 功效宣称 | 说明 |
|---|---|
| 祛斑美白 | 物理遮盖型除外 |
| 防晒 | 含 SPF/PA 等 |
| 防脱发 | 原发类 |
| 祛痘 | 含丘疹/脓疱等 |
| 滋养 | 指促进细胞活力等 |
| 修护 | 屏障功能修复 |
| 宣称无泪配方 | 必须人体试用安全 |

### 可用体外/文献/消费者测试替代（可结合文献资料）
| 功效宣称 | 允许评价方式 |
|---|---|
| **抗皱*** | 功效宣称评价试验（可结合文献） |
| **紧致*** | 同上 |
| **舒缓*** | 同上 |
| **控油*** | 同上 |
| **去角质（非物理）*** | 同上 |
| **防断发*** | 同上 |
| **去屑*** | 同上 |
| **保湿**** | 可仅用消费者使用测试/实验室试验 |
| **护发**** | 同上 |
| 宣称适用于敏感皮肤（肌肤）** | 须人体功效评价（敏感人群） |
| 宣称量化指标/统计数据 | 须功效宣称评价试验 |

> 注：*** 表示须化妆品功效宣称评价试验（可结合文献）；**** 表示可仅用消费者使用测试或实验室试验；** 表示须人体功效评价（敏感人群筛选）。
> ⚠️ 上述分类依据 2021 年规范（来源[8]），2026 年后可能有更新调整，建议核对 NMPA 最新版本（标"原文待核"）。

## 4. 2026 年新规（注册备案重要更新）
- **鼓励新品中国首发**（企鹅号 2026-07-29 引用官方公告）：承诺在中国首发，可免交境外上市销售证明（来源[2] 企鹅号 2026-07-29）。
- **减免动物试验**（企鹅号 2026-07-31）：烫发产品、非氧化染发产品、仅物理遮盖的祛斑美白产品，以及使用新原料的普通化妆品（儿童化妆品除外），若企业已取得境外 GMP 资质且安全评估充分，可**免于提交毒理学动物试验报告**（来源[4] 企鹅号 2026-07-31）。**配方启示**：含新原料的普通品可省动物试验，但须安全评估充分。
- **原料报送码制度取消**（企鹅号 2026-07-31）：注册/备案仅需填原料生产商名称，不再强制填报报送码（来源[4]）。**配方启示**：原料供应商资质审核更关键（GMP/ISO/原料规格 COA 自检）。
- **2026 年五类化妆品禁产禁售**（腾讯网 2026-01-07）：过渡期结束后部分品类调整；两种去向——①调整为普通化妆品备案（配方稳定/风险可控类，如防断发、美乳类）；②纳入药品监管（参与人体生理活动的品类）（来源[1] 腾讯网）。

## 5. 标签与宣称合规红线（高频驳回场景）
- **医疗术语禁用**："医学"、"治疗"、"消炎"、"杀菌"、"处方"等词不得用于普通化妆品宣称；"医用面膜"等属医疗误导（来源[5]）。
- **成分表规范**：须用 INCI 名称、含量**降序排列**、全成分标注（来源[5]）。
- **警示语**：字体须≥1.8mm 且置于可视面（来源[5]）。
- **功效宣称边界**：不得夸大/虚假；量化指标须有对应检测报告支撑（来源[8] NMPA 规范第9条）。
- ⚠️ **李锦聪/妆研24小时**等公众号有详细违禁词库，配方设计阶段应参照（来源：研发权威资料清单公众号列表）。

## 6. 特殊化妆品 vs 普通化妆品红线（配方师必知）
| 场景 | 规则 | 来源 |
|---|---|---|
| 普通化妆品宣称祛斑美白 | ❌ 禁止（须注册特殊化妆品） | [5][10] 企鹅号 |
| 普通化妆品宣称防脱发 | ❌ 禁止（须注册特殊化妆品） | [5][10] |
| 普通化妆品宣称染发/烫发 | ❌ 禁止（须注册特殊化妆品） | [3] Reach24h |
| 特殊化妆品注册证 | 上市前必须取得，否则违规 | [3] |

## 7. 对配方/研发的直接指导（速查）
| 配方决策点 | 结论 | 来源 |
|---|---|---|
| 立项先判品类 | 功效决定品类：祛斑美白/防脱发/防晒=特殊化妆品（注册） | [1][3][5] |
| 祛斑美白配方 | 须注册特妆证，功效评价须人体试验；2026 年物理遮盖型可免动物试验 | [4][8] |
| 抗皱/紧致/舒缓/控油 | 可用功效宣称评价试验+文献替代，不需要强制人体试验 | [8] |
| 保湿宣称 | 可仅消费者测试/实验室，无须人体试验 | [8] |
| 原料禁用筛查 | 禁用目录+限用清单+已使用目录三表联查；植物提取物查天然禁用成分 | [5][6][7] |
| AHA/BHA 添加 | ≤6% / pH ≥3.5；≥3% 或宣称 AHA 须标"与防晒同用" | [6][7] |
| 标签 INCI | 强制降序排列，INCI 名称规范；警示语 ≥1.8mm | [5] |
| 2026 新规 | 原料报送码取消→原料商资质更重要；新原料普通品可免动物试验 | [4] |
| 儿童化妆品 | 更严格要求，动物试验不可豁免 | [1] |
