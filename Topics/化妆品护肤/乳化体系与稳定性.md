# 乳化体系与稳定性（O/W、W/O、凝胶、悬浮）配方技术专题

> 学习笔记：配方设计的"骨架"技术。重点在**体系选型（O/W vs W/O）→ HLB 定量筛选 → 工艺（均质/相序）→ 失效机理（破乳）→ 增稠流变**，落到可执行的处方与稳定性 SOP。

## 1. 基础认知
- 乳剂由**水相（W）+ 油相（O）+ 乳化剂**组成；依乳化剂种类/性质/相体积比 φ 可形成 **O/W（水包油）、W/O（油包水）**，以及**复乳（W/O/W、O/W/O）**、**纳米乳**等（来源[1] 搜狗百科·乳剂 2023-07-10，https://baike.sogou.com/v8192812.htm）。
- 选型原则：先定乳剂类型，再围绕类型选油相与乳化剂（来源[2] 搜狐·乳化体配方设计 2024-08-20，https://www.sohu.com/a/801753473_100111144）。
- 配方启示：O/W 肤感清爽、易铺展、适合驻留护肤；W/O 滋润封闭、适合干皮/高滋润；体系类型是配方第一决策。

## 2. 选型与 HLB（定量筛选）
- **HLB 法（亲水亲油平衡）**：Griffin 于 1949–1954 建立 0–20 标度（0=全亲油，20=100%亲水）；Davies 1957 扩展（来源[4] 知乎·HLB系统 2020-12-03，https://zhuanlan.zhihu.com/p/327654900）。
- **类型—HLB 匹配**：O/W 型所需 HLB ≈ **8–18**；W/O 型所需 HLB ≈ **3–6**；否则难以获得稳定体系（来源[2] 搜狐 2024-08-20）。步骤：①定类型 → ②选油相并算油相所需 HLB → ③选乳化剂对使提供 HLB 落入目标区间。
- **PIT 法（相转变温度）**：对非离子表面活性剂的有效补充（来源[3] 人人文库·HLB值及乳化剂选择 2022-04-03，https://www.renrendoc.com/paper/206820611.html）。
- **最可靠仍是实验筛选**：HLB 只辅助，最终靠小试筛选乳化剂组合（来源[3]）。
- **常见乳化剂对（供应商数据）**：硬脂醇聚醚-2（HLB≈4.9，W/O 乳化剂，常配硬脂醇聚醚-21；添加 1%–5%）+ 硬脂醇聚醚-21（HLB≈15.5，二者配对成稳定 O/W，用于含极性油膏霜/乳液）（来源[5] 搜狐·化妆品常见乳化剂性质与应用 2024-10-29，https://www.sohu.com/a/818769076_100111144）。
- 配方启示：用"一对 HLB 互补的非离子乳化剂"是 O/W 膏霜的稳定基石；极性油（酯类）需更高 HLB 乳化剂。

## 3. 稳定性机理 / 失效（破乳）
- 乳状液破坏分两步（来源[6] 搜狗百科·破乳 2024-06-05，https://baike.sogou.com/v6521472.htm；[7] 原创力文档·乳状液稳定性和破乳 2023-10-22，https://max.book118.com/html/2023/1019/8057102005005143.shtm）：
  1. **絮凝（flocculation）**：分散相液滴聚集成团但各自仍存在，**可逆**；若絮团与介质密度差大则加速分层，浓度大时黏度显著增高。
  2. **聚结（coalescence）**：团块融合成大气滴，**不可逆**，液滴数随时间减少，直至完全破坏。
- 其他失效：奥氏熟化（Ostwald ripening，小液滴溶解扩散至大液滴，常见于低分子量油/界面张力差）、分层/creaming（密度差）、相分离。
- 配方启示：稳定化 = 抑制絮凝+聚结——靠**低界面张力（合适乳化剂）、足够界面膜强度、合适连续相黏度、小且窄的粒径分布**。

## 4. 工艺与技术（均质 / 相序）
- **均质目标**：获得**小粒径、窄分布**的分散相，是稳定乳液的基础；通过调控**均质机类型、温度、能量输入、时间、均质次数**实现（来源[8] 上海珩泽·快速稳定性分析仪评价均质优化 2022-07-15，http://www.hengze-haake.com/Article-3074874.html）。
- 常用工艺：水/油相分别加热溶解 → 有序混合（油入水/水入油或转相乳化）→ 均质（8000–20000 rpm 数分钟，依体系）→ 搅拌降温 → 后段加温敏/活性物 → 脱气。
- 配方启示：均质不足→粒径大→易分层/絮凝；过度均质→引入气泡/升温降解；**能量输入需量化（rpm×时间）而非"均质一下"**。

## 5. 增稠与流变
- **卡波（Carbomer / 丙烯酸或丙烯酸酯交联聚合物）**：高效增稠、高透明、强悬浮、触变；**中和成盐（NaOH/精氨酸/TEA）后形成凝胶**，是优秀凝胶基质，用于精华/膏霜/凝胶；**低耐离子/剪切**（来源[10] 搜狗百科·卡波940 2024-10-24，https://baike.sogou.com/v60466756.htm；[12] book118·卡波树脂应用 2016-10-12，https://max.book118.com/html/2016/1012/58680722.shtm：Carbomer=聚丙烯酸均聚 / 丙烯酸酯-C10-30烷基丙烯酸酯交联共聚，1953 Goodrich 引入 Carbomer 934）。
- **黄原胶（Xanthan Gum）**：阴离子微生物多糖，集**增稠/悬浮/乳化/稳定**于一体；对热、酸、碱稳定，与多种盐相容；低浓度显著增稠、改善质地（来源[9] 百度百科·黄原胶 2025-03-19，https://baike.baidu.com/item/黄原胶/8765033；[11] 21food·黄原胶稳定保湿 2025-01-02，https://zs.21food.cn/zs/newsdetail790470-158387.html）。
- 复配：卡波（透明/触变）+ 黄原胶/纤维素（悬浮/耐剪切）互补；阳离子体系避用阴离子黄原胶（电荷冲突）。
- 配方启示：流变设计 = 目标黏度 + 悬浮力（颗粒/油滴）+ 铺展性（剪切变稀）；卡波给透明凝胶，黄原胶给悬浮耐剪切。

## 6. 配方速查
| 要素 | 经验值 / 选型 | 备注 |
|---|---|---|
| O/W 乳化剂 HLB 目标 | 8–18 | 依油相所需 HLB 定 |
| W/O 乳化剂 HLB 目标 | 3–6 | 滋润封闭体系 |
| 经典 O/W 对 | 硬脂醇聚醚-2 (HLB≈4.9) + 硬脂醇聚醚-21 (HLB≈15.5) | 1%–5%，极性油友好 |
| 卡波增稠 | 0.1%–1%（中和后凝胶） | 需中和至 pH≈6–7；耐离子弱 |
| 黄原胶增稠 | 0.1%–0.5% | 耐酸/热/盐，悬浮强 |

## 7. pH / 配伍矩阵
- **卡波**：酸性原料（pH≈3），需加碱中和（NaOH/精氨酸/TEA）才成凝胶；高电解质（多价离子、高浓度盐）会降黏/絮凝——**耐离子性差**，配方算离子强度。
- **黄原胶**：阴离子，与阳离子表面活性剂/聚合物同罐可能电荷絮凝；与盐相容性好但仍受高盐降黏。
- 活性物加入时序：热敏感（视黄醇/酶/益生菌）后段/冷却加入；酸类（AHA/VC）注意与卡波中和 pH 兼容。

## 8. 稳定性评价（研发 SOP）
- 常规加速/货架筛查：**高温（40–45°C）、高湿、光照、冷热循环、离心**观察分层/析水/变色/气味；量化用**粒径（DLS/显微镜）、黏度、离心分层率、Turbiscan 透光率随时间变化**（来源[8]）。
- ⚠️ **NMPA《化妆品稳定性评价》具体试验条件、周期与判定阈值本次未直连官方原文，标注"待核实"**，定稿前以官方技术指导原则为准。
- 合规：稳定性是备案/宣称支撑（尤其"长效/不分层"类宣称）的必证项。
