## 2. 经典配方架构：壬二酸凝胶（公开拆解）
> 来源：有来医生·壬二酸祛痘凝胶（2023-10-31）[3]、医联媒体·壬二酸凝胶治疗痤疮（2022-11-17）[2]
- **主药 壬二酸**：溶解微粉刺 + 调节毛囊角化 + 抑角蛋白 + 减少油脂 + 抑菌（**厌氧菌+需氧菌+痤疮丙酸杆菌三杀**）+ 抗炎
- **辅料基质**：甘油 + 透明质酸 + 十六醇 + 单硬脂酸甘油酯 + 白色凡士林（W/O 乳膏基质）
- **临床定位**：轻度-中度炎性痤疮 + 毛囊角化
→ 配方启示：壬二酸三效（抑菌+控油+抗炎）+ 保湿剂（甘油/透明质酸）+ 乳化稳定（十六醇/单硬脂酸甘油酯）；本方为含壬二酸的 W/O 膏霜处方，**凝胶剂型需换卡波姆+氨甲基丙醇中和**。

## 3. "教科书级"配方架构（2026 油痘肌）
> 来源：企鹅号·2026 祛痘去痘印产品测评 壬二酸传明酸配方（2026-04-23）[5]
- **5% 高纯度烟酰胺**（抑油+抑转运）
- **锌-PCA / PCA 锌**（抑 5α-还原酶 + 控油）
- **补骨脂酚**（植物视黄醇，无刺激 A 醇替代）
- **南瓜籽油提取物**（微脂囊技术，渗透皮脂腺基底，抑 5α-还原酶）
- **壬二酸 + 传明酸**（壬二酸抑菌+控油+抗炎，传明酸抗炎 PIH）
→ 配方启示：现代油痘肌配方 = 控油核心（抑 5α-还原酶三剑客：PCA锌 + 壬二酸 + 烟酰胺）+ 抑菌 + 抗炎 PIH + 微脂囊渗透。

- **工艺**：
  1. A 水相（除壬二酸外）加热 75℃ 溶解→降温；
  2. 50℃ 加入卡波姆 940 中和（边搅拌边加氨甲基丙醇）形成凝胶骨架（**专利工艺**来源[10][11]）；
  3. 降至 40℃ 加 C 舒缓（甘草酸二钾/红没药醇/积雪草苷）+ 植酸钠；
  4. 降至 30℃ 后段加壬二酸（**预溶：丙二醇/PPG-15硬脂醇醚加热助溶**）+ 皮傲宁（预溶丙二醇）+ 季铵盐-73 + B 乳酸；
  5. 35℃ 加 F 防腐（皮傲宁本身抑菌可减防腐剂用量）；
  6. NaOH 调 pH 4.5–5.0；
  7. **0.22μm 终端过滤**（壬二酸微晶须高剪切分散/超声）；
  8. **充氮灌装不透明管**。
- **稳定性**：加速 40℃/75%RH 4 周 + 冻融 -10~25℃ 3 循环 + 离心 3000rpm 30 min + 防腐挑战；监测壬二酸 HPLC ≥95%（壬二酸稳定，不易分解）；黏度（卡波姆凝胶 Brookfield RV 20000-50000 cP）
- **宣称**：控油 + 祛痘 → **祛痘=特殊化妆品，须注册 + 人体功效试验**（08-03 第10条）；**宣称避雷**：禁"医学/治疗"医疗词；"控油/减少油光/细致毛孔/抑制痘痘"普通品可用（第9条）；如走"祛痘"宣称须注册
- **配套**：白天必须防晒（PIH 防护）；避免与 BPO/水杨酸/原型VC 同时叠加
- **禁忌**：BPO+酸+壬二酸同时叠加→屏障崩溃；壬二酸+EDTA禁忌（**08-07 重点**——壬二酸与EDTA络合形成不溶物，影响稳定+生物利用度）；壬二酸+BPO 强氧化剂分时/分罐

## 8. 工艺关键技术（10 条铁律）
1. **温度控制**：壬二酸/皮傲宁/季铵盐-73/烟酰胺 ≤40℃ 后段加；水相 75℃ 溶解后降温。
2. **充氮 + 避光**：壬二酸/皮傲宁/季铵盐-73 充氮避光灌装（08-07）。
3. **pH 调节**：凝胶 pH 4.5–5.0；修护乳 pH 5.0–5.5；用 NaOH/三乙醇胺/AMP。
4. **加料顺序**（07-27 + 来源[10][11]）：
   - A 水相 75℃ 溶解 → 降温
   - 加保湿剂/PCA锌/壬二酰二甘氨酸钾/烟酰胺/泛醇/植酸钠
   - 50℃ 加入卡波姆 + 边搅边加氨甲基丙醇（中和成凝胶）[10][11]
   - 40℃ 加舒缓剂（甘草酸二钾/红没药醇/积雪草苷）
   - 30℃ 后段加壬二酸/皮傲宁/季铵盐-73/乳酸
   - 35℃ 加防腐（皮傲宁本身抑菌可减防腐剂用量）
5. **螯合剂避 EDTA**（**08-07 壬二酸+EDTA 重点禁忌**——壬二酸与 EDTA 络合形成不溶物，影响稳定+生物利用度）：改 **植酸钠 0.05–0.1%** 或酸式焦磷酸二氢二钠（08-07/08-06）。
6. **预溶**：
   - **壬二酸微晶 + PPG-15 硬脂醇醚 / 丙二醇 加热助溶** + 超声/高剪切分散；
   - **皮傲宁预溶丙二醇**（皮傲宁 0.1–0.5% 易溶丙二醇）；
   - **季铵盐-73 预溶丙二醇/乙醇**。
7. **过滤**：0.22μm 终端过滤；壬二酸微晶需高剪切分散后过滤；含大分子透明质酸可省。
8. **防腐挑战**：皮傲宁+季铵盐-73 本身抑菌可减少防腐剂用量；1,2-己二醇 1% + 对羟基苯乙酮 0.5% 可挑战；**避 MIT-CMIT / 甲醛释放体**（08-07）。
9. **包材**：真空泵/不透明管/铝箔袋；壬二酸/皮傲宁 必避光。
10. **生产环境**：GMP 10万级；金属离子控制（壬二酸与铁/铜离子络合变色）。

## 9. ⚠️ 工艺避坑清单（壬二酸专属）
| 禁忌 | 原因 | 替代 |
|---|---|---|
| **壬二酸 + EDTA 二钠** | 络合形成不溶物 + 影响壬二酸生物利用度 | **植酸钠 / 酸式焦磷酸二氢二钠** |
| **壬二酸 + 强氧化剂（BPO/原型VC/过氧化氢）** | 氧化降解壬二酸 | 分时/分罐使用；避 BPO 同罐 |
| **壬二酸 + 强碱（NaOH 高浓度）** | pH > 6 壬二酸活性下降 | pH 4.5–5.5 区间 |
| **壬二酸 + 强还原剂** | 可能还原壬二酸羧基 | 烟酰胺/泛醇/神经酰胺 兼容 |
| **壬二酸 + 铁/铜离子** | 络合变色（黄/绿） | 充氮 + 螯合剂 + 不透明瓶 |
