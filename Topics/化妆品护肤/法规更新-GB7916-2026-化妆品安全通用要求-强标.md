# GB 7916—2026《化妆品 安全通用要求》

## 一句话

我国化妆品行业**首个强制性国家标准**，2026-09 批准发布，**2028-01-01 实施**，1987 年版《化妆品卫生标准》同步废止——行业从「卫生标准」升级为「安全标准」。

## 关键时间线

| 时间 | 事件 |
|---|---|
| 2026-09 | GB 7916—2026 批准发布 |
| 2026—2027 | **配方调整与备案迁移关键窗口期** |
| 2027-01-01 | 多项禁限用调整生效（染发剂、微生物指标等） |
| 2028-01-01 | 强标实施；环四聚二甲基硅氧烷、吡硫鎓锌等禁用生效 |

## 对配方端最要命的几条（2026-09 技术规范修订联动）

1. **环四聚二甲基硅氧烷 → 禁用**（2027.1.1/2028.1.1）：硅油替代已是原料端热门方向（见归档《D4D5D6监管与硅油替代》）
2. **吡硫鎓锌 → 禁用**（2028.1.1）：去屑洗发水主力防腐/去屑体系需换方案（PCA锌、吡罗克酮乙醇胺盐等）
3. **4-甲基苄亚基樟脑 → 禁用**：防晒剂名单收缩
4. **丁苯基甲基丙醛（铃兰醛）→ 禁用**：香精体系排查
5. 二苯酮-3、胡莫柳酯、奥克立林限值调整；水杨酸限值调整

## 研发/产品行动清单

- [ ] 立即排查现行配方中的禁用/限用原料，建立**逐产品迁移时间表**
- [ ] 关注 GB 7916—2026 实施细则与过渡期安排
- [ ] 备案端：未提交年度报告的普通化妆品正被批量取消备案（山东、河南已有大量案例），别让存量产品死在年报上
- [ ] 检验方法同步更新：三价铬/六价铬等 8 项新方法 2027-03-01 实施
