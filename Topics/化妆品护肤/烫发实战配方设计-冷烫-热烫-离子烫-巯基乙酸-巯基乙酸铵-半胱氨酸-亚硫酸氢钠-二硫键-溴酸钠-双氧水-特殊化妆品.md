## 1. 烫发"机理与底层逻辑"（来源[1][4][11]辽阳市监局+中国科普博览+北京药监）
> 来源[1]辽阳市监局·2025-04-21 + 来源[4]中国科普博览·2020-03-11 + 来源[11]北京药监·2020-10-10
- **烫发本质=化学改变头发结构**（来源[1]辽阳市监局）：烫发类化妆品通过化学作用改变头发结构；效果与安全性取决于成分、使用方式、后续护理；
- **还原剂（巯基乙酸盐类）=核心**（来源[1]辽阳市监局）：**还原剂核心功能=破坏头发中的二硫键（胱氨酸的 -S-S- 键），使头发角蛋白链解旋，达到软化效果**；
- **软化剂组成=还原剂+碱化剂**（来源[4]中国科普博览）：**软化剂的主要组成是还原剂和碱化剂；目前最常用还原剂是巯基乙酸，这种物质会以不同形式出现，但目的相同——与蛋白质中的二硫键发生反应，将这些连接断开；碱化剂负责调整 pH 值**（打开毛鳞片）；
- **冷烫剂=两剂构成**（来源[11]北京药监）：**冷烫剂由"两剂"构成**——1号剂（还原剂·软化）+ 2号剂（氧化剂·定型）；
- **烫发三步机理**：
  1. **还原断开二硫键**：巯基乙酸（或其铵盐）在碱性（pH 8-9.5）下打开头发角蛋白胱氨酸二硫键（-S-S- → -SH），头发软化可塑形（来源[1][4]）；
  2. **塑形**：将软化头发卷上卷杠（冷烫卷曲）或夹板拉直（离子烫/直发），固定新形状；
  3. **氧化重组二硫键**：氧化剂（双氧水/溴酸钠）中和残留还原剂并氧化重组二硫键（-SH + -SH → -S-S-），锁定新卷度/直度（来源[1][2][3]）；

## 2. 烫发"类型与 pH"（来源[6][7]网易+cosmeticmk）
> 来源[6]网易·2026-08-21 + 来源[7]m.cosmeticmk.com·2021-06-02
- **市场主流两类冷烫药水**（来源[6]网易·2026-08-21）：**硫代系碱性水剂冷烫药水**（巯基乙酸铵+氨水，pH 8-9.5，强效）+ **半胱氨酸系弱碱/弱酸膏状冷烫药水**（半胱氨酸+亚硫酸氢钠，pH 6-7，温和，适配细软/受损发质）；两类药水的核心成分/物理形态/操作流程差异显著，适配发质/烫后效果/损伤程度各不相同；
- **Hot perms（热烫/数码烫）pH 4.5 酸性**（来源[7]cosmeticmk·2021-06-02）：Hot perms use a formula with a pH between 4.5（酸性，配合热能）；Cold perms（冷烫）一般碱性 pH 8-9.5；
- **冷烫 vs 热烫**：冷烫（卷杠常温催化，卷度更弹/羊毛卷/泡面头）+ 热烫（数码烫/陶瓷烫，加热催化，更直顺/大波浪）+ 离子烫（直发，巯基乙酸+高温夹板 180-200℃）；

## 3. 还原剂"原料路线"（来源[1][2][6]辽阳市监局+lv-1+网易）
> 来源[1]辽阳市监局·2025-04-21 + 来源[2]lv-1·2026-07-27 + 来源[6]网易·2026-08-21
- **巯基乙酸盐类（最常用）**：巯基乙酸（Thioglycolic Acid, TGA）、巯基乙酸铵（Ammonium Thioglycolate, ATG）——核心还原剂，断二硫键（来源[1][4]）；
- **半胱氨酸系（温和）**：L-半胱氨酸（Cysteine）+ 亚硫酸氢钠（Sodium Bisulfite）——弱碱/弱酸，温和低刺激，适配敏感/受损发质（来源[6]网易）；
- **半胱胺（Cysteamine）**：另类还原剂，弱碱；
- **巯基乙酸限值（核心法规锚）**（来源[2]lv-1·2026-07-27）：**巯基乙酸在烫发产品中最大使用浓度为 11%（pH≤9）**——即还原剂含量须以巯基乙酸计 ≤11% 且 pH≤9；
- **氧化剂/定型剂（来源[2][3]lv-1）**：**双氧水（H₂O₂）6%** 或 **溴酸钠（Sodium Bromate）**——重组二硫键+中和残留还原剂；

## 4. 烫发"安全红线"（来源[1][2][3][9][10]辽阳市监局+lv-1+复禾+39yst）
> 来源[1]辽阳市监局·2025-04-21 + 来源[2][3]lv-1·2026-07-27/07-24 + 来源[9]复禾健康·2025-07-13 + 来源[10]39yst·2025-12-09
- **烫发类=特殊化妆品**（来源[2][3]lv-1）：**需取得注册证后上市**；申报需配方+检验报告+毒理学试验+人体安全试验+安全评估报告；**两剂产品因需分开检验和编制资料，费用通常高于单剂产品**（来源[3]）；
- **还原剂+氧化剂含量须符合《规范》限值**（来源[2]lv-1）：**配方中还原剂（如巯基乙酸及其盐类）和氧化剂（如溴酸钠、双氧水）含量须符合《安全技术规范》限值**；巯基乙酸最大 11%（pH≤9）；
- **巯基乙酸刺激性**（来源[1]辽阳市监局+来源[9]复禾+来源[10]39yst）：巯基乙酸/氨水对皮肤眼睛有刺激性；**离子烫药水含氢氧化钠/巯基乙酸破坏二硫键，可能刺激头皮致瘙痒红肿**（来源[9][10]）；**频繁烫发/不当操作致头发干枯分叉断裂**（来源[9][10]）；**儿童娇嫩毛囊/孕妇（药水化学物质可能影响胎儿）慎用**（来源[10]39yst）；
- **警示用语**（来源[1][2]辽-1+辽阳市监局）：不可用于眉毛睫毛（同染发）+ 皮试要求（过敏史慎用）+ 避免接触眼睛皮肤+ 专业操作；

## 5. 烫发"原料路线"完整
- **还原剂（1号剂）**：巯基乙酸（TGA）、巯基乙酸铵（ATG）、L-半胱氨酸、亚硫酸氢钠、半胱胺（待核《规范》表7 列名与限值，ATG 以巯基乙酸计 ≤11% pH≤9）；
- **碱化剂**：氨水（28%）、单乙醇胺（MEA）、三乙醇胺（调 pH 8-9.5 打开毛鳞片）；
- **氧化剂（2号剂）**：双氧水（H₂O₂）6%、溴酸钠（Sodium Bromate）（待核《规范》表7）；
- **基质/护理**：表面活性剂（椰油酰胺丙基甜菜碱+月桂醇聚醚硫酸酯钠）、增稠（羟乙基纤维素+鲸蜡醇）、螯合（EDTA 二钠）、保湿（甘油+泛醇）、蛋白修护（水解胶原+神经酰胺 NP 油溶）、香精（待核，敏感肌避）；
- **稳定剂**：8-羟基喹啉/锡酸钠（H₂O₂ 稳定）；

## 8. 离子烫/直发（variant）
> 来源[9]复禾健康·2025-07-13 + 来源[10]39yst·2025-12-09
- **离子烫（直发）机理**：巯基乙酸还原剂断二硫键 + **高温夹板（180-200℃）拉直** + 氧化剂定型（来源[9][10]：离子烫通过化学药剂改变头发结构实现拉直；药水含氢氧化钠/巯基乙酸破坏二硫键）；
- **碱性直发膏（日本/巴西直发）**：氢氧化钠（NaOH）+ 巯基乙酸——强碱性拉直（来源[9][10]：离子烫药水含氢氧化钠/巯基乙酸）；
- **风险提示**（来源[9][10]）：破坏毛鳞片致水分流失干枯+刺激头皮瘙痒红肿+频繁增头皮炎症+影响毛囊致脱发+儿童/孕妇慎用；
- **配方要点**：1号剂（巯基乙酸铵/氢氧化钠 调 pH 9-12 强碱 + 还原剂）+ 2号剂（双氧水/溴酸钠 中和+定型）+ 高温夹板；**强碱腐蚀性强，警示严格**；

## 10. 工艺关键技术（10 条铁律）
1. **双剂分离**：1号剂（还原软化）+ 2号剂（氧化定型）**必须分装**，使用时依次涂（来源[11]北京药监 两剂构成）；混用顺序错误失效；
2. **碱化开鳞片**：1号剂 pH 8.5-9.5（硫代系）或 6-7（半胱氨酸系），氨水/MEA 打开毛鳞片让还原剂渗入（来源[4]中国科普博览）；**pH≤9 限值**（来源[2]lv-1 巯基乙酸 11% pH≤9）；
3. **还原剂后段加**：巯基乙酸铵/半胱氨酸 **30℃ 后段加**，避免高温分解（来源[4]碱化剂调 pH；还原剂不稳定）；
4. **氧化剂酸性稳定**：2号剂 pH 2.5-4.0（磷酸/柠檬酸）+ 8-羟基喹啉/锡酸钠稳定 H₂O₂，避光（同染发 2号剂）；
5. **螯合抗氧**：EDTA 二钠（螯合金属防 H₂O₂/还原剂分解）；
6. **温度控制**：1号剂 40℃ 溶胀+30℃ 加还原剂/碱剂；2号剂 40℃ 溶胀+灌装；离子烫需高温夹板（180-200℃，来源[9][10]）；
7. **增稠流变**：羟乙基纤维素（水剂）+ 鲸蜡醇/单硬脂酸甘油酯（膏体 O/W）——避免滴流（08-27 乳化）；
8. **修护添加**：泛醇+水解胶原+神经酰胺 NP（烫发损伤修护，08-05/08-11/08-14）；
9. **防腐**：1,2-己二醇+对羟基苯乙酮（避 MIT/CMIT/尼泊金酯，08-05）；
10. **包材避光+警示**：1号剂不透光管（巯基乙酸见光氧化）+ 2号剂不透光瓶（H₂O₂ 见光分解）；标签标注"不可用于眉毛睫毛/皮试/避免接触眼睛皮肤/专业操作"（来源[1][2]）；

## 11. ⚠️ 烫发专属工艺避坑清单
| 禁忌 | 原因 | 替代 |
|---|---|---|
| **巯基乙酸 >11%（以巯基乙酸计）或 pH>9** | 超《规范》限值+强刺激（来源[2]lv-1 11% pH≤9）| ATG≤11% pH≤9 |
| **还原剂提前氧化（与空气/氧化剂接触）** | 失效（来源[1]）| 后段加+避光+分装 |
| **H₂O₂ 碱性/见光分解** | 氧化剂失活（来源[2]）| 2号剂 pH2.5-4.0+8-羟基喹啉+避光 |

| **氨水过量** | 刺激腐蚀（来源[9][10]）| MEA 替代减氨味 |
| **孕妇/儿童烫发** | 来源[10] 孕妇药水影响胎儿+儿童毛囊娇嫩 | 避免烫发 |

| **MIT/CMIT/尼泊金酯** | 08-05+08-13 防腐剂过敏 | 1,2-己二醇+对羟基苯乙酮 |
| **EDTA** | 08-07 金属催化（但烫发需 EDTA 稳 H₂O₂/还原剂，待核）| 植酸钠（待核） |
| **染眉睫** | 来源[2] 警示：不可用于染眉毛睫毛 | 专用染眉（17槽） |
