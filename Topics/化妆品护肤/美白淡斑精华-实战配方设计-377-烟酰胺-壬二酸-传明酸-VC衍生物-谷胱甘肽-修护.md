# 美白淡斑精华实战配方设计 · 377 + 烟酰胺 + 壬二酸 + 传明酸 + VC衍生物 + 谷胱甘肽 + 修护

> 「实战配方阶段」第②篇（08-08 是抗衰精华①，本篇美白②）。把 08-04 色素沉着与美白机理 + 07-23 烟酰胺 + 08-07 壬二酸 + 08-06 抗氧化 + 07-31 屏障 + 08-05 舒缓 + 08-03 法规（**祛斑美白=特殊化妆品须注册 + 人体功效试验**）全部装进 3 套真实可生产的美白淡斑精华液。
> 对接：08-04 色素笔记、07-23 烟酰胺、08-07 壬二酸、08-06 抗氧化抗糖化（谷胱甘肽/麦角硫因）、07-25 AHA/BHA（乳酸促角质代谢）、07-26 泛醇、07-31 屏障、08-02 功效评价、08-03 法规。

## 1. 美白淡斑的"配方骨架"（5 个底层决策）
| 决策点 | 选项 | 推荐（综合 08-04 + 来源[1][5][9][10][11]） |
|---|---|---|
| **剂型** | 精华液 / 凝胶 / 安瓶 / 乳液 / 霜 | **水基精华液（双剂）**：早间 VC 抗氧瓶（pH 3.5）+ 晚间 377+壬二酸 美白瓶（pH 5.5）；亦可单瓶 pH 5.0–5.5 用 VC 衍生物 |
| **美白通路** | 抑 TYR / 还原 / 阻断转运 / 促代谢 / 抗炎 PIH | **五通路全覆盖**（08-04）：①抑酶=377+壬二酸+α-熊果苷+光甘草定；②还原=VC/谷胱甘肽；③阻断转运=烟酰胺；④促代谢=乳酸/AHA（08-04 自限≤6%）；⑤抗炎 PIH=传明酸+甘草酸二钾 |
| **pH 区间** | 3.5（原型VC）/ 5.5（377+烟酰胺+壬二酸+衍生物）/ 5.0（敏感） | **早间 pH 3.5（原型VC）/ 晚间 pH 5.5（377+壬二酸+烟酰胺+传明酸）/ 敏感肌单瓶 pH 5.0（VC衍生物+低377）** |
| **活性物组合** | 单通路 / 双通路 / 多通路 | **多通路复配**：若美欣 0.4%377+烟酰胺+传明酸+乳酸（拆解[9]）；意肤美白祛斑霜 377+烟酰胺+光甘草定+传明酸+α-熊果苷（2026-08 测评[5]）；德宜芙 377+VC衍生物+传明酸（抖音[10]） |
| **包装/防晒** | 透明玻璃 / 不透明 / 真空 / 充氮 | **充氮不透明瓶**（VC/377/阿魏酸 抗氧化）；**日间必须配合防晒**（紫外是黑色素生成的源头驱动，08-04） |

## 2. 经典配方架构：若美欣 377 美白精华（公开拆解）
> 来源：什么值得买·若美欣377美白精华（2024-06-03）[9]
- **德之馨 377（苯乙基间苯二酚）0.4%**（在《规范》0.5% 限值内，08-04）
- **烟酰胺**（黑素小体转运抑制，07-23）

→ 配方启示：经典 4 通路复配（抑酶+转运抑制+抗炎+促代谢），日间防晒必须跟上。

## 7. 工艺关键技术（10 条铁律）
1. **温度控制**：377/VC/谷胱甘肽/光甘草定/壬二酸 ≤40℃ 后段加；水相 75℃ 溶解后降温。
2. **充氮 + 避光**：VC/VC乙基醚/377/阿魏酸/光甘草定 充氮灌装+不透明瓶（08-06）。
3. **pH 调节**：
   - 原型 VC 早间瓶 → pH 3.5±0.2；
   - 晚间瓶 → pH 5.5±0.3（377+烟酰胺+壬二酸+传明酸稳定）；
   - 敏感肌瓶 → pH 5.0±0.3（贴近皮脂膜 4.5–6.5；08-05）。
4. **加料顺序**（07-27 经验）：
   - A 水相 75℃ 溶解 → 降温
   - 加保湿剂/烟酰胺/传明酸/植酸钠
   - 降至 50℃ 加卡波姆中和+黄原胶水合
   - 降至 40℃ 加舒缓剂（甘草酸二钾/红没药醇/积雪草苷）
   - 降至 30℃ 后段加 377/壬二酸/α-熊果苷/光甘草定/VC 衍生物/谷胱甘肽
   - 35℃ 加防腐（对羟基苯乙酮+1,2-己二醇）
5. **螯合剂避 EDTA**：改植酸钠 0.05–0.1% 或酸式焦磷酸二氢二钠（08-06）。
6. **预溶**：
   - 377 预溶丁二醇/乙醇（脂溶差，水中难溶）；
   - 壬二酸难溶需加热助溶+表面活性剂协助（如 PPG-15 硬脂醇醚）或微晶工艺；
   - 阿魏酸预溶乙醇；光甘草定预溶丙二醇；
   - VC 预溶丁二醇/乙醇。
7. **过滤**：0.22μm 终端过滤；含大分子透明质酸可省；壬二酸微晶需高剪切分散。
8. **防腐挑战**：多元醇+对羟基苯乙酮 可挑战防腐（pH 5.5 防腐效率较 pH 7 低，注意）；含壬二酸可能影响部分防腐剂效能。
9. **包材**：充氮不透明瓶/真空瓶；377/VC/光甘草定 必避光。
10. **生产环境**：GMP 10万级净化车间；充氮装置；金属离子控制（VC/377 易被金属催化氧化）。

## 9. 功效评价（08-02 体系）
- **人体试验**（≥30人/臂，28天/56天 D0/D14/D28/D56）：
  - **Mexameter MX18**（黑色素指数 MI；提亮指标）
  - **VISIA 紫外/标准光源**（色斑量化）
  - **Chromameter**（皮肤 L*a*b*；L↑肤色亮，a↓泛红，b↓黄气）
  - **图像分析/Primos**（色斑面积/数量）
  - 受试者自评（光泽、均匀、淡化痘印）
- **体外**（08-02）：
  - TYR 活性抑制试验（蘑菇 TYR/L-DOPA 法）
  - B16 黑素瘤细胞 黑素含量测定
- **仪器双臂对照 + 随机双盲 + 防晒配套**（否则 UV 干扰大）
- **法规**：**祛斑美白=特殊化妆品，须注册 + 人体功效试验**（08-03 第10条）

## 10. 法规红线（08-03 第10条）
