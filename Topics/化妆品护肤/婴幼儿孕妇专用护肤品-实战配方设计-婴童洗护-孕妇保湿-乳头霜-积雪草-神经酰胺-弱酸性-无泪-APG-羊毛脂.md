## 2. 婴幼儿洗发沐浴"无泪配方"基本原则
> 来源：知乎·宝宝沐浴露怎么选（2021-12-16）[1] + 知乎·六款热门婴童洗发沐浴露测评（2020-07-18）[2] + 什么值得买·婴儿洗发水挑选攻略（2025-04-04）[4] + 红色小象·婴儿洁面乳（2022-11-02）[5]
- **pH 弱酸性 5.0–5.5**（贴近婴儿皮脂膜 4.5–5.5；不破坏皮脂层；来源[4][5]）
- **无泪配方**：等渗表活（与泪液渗透压接近）+ **APG（烷基糖苷，Decyl/Lauryl Glucoside）+ 氨基酸表活（Cocamidopropyl Betaine/Sodium Cocoyl Isethionate）**——**两性表活 + APG**最温和（知乎·来源[1]Aveeno）
- **完全避用**：SLS / SLES（强清洁刺激）/ 皂基（碱性破坏）/ 香精 / 色素 / 酒精 / 防腐剂 MIT/CMIT/尼泊金酯/甲醛释放体（08-05 敏感肌过敏率高）
- **舒缓保湿添加**：燕麦仁提取物（Aveeno 经典·来源[1]）/ 卵磷脂 / 维生素 E / 神经酰胺 NP / 角鲨烷 / 泛醇 / 艾叶提取物 / 柳杉芽提取物（3-12岁·来源[4]）
- **婴童分龄**（来源[4]）：
  - **0-3岁**：APG 表活 + CalmYang（多种植物）+ 弱酸性 → 适度清洁 + 强健屏障；
  - **3-12岁**：天然氨基酸 + APG 双重表活 + 艾叶提取物 + 柳杉芽提取物 → 温和清洁多余油脂；
- **工艺**：低温（≤40℃）避免破坏表活 + 蛋白类添加后段加 + 防腐多元醇（避 MIT/CMIT）。
→ 配方启示：婴童洗护 = **弱酸性 pH 5.5 + APG/氨基酸 + 拟肤成分（神经酰胺/角鲨烷/泛醇）+ 燕麦仁 + 卵磷脂 + 无泪设计 + 多元醇防腐 + 避香精色素酒精**。

- **功效护肤（敏宝）**：华西珐玛婴儿桂花舒缓特护霜（企鹅号·2026-07-28）— **桂花素 Osth**（天然抗炎+舒缓）+ 仿胎脂脂质 + 泛醇；

- **孕妇可用**：透明质酸 + 甘油 + 氨基酸表活 + **物理防晒（氧化锌+二氧化钛）+ VE + 乳木果油**（博禾·来源[8]）。

## 4. 孕妇护肤品"安全禁区"
> 来源：39健康网·孕妇不能用什么化妆品（2025-03-20）[9] + 腾讯·孕期护肤品禁忌（2025-10-28）[10] + 全民健康网·孕妇护肤品禁忌成分表（2026-05-23）[11]
- **维A酸及衍生物**（视黄醇/视黄酯/视黄醛/视黄醇棕榈酸酯）：**★★★★★ 极高危**——口服过量已证实导致胎儿畸形；**外用专家建议孕期碰都别碰**（来源[10]）；
- **水杨酸类**（Salicylic Acid / 水杨酸甲酯 / 水杨酸乙酯）：**★★★☆☆**——祛痘产品+去角质；**外用对皮肤刺激+长期使用风险**；**妊娠纹预防中亦应避用**；
- **对苯二酚（氢醌）**：美白产品主流；**孕期暂停使用**（来源[9]）；
- **邻苯二甲酸盐（Phthalates）**：塑化剂；**内分泌干扰**；指甲油/香水常见；避用；
- **水杨酸甲酯 / 水杨酸乙酯**：常见于防晒+香精+防腐；**内分泌干扰**；
- **4-MBC（4-甲基苄亚基樟脑）**：化学防晒；**内分泌干扰**（来源[9]）；
- **重金属超标**：铅/汞/砷；化妆品基质污染控制；
- **刺激性香精**：部分成分可能致敏；尽量避免；
- **美白祛斑**：377 / 壬二酸 / 曲酸 / 对苯二酚 / 烟酰胺（高浓度）；
- **物理防晒优先**：氧化锌+二氧化钛（08-12 B 方路线）；**完全避用化学防晒剂（OMC/Avobenzone/4-MBC）**（08-12）。
- **基础保湿类安全**：透明质酸+甘油+氨基酸表活+VE+乳木果油（博禾·来源[8]）。

## 5. 妊娠纹预防/修复"专用配方架构"
> 来源：民福康·抹什么可以淡化妊娠纹（2026-05-18）[12] + 博禾·橄榄油可以去妊娠纹吗（2026-04-04）[13] + 海淘族·Mama kids 妊娠纹护理乳液（2023-01-20）[14]
- **橄榄油 + 积雪苷霜软膏**（来源[12]民福康）：**橄榄油富含 VE 和不饱和脂肪酸** → 滋润+抗氧化+增加皮肤弹性+柔软度；**积雪苷霜软膏**——促进创伤愈合+激活上皮细胞+促进正常肉芽组织+抑制纤维细胞增殖+妊娠纹修复；**效果因人而异**；
- **妊娠纹预防多维度**（来源[13]博禾）：橄榄油预防早期妊娠纹；**积雪草苷霜+妊娠纹修复凝胶**效果可能优于单纯橄榄油；**控制孕期增重速度+优质蛋白+VC 摄入**；**孕早期每天橄榄油+乳液保湿**；**淋浴水温不宜过高**；
- **Mama kids 妊娠纹乳液配方分析**（来源[14]海淘族）：
  - **33 种化学成分**；**无香精、无风险、孕妇适用**；
  - **保湿成分（19种）**：甘油、野大豆甾醇类、水解胶原等；
  - **美白成分（5种）**：**烟酰胺**、积雪草提取物、水解蛋壳膜等；
  - **活性成分（22种）**：氢化卵磷脂、银杏叶提取物、磷脂等；
  - **抗氧化成分（7种）**：卵磷脂、**神经酰胺 3**、生育酚等；
  - **舒缓成分（1种）**：**欧洲七叶树树皮提取物**。
→ 配方启示：妊娠纹配方 = **保湿（甘油+水解胶原）+ 美白（烟酰胺+积雪草提取物）+ 活性（卵磷脂+银杏叶+磷脂）+ 抗氧化（神经酰胺 3+VE）+ 舒缓（欧洲七叶树）** + **避 A 醇/水杨酸/对苯二酚**。

## 6. 乳头保护霜"纯羊毛脂膏"配方架构
> 来源：复禾健康·哺乳期乳头裂了怎么办（2025-01-11）[15] + 复禾健康·哺乳乳头破裂怎么治疗（2026-06-09）[16]
- **羊毛脂（Lanolin）**：纯天然+较好保湿和修复+促进乳头皮肤愈合；
- **VE（生育酚）**：抗氧化+滋润；
- **蜂蜡**：封闭性增强+修护屏障；
- **无香精/无酒精/无添加剂**（来源[16]）；
- **哺乳前无需擦除**——纯羊毛脂+VE+蜂蜡=对婴儿安全；
- **涂抹时机**：每次哺乳后涂抹少量在乳头及周围皮肤上；
- **避用**：含香料/酒精/添加剂产品（刺激皮肤）；
- **如严重皲裂**：温水清洁后再涂抹+哺乳保护罩+抗生素软膏（就医）。
→ 配方启示：乳头膏 = **纯羊毛脂 90%+ + VE 5%+ 蜂蜡 3%+ 螯合剂 + 哺乳前无需擦除 + 对婴儿安全**。

## 11. 工艺关键技术（10 条铁律）
1. **温度控制**（婴童洗护）：**≤50℃** 加热溶解水相；**40℃ 加 B 表活**（避免高温破坏 APG/氨基酸/两性表活）；**40℃ 加 C 油脂**；**35℃ 防腐**；婴童配方严禁 ≥60℃ 高温。
2. **表活选择**（婴童洗护）：**APG（癸基/癸基+月桂基葡糖苷）+ 氨基酸（椰油酰甘氨酸钠）+ 两性表活（椰油酰两性基乙酸钠/椰油酰胺丙基甜菜碱）**——三重温和；**避 SLS/SLES/皂基**。
3. **pH 调节**：婴童洗护 **pH 5.0–5.5**（弱酸性）；孕妇精华乳 **pH 5.0–5.5**；乳头膏**中性不调**；NaOH/三乙醇胺/柠檬酸调 pH。
4. **加料顺序**：
   - 婴童洗护：A 水相 50℃ 溶解→B 表活 40℃ 后段加→C 油脂 40℃ 后段加→D 螯合→E 防腐→柠檬酸调 pH 5.5→真空灌装。
   - 孕妇精华乳：A 水相 75℃ 溶解→D 增稠→B 油相 80℃ 乳化→50℃ 加活性剂→40℃ 加舒缓剂+螯合+防腐→NaOH 调 pH→真空灌装。
   - 乳头膏：基质 70℃ 溶解→高速剪切→降温 50℃ 灌装。
5. **无泪设计**（婴童洗护）：
   - **APG + 氨基酸 + 两性表活** 等渗表活（与泪液渗透压接近 0.9% NaCl）；
   - **pH 5.0–5.5**（与泪液 pH 7.0-7.4 接近）；
   - **低泡配方**（泡沫少进眼少）；
   - **Draize 兔眼刺激试验** 阴性。
6. **螯合剂避 EDTA**：改**植酸钠**（08-07）。
7. **防腐**：1,2-己二醇 1%+对羟基苯乙酮 0.5%（婴童+孕妇+乳头膏均适用）；**避 MIT/CMIT/甲醛释放体/尼泊金酯**（08-05）；乳头膏**无需防腐剂**（纯油膏含水 0）。
8. **仿胎脂配方**（婴童+孕妇）：**胆固醇+角鲨烷+神经酰胺**——仿婴儿胎脂脂质（3:1:1 黄金比例，08-11）。
9. **避孕妇安全禁区**：A 醇/视黄醇/视黄酯/视黄醛/视黄醇棕榈酸酯/水杨酸/水杨酸甲酯/水杨酸乙酯/对苯二酚/邻苯二甲酸盐/4-MBC/香精/色素/酒精/化学防晒剂。
10. **包材**：婴童洗护按压泵/翻盖瓶；孕妇精华乳真空泵/软管；乳头膏**广口瓶/软管**（**哺乳前无需擦除**）。
