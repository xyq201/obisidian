# 超分子 866 · 杉海创新抗衰三肽 + 超分子促渗平台

> 商业原料平台型案例研究。一个 SKU 把"抗衰三肽 + 超分子递送"打包售卖，是观察"成分党叙事 → 功效数据 → 工厂产能"闭环的完整范本。**重点抓三条：① 抗炎修护 / 结构重建 / 功能调节 的三轴定位；② 三肽各自机制与现有胜肽知识图谱的对齐；③ 超分子促渗（vs 微针 / 纳米乳 / 天然促渗剂）的差异化卖点。**

## 1. 产品定位（一句话）

**杉海创新（Shinehigh）**自研"超分子 866"原料平台 —— 以**乙酰基八肽-1 / 乙酰基六肽-8 / 六肽-9** 三种胜肽为功能主体，叠加**超分子（深共晶溶剂 / low-eutectic solvent）促渗**技术，对标皮肤衰老的**可干预标志**：蛋白质稳态丧失、细胞衰老、ECM 变化、慢性炎症。

> 产品对外宣称关键词：**紧致充盈 / 抗炎修复 / 舒缓保湿**

底层逻辑引用：**国际顶刊《Cell》发表的"人类衰老 14 大标志"** 中，与皮肤外观（皱纹、松弛、敏感）直接相关的四大标志 —— 蛋白质稳态丧失、细胞衰老、ECM 变化、慢性炎症。

## 2. 三肽机制拆解

### 2.1 乙酰基八肽-1（Acetyl Octapeptide-1）— 抗炎 + 抗衰 双机制

| 项 | 内容 |
|---|---|
| 类型 | 抗炎修护肽（新型，区别于常见信号肽/神经递质肽） |
| 核心通路 | 抑制炎症因子 **TNF-α、IL-6、IL-8** 的表达；同时靶向调控 **ECM 形成相关通路、胶原蛋白形成相关通路**，促进成纤维细胞增殖与分化 |
| 表皮层效果 | 修复皮肤屏障功能、修护皮肤微环境 |
| 真皮层效果 | 促 I 型、III 型胶原蛋白合成（I 型=结构支撑，III 型=柔韧弹性） → 紧致 |
| 用量梯度（厂商实验） | 0.1% / 0.5% / 1% 三档；**细胞增殖相对含量随浓度递增**（原料图示） |
| 与既有肽谱的对齐 | **新类** —— 现存知识图谱的"信号肽 / 神经递质肽 / 载体肽"三类中未单列，应作为**第四类"免疫调节肽 / 抗炎肽"** 单独建档 |

> 配方启示：抗炎修护是新风口。"敏感肌 + 早衰 + 炎症后色沉（PIH）"三角人群可优先选配本品，**与泛醇 / 神经酰胺 / 红没药醇形成"屏障 + 抗炎"双轴**。

### 2.2 乙酰基六肽-8（Acetyl Hexapeptide-8 / Argireline）— 类肉毒放松表情肌

| 项 | 内容 |
|---|---|
| 机制 | 模仿 **SNAP-25** N-末端结构域，竞争 SNARE 复合物中的位置 → 阻断乙酰胆碱释放 → 肌肉放松 → 抚平动态纹/静态纹/细纹 |
| 通路详 | 神经递质释放需 VAMP / syntaxin / SNAP-25 三蛋白组装为 SNARE 复合物；乙酰基六肽-8 模拟 SNAP-25 抢占结合位 → 囊泡不能与突触前膜融合 → 乙酰胆碱无法释放 → 肌肉电脉冲阻断 |
| 附加价值 | 抑制肌肉收缩的同时，**促进胶原蛋白与弹力蛋白活性** → 增强皮肤弹性与紧致度（区别于纯神经阻断） |
| 与既有认知对齐 | **与 [[Topics/原料学习知识/肽类-胜肽]] 2.2 节完全一致**，可作为该机制**产业化最成熟的代表** |

> 配方启示：本成分在 28 天人体测试（厂商数据 16 例受试者）中 **R2 弹性 +10.08%、F4 紧致 -13.39%、皱纹数量 -4.94%** —— 三指标均显著，与[[Topics/化妆品护肤/抗衰精华-实战配方设计-CEF-玻色因-胜肽-烟酰胺-视黄醇HPR-修护]]中的"抗衰四矩阵"高度呼应，可作为组合中的"放松表情肌"组件。

### 2.3 六肽-9（Hexapeptide-9）— 屏障重建 + 深层保湿

| 项 | 内容 |
|---|---|
| 结构 | 小分子合成六元多肽（两个 Gly-Pro-Gln 重复序列） |
| 与人体同源性 | 序列与**人体胶原蛋白 IV 型和 XVII 型**相同 → 天然亲和 |
| 核心机制 | 作用于皮肤成纤维细胞 → 合成修复/重建 **ECM 与 DEJ（dermal-epidermal junction）** 所需的小分子：I / III / IV 型胶原、纤维连接蛋白 Fibronectin、糖胺聚糖 |
| 保湿 | 上调皮肤自身**透明质酸**合成 → 从根源提高水合能力（区别于"外涂玻尿酸"的临时性） |
| 修护定位 | 清洁过度/刷酸/环境刺激导致的屏障受损、泛红、干燥、刺痛 |
| DEJ 联动 | DEJ 主体 = 层粘连蛋白 + IV 型胶原（致密板），通过 XVII 型胶原与表皮基底层交联，往下通过 VII 型胶原与真皮 I/III 型网络骨架交联，再加整合素整体连接 → 本成分**精准补全 DEJ 三型胶原的关键缺口** |

> 配方启示：**与 [[Topics/皮肤科学/皮肤屏障-角质层砖墙模型-细胞间脂质]] 的"屏障修复 3:1:1"互补** —— 一个补细胞间脂质（神经酰胺），一个补 DEJ 胶原锚点（六肽-9）。屏障修护从"角质层砖墙"延伸到"表皮-真皮锚点"，是配方概念的升级方向。

### 2.4 三肽组合的整体逻辑

```
抗炎修护 ── 乙酰基八肽-1 ─┐
                            ├─→ 立体抗衰（炎症+ECM+功能）
结构重建 ── 六肽-9       ─┤
功能调节 ── 乙酰基六肽-8 ─┘
```

> 与现有[[Topics/化妆品护肤/抗衰精华-实战配方设计-CEF-玻色因-胜肽-烟酰胺-视黄醇HPR-修护]]的"四抗衰矩阵"（CEF + 玻色因 + 胜肽 + 烟酰胺）相比，本品**用三种胜肽替代"玻色因 + 烟酰胺"，突出胜肽线**；再叠加超分子递送 —— 差异化在"递送通道"。

## 3. 超分子促渗平台（核心差异化卖点）

### 3.1 超分子化学背景

- **1987** —— 首次提出超分子化学（Nobel Chemistry）
- **2016** —— 超分子化学及分子机器（Nobel Chemistry）
- **2025** —— 最重要的技术创新：发展金属有机框架材料 MOF（*MOF 的核心原理源于超分子化学中的"分子识别"与"自组装"机制*）

> 超分子化学三次诺奖加持，是厂商叙事的合法性背书。

### 3.2 超导协同促渗技术（创新递送体系）

| 项 | 内容 |
|---|---|
| 痛点 | 大分子活性物（重组胶原蛋白、多肽）皮肤透过量低；水溶性成分难透过皮脂膜 |
| 解法 | 杉海创新用**量子化学辅助合成促渗多肽**，在不损伤皮肤结构的前提下，**靶点部位含量提升 45%+**，渗透效果与驻留时间里程碑式提升 |
| 安全 | 对皮肤屏障无损伤；属业界首创 |
| 适用 | 重组胶原蛋白、多肽、水溶性活性物的精准递送 |

### 3.3 常见促渗手段横向对比（厂商整理 + 配方师视角点评）

| 手段 | 类别 | 优势 | 劣势 / 风险 |
|---|---|---|---|
| **微针** | 物理促渗 | 安全便捷、生物相容性好、刺激胶原再生 | 出血开放伤口、需无菌操作、需麻醉、有恢复期、卫生要求高 |
| **水光针** | 物理促渗 | 直注真皮层、效果快 | 个别不适用、需医疗资质、术后护理 |
| **纳米乳** | 纳米技术 | 缓释靶向、工艺简单 | 微粒小、可能具有一定毒性、对不同活性物需筛选 |
| **天然促渗剂**（薄荷油等） | 化学促渗 | 安全、天然、环保、提高溶解度 | 促渗效果有限 |
| **超分子溶剂促渗** | 化学促渗 | **安全、环保、高效；缓释、靶向；可逆破坏角质细胞间脂质结构；促进细胞间隙扩大；有效成分含量可达更高** | 需针对不同活性物筛选不同的超分子溶剂组合（**理论与工艺门槛高**） |

> 配方启示：**对配方师最有价值的判断**：超分子溶剂 = 化学促渗的"高端版本"，**对皮肤屏障"可逆破坏"是关键词** —— 既提升渗透、又比纳米乳安全、比微针温和、比传统化学促渗剂高效。这是行业方向。

### 3.4 理论计算验证（甜菜碱-乳酸共晶案例）

- **ΔpKa < -1** → 形成共晶；**ΔpKa > 4** → 形成盐；中间区离子化程度线性增加
- 甜菜碱-乳酸 **ΔpKa = -2.14** → 理论上形成**共晶**
- 当熔点足够低时，也属于**低共熔溶剂（DES / Deep Eutectic Solvent）** —— 这就是"超分子溶剂促渗"的化学本质

> 与[[Topics/皮肤科学/透皮吸收机理-路径-500道尔顿-Franz扩散池]]中的"促渗剂"一节呼应：传统化学促渗剂（氮酮/乙醇/丙二醇）作用单一，超分子溶剂是**多组分协同**（氢键受体 + 给体 + 活性物三元共晶），作用更精准。

## 4. 功效与安全数据（厂商公布）

### 4.1 稳定性测试

- **50℃ / 45℃ / 5℃ / -15℃ / 光照 / 常温** 六条件下，三个月原料均未见明显析出、变色
- 节点：1d / 7d / 14d / 21d / 28d / 45d / 60d / 90d
- **配方启示**：超分子促渗体系对活性物稳定性有正向贡献（猜测机理：共晶结构降低分子自由度、抑制水解/氧化）

### 4.2 安全性测试（细胞毒性）

- 超分子 866（不带防腐）浓度梯度 **0.078125% / 0.15625% / 0.3125% / 0.625% / 1.25% / 2.5% / 5% / 10%（v/v）**
- 细胞活力均值：102.64% / 95.75% / 103.63% / 97.73% / 92.01% / 98.79% / 91.38% / 81.38%
- 阳性对照（10% DMS）：4.36%；阴性对照（PC）：100%
- **结论：10% 添加量细胞存活率仍在 80%+** —— 高浓度安全余量充足，符合温和抗衰定位

> 与[[Topics/化妆品护肤/乳化体系与稳定性]]的"安全余量"概念呼应：终产品中活性物添加 5–10% 是合理安全窗。

### 4.3 透皮测试

- **荧光透皮测试**：超分子 866 > 游离 866（定性强证据）
- **拉曼测试**：作用于皮肤 6h 显著渗透；**24h 渗透率较 6h 提升 96.6%**（有时间依赖性蓄积）
- **配方启示**：超分子促渗实现"持续释放+靶点蓄积"，是优于"瞬时渗透"的卖点

## 7. 配方师可立即借鉴的 5 条

1. **"三轴抗衰"叙事框架可借鉴**：抗炎修护 / 结构重建 / 功能调节 —— 比"一瓶多效"更显机理清晰，比"抗衰 + 美白 + 修护"更聚焦
2. **超分子促渗 = 高端差异化点**：原料商如能用 ΔpKa + 共晶 + DES 三件套讲清楚机制，比"纳米包裹"更有技术纵深感
3. **"屏障 + DEJ"双层修护叙事**：现有知识库重角质层脂质（Cer 3:1:1），**DEJ 胶原锚点（六肽-9 类）是被低估的修护角度**，可作为新原料选品方向
4. **多肽复配的"机制不重叠"原则**：抗炎肽（八肽-1）+ 神经递质肽（六肽-8）+ 修护肽（六肽-9）三机制互不重叠，与 [[Topics/化妆品护肤/抗衰精华-实战配方设计-CEF-玻色因-胜肽-烟酰胺-视黄醇HPR-修护]] 中的"四矩阵"思路一致
5. **透皮测试选型**：荧光定性 + 拉曼定量 + 24h 时间依赖性 —— 三个数据维度比"单一时间点渗透率"更能证明产品力
