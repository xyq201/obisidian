# NMPA 化妆品注册备案改革公告（2026-07-29）

> 国家药监局发布关于化妆品注册备案有关事项的公告,围绕"管理效能提升"提出八大举措,**自发布之日起实施**。本笔记重点拆解"对配方开发与备案策略的影响",并与已有原料/法规笔记联动。

## 一、核心信息

- **发文机关:** 国家药品监督管理局(NMPA)
- **发布时间:** 2026 年 7 月 29 日
- **生效时间:** 自发布之日起实施(无过渡期)
- **核心导向:** 减负增效 + 鼓励创新 + 简化流程 + 数据共用
- **重大变化:** **原料报送码制度**成为历史

## 二、八大举措速览

| 举措 | 核心变化 | 对配方/备案的影响 |
|---|---|---|
| 一、国际新品首发 | 免交境外上市销售证明,销售包装可用设计图 | 跨国新品快速进入中国市场 |
| 二、毒理豁免扩大 | 烫发/非氧化染发/物理遮盖美白/含新原料的普通化妆品可免动物试验 | 条件:境外官方生产质量管理资质 + 安全评估充分 |
| 三、原料报送码取消 | 仅填原料生产商名称,自行留存备查,**国家局不再公开原料报送码** | **重大变化:**原料报送码制度成为历史 |
| 四、配方近似共用 | 配方近似+统一生产场地→1款代表品做微生/毒理/人体安全,其余共用 | 配方变体策略可大幅降低测试成本 |
| 五、境内外互转/新增场地 | 注册人/配方/产品名/执行标准无实质变化→毒理/人体/安评/功效可共用,微生理化重做 | OEM 工厂切换成本降低 |
| 六、功效评价方法放开 | 除美白/防晒/防脱发外,其他功效可自主选用:行业标准/国际标准/技术指南/企业自建方法 | 抗衰/保湿/控油/舒缓等功效申报更灵活 |
| 七、同品牌近似功效共用 | 代表品功效试验,其余共用+等效评价证明,公示注明共用 | **配方近似范围增加"防腐剂"变量**(比第四条更宽松) |
| 八、变更境内责任人 | 取消知情同意书+法院变更文书,简化为三类资料 | 跨境品牌变更代理人更便捷 |

## 三、对配方开发与备案的具体影响

### 3.1 原料报送码制度取消(第三大举措)

**变化前:**
- 注册备案需填原料报送码
- 国家局公开原料报送码
- 原料生产商变更需重报

**变化后:**
- 仅填**原料生产商名称**
- 相关资料企业自行留存备查
- 国家局不再公开原料报送码
- 原料生产商/规格变更按规定更新备案即可

**配方启示:**
- 原料选择更灵活——不再因"报送码未取得"被卡
- 国产新原料、小众植萃、特色活性物的申报路径简化
- 但**企业内部仍需建立完整的原料档案**(生产商资质、规格、COA、安全数据),因为"自行留存备查"=责任自负
- 与 [[研发权威资料清单]] 第二节"国内监管官方平台" 联动——NMPA 不再公开后,内部台账的重要性上升

### 3.2 配方近似共用报告(第四、七大举措)

**核心规则:**

| 维度 | 第四条 | 第七条(更宽松) |
|---|---|---|
| 范围 | 配方近似 + 统一生产场地 | 同品牌 + 配方近似 |
| 微生物理化 | 多场地分别做 | — |
| 毒理 | 共用 | 共用 |
| 人体安全 | 共用 | — |
| 功效评价 | — | **代表品做,其余共用+等效评价证明** |
| **配方近似范围** | 近似配方体系 | **近似 + 防腐剂变量** |
| 公示要求 | — | **功效宣称资料摘要需注明共用数据情况** |

**配方启示:**
- **多 SKU 策略:** 同一品牌下设计配方近似系列(同一基质+不同活性物组合)成本大降
- **配方变体设计:** 微调香气/色素/防腐剂即可新增 SKU,功效报告无需重做
- **多场地生产:** 需各场地做微生物理化,但毒理/功效仍可共用
- **成本量化(行业人士口径):** 口红共用功效/毒理/微生物重金属可**节约万元左右**;不涉及功效/毒理的**节约千元左右**

### 3.3 功效评价方法放开(第六大举措)

**受严格管控(三类,仍须全套功效试验):**
- **祛斑美白**
- **防晒**
- **防脱发**

**可自主选择方法(其他所有功效):**
- 行业标准
- 国际标准
- 技术指南
- **经验证的企业自建方法** ← 新增亮点

**配方启示:**
- 抗衰、紧致、淡化细纹、舒缓、修护、控油、补水等功效申报路径更灵活
- 企业可建立自建方法库(仪器测试+人体试用+统计分析),经内部验证后作为功效宣称依据
- 与 [[视黄醇-Retinol]]、[[肽类-胜肽]]、[[玻色因-羟丙基四氢吡喃三醇]] 等抗衰原料联动——抗衰功效可不再依赖单一标准方法
- **美白/防晒/防脱发三类仍严管:** 涉及 [[酸类-AHA-BHA-果酸水杨酸]](美白场景)、[[视黄醇-Retinol]](部分美白宣称)、未来防脱发原料仍需全套功效试验+配方近似说明

### 3.4 毒理动物试验豁免扩大(第二大举措)

**可免毒理动物试验的产品:**
- 烫发
- 非氧化染发
- 仅具物理遮盖作用的祛斑美白产品
- 含新原料的普通化妆品(**儿童化妆品除外**)

**必要条件(同时满足):**
- 企业持有**境外官方生产质量管理资质**
- **安全评估可充分证明产品安全**

**配方启示:**
- 进口品牌可借助境外 GMP 资质免动物试验,缩短新品周期
- **新原料研发:** 含新原料的普通化妆品可免动物试验,鼓励国产新原料创新
- **儿童化妆品仍需动物试验:** 婴幼儿/儿童线研发需保留毒理路径
- 安全评估能力成为核心竞争力——可参考 [[乳化体系与稳定性]] 中的稳定性评价体系建立安评 SOP

### 3.5 国际新品首发简化(第一大举措)

**适用场景:**
- 国际新品在中国首发
- 国际新品全球同步上市

**简化内容:**
- **免交境外上市销售证明**(提交首发承诺声明即可)
- 申报时销售包装可用**设计图**

**配方启示:**
- 跨国新品"全球首发选中国"成为可能
- 包装设计可先申报,实物后补——设计-申报-生产并行
- 与 [[头皮洗护市场洞察与趋势]] 中"国际品牌+国货品牌 Top10"竞争格局联动——首发效率成为外资品牌差异化优势

### 3.6 境内外互转/新增场地简化(第五大举措)

**适用场景:**
- 已备案产品境内外互转
- 增加生产场地

**条件:** 注册人、配方、产品名、执行标准无实质变化

**可共用报告:** 毒理、人体安全、安全评估、功效评价

**必须重做:** 微生物与理化检验

**额外要求:** 提交原注册/备案凭证

**配方启示:**
- OEM 工厂切换、品牌出海、跨境供应链调整成本降低
- 与 [[乳化体系与稳定性]] 联动——切换工厂需重做微生物理化,稳定性数据无需重做

### 3.7 变更境内责任人简化(第八大举措)

**取消材料:**
- 原境内责任人知情同意书
- 法院变更文书

**新三类材料:**
1. 境内责任人授权原件及其公证书原件
2. 拟变更境内责任人的产品清单
3. 拟变更责任人承担产品原境内责任人各项责任的承诺书

**配方启示:**
- 跨境品牌集团内部调整代理人结构更便捷
- 进口品牌被收购/重组的法规路径简化

## 四、配方变体设计策略建议

利用第四、七大举措,设计"核心配方 + 微调变体"系列:

| 策略 | 适用场景 | 成本节约 |
|---|---|---|
| 同基质+不同活性物 | 主打原料切换(玻色因/胜肽/VC) | 万元/产品 |
| 同基质+不同香气/色泽 | 香水、洗护色彩线 | 千元/产品 |
| 同基质+不同地域生产 | 多工厂 OEM 布局 | 微生物理化外可共用 |
| 同基质+不同规格/包装 | 30ml/50ml/100ml 系列 | 千元/产品 |

> **配方开发思维转变:** 从"每个 SKU 都是独立配方"转为"**配方平台化**"——一个稳定基质 + 多个活性物模块 + 多个变体维度

## 五、对企业内部合规能力的倒逼

虽然多份报告可共用,但**责任并未减轻**——

| 责任维度 | 应对方式 |
|---|---|
| 原料报送码取消后原料台账 | 建立内部 INCI/规格/生产商/COA 数据库 |
| 安全评估充分证明 | 培养内部安评员或外包权威第三方 |
| 自建功效方法验证 | 建立功效实验室+统计分析能力 |
| 配方近似等效性证明 | 配方变更 SOP+等效性评估流程 |
| 微生物理化多场地管理 | 各场地微生物挑战+理化指标台账 |

> **核心逻辑:** 减的是"重复提交的材料",**加的是"企业自身的能力"**。
