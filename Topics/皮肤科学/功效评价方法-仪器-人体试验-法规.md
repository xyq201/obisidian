# 功效评价方法 · 仪器 / 人体试验 / 法规框架

> 学习笔记：把"产品到底有没有效、怎么证明有效"的方法体系梳一遍，直接支撑**配方立项→体外筛选→人体终局证据→合规宣称**全链路。桥接[[透皮吸收机理-路径-500道尔顿-Franz扩散池]]（Franz 体外机制）与[[皮肤屏障-角质层砖墙模型-细胞间脂质]]（TEWL 即屏障终点）。

## 1. 为什么做功效评价（双驱动）
- **法规驱动**：中国《化妆品功效宣称评价规范》(NMPA, 2021) 要求宣称功效须有评价依据并存档备查；安全性/功效性宣称须与证据匹配（来源[8] 检验规范区别；法规原文待核）。
- **研发驱动**：配方阶段用体外/Franz 快速筛选，上市前用人体现场证据，避免"主观觉得有效"。

## 2. 在体无创仪器图谱（人体现场常用）
| 维度 | 仪器/原理 | 读数与含义 | 来源 |
|---|---|---|---|
| 屏障/保湿（失水） | TEWL（Tewameter，开放式/封闭式腔测水散失） | 值越低=屏障越好、产品锁水越强 | [2] |
| 角质层含水量 | Corneometer CM825（CK，电容法 MMV） | 电容随水合上升；值越高越润 | [4] |
| 含水量（多深度） | Delfin MoistureMeter SC / Biox Epsilon 介电成像 | 近红外/介电反映不同深度水分 | [4] |
| 皮肤弹性 | Cutometer® dualMPA580（CK，吸力拉伸法） | 垂直负压致变形，R 值越大弹性越高 | [1] |
| 皱纹/纹理 | PRIMOS（相位测量轮廓术）/ VISIOD-3D（条纹投影, DermaTOP）/ VISIR-CR 面部成像 | 定量皱纹深度、皮肤粗糙度 | [5] |
| 色素/美白 | Mexameter MX18（红斑/黑素指数）/ Visia | 监测肤色、黑素变化 | [2][9] |
| 综合成像 | VISIA（Canfield，标准/紫外/偏振三光源，1200万–2800万像素） | 斑点/皱纹/纹理/毛孔/红血丝/色素/油脂/UV斑定量 | [9][10][11] |

### 配方启示
- **保湿/屏障修护品**：必报 **TEWL↓ + Corneometer↑** 双指标（桥接屏障笔记：修复周期 ≥28 天）。
- **抗皱/紧致**：Cutometer（弹性 R 值）+ PRIMOS/Visia 皱纹参数（深度、面积、数量）。
- **美白/淡斑**：Mexameter 黑素指数 + Visia 色斑量化 + 色度仪（ITA°/L*a*b*）。
- **敏感/修护**：选乳酸刺痛阳性人群（见 §4），以 TEWL + 红斑指数 + 自评为主。

## 3. 体外 / 离体方法（配方阶段快速筛选）
- **Franz 扩散池**：最经典体外透皮（依据 OECD 428 / GB/T 27818-2011）；除"接收液透过量"更应测**皮肤各层滞留量**（角质层/表皮/真皮）判断真吸收（来源见[[透皮吸收机理-路径-500道尔顿-Franz扩散池]]）。
- **人工皮肤模型**：Strat-M®、EpiDerm™、SkinEthic™ 等替代动物/人皮，预测人体透皮、做安全性与促渗有效性筛选（来源[12] 羿科联和；[13] hq17·Strat-M）。
- **体外称重法（保湿）**：高湿干燥器测**吸湿率**、低湿（硅胶）测**保湿率**，快速比原料吸湿/锁水（来源[3] 知乎·八种保湿评价方法）。
- **体外细胞/3D 模型**：角质形成细胞、重建表皮用于刺激/光保护机制（研发向，待补专题）。

## 4. 人体功效试验设计要素（可落地模板）
- **周期与时间点**：修护/屏障类常用 **28 天**，时间点 **D0、D14、D28**（来源[6] 环特生物·修护测试方案）；祛痘类 **≥4 周**，D0/2周/4周（来源[7] 企鹅号·祛痘合规）。
- **样本量**：祛痘有效例数 **≥30 人/组**，年龄 18–45；修护/敏感类纳入 **乳酸刺痛 ≥3 分** 的敏感人群，年龄 18–55（来源[6][7]）。
- **多维度评估**：仪器测试 + 标准图像 + 临床医生评估 + 受试者自评"四位一体"（来源[7]）。
- **伦理与对照**：知情同意书；设空白/阳性对照；试验期间禁用干扰化妆品/药物（来源[6]）。
- **统计**：报告样本量、p 值/置信区间、效应量；宣称须与终点一致（如"保湿"不能拿"美白"数据宣称）。

## 5. 法规框架（中国，必备红线）
- **《化妆品功效宣称评价规范》**(NMPA, 2021 发布施行)：宣称功效须有评价依据；部分功效（祛斑美白、防晒、防脱发、祛痘、抗皱、紧致、舒缓、控油、去角质、无泪配方等）须**人体试验**，其余可实验室/文献（具体清单 **以 NMPA 原文为准，待核**）（来源[7][8]）。
- **《化妆品注册和备案检验工作规范》**：宣称祛斑美白、防脱发及新功效的产品须按指导原则做相应功效检验并出具报告（来源[8]）。
- **红线**：普通化妆品**不得宣称特殊化妆品功效**（美白/防晒/染发/烫发/祛斑/防脱发等属特殊或须专项检验）（来源[7]）。
- ⚠️ 上述法规条目与"哪些功效强制人体试验"的具体清单，建议直连 NMPA 官网（nmpa.gov.cn/hzhp）核对原文，标"待核"。

## 6. 对配方/研发的实操指导（速查）
1. **立项先定终点**：要宣称什么 → 选对应仪器+试验设计（保湿=TEWL+Corneometer；抗皱=Cutometer+PRIMOS；修护=乳酸刺痛人群+28天）。
2. **配方阶段用 Franz/人工膜做机制筛选**，降低人体试验试错成本（桥接递送系统：包裹后滞留量↑即有效信号）。
3. **人体试验是终局证据**：样本量/周期/时间点按规范与 CRO 方案（修护 28天 D0/D14/D28；祛痘 ≥30人 ≥4周）。
4. **宣称与证据严格对齐**：不跨功效宣称；普通品不碰特殊功效词。
5. **警惕局限**：仪器多测表面/浅层；深层机制（如胶原新生）建议补组织学/生物标志物（待补专题）。
