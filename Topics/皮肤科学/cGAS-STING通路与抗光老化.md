# cGAS-STING 通路与抗光老化 · 天然免疫 · 配方设计

> 学习卡片：UV 不仅产 ROS，还会异常激活皮肤细胞的"病毒防御系统" cGAS-STING，驱动慢性炎症与胶原降解。这是继抗氧化之后的**新兴抗光老化靶点**。对接 皮肤老化与光老化机理。

## 1. 通路机制链
UVB → 细胞质 DNA 损伤 + 线粒体 DNA(mtDNA) 泄漏 → 被 **cGAS** 识别 → 催化 2'3'-cGAMP → 激活 **STING** → 磷酸化 TBK1 / IRF3·IRF7 → **I 型干扰素(IFN-α/β)↑** + 其他炎症因子 → **MMP 上调** → 胶原 I/III 降解 → 皱纹/松弛。
> 光老化慢性炎症的"隐形引擎"：cGAS-STING 持续激活 → IFN-Ⅰ 慢性高表达 → 基质降解。

## 2. 天然成分抑制证据
| 成分 | 证据 | 活性/备注 |
|---|---|---|
| **绿原酸（Chlorogenic Acid）** | 分子对接证实结合 cGAS 与 STING，抑制其 mRNA/蛋白表达 | 咖啡/金银花等多源；兼抗氧化 |
| **三七提取物（PNE）** | 小鼠+细胞模型显著抑制 cGAS-STING，减轻 AD 样炎症 | 皂苷类 |
| **茵陈蒿提取物（AC）** | 抑制 UVB 诱导的 cGAS/STING 活化，减少 IL-1α/IL-6/PGE2 | 主活性=绿原酸及其衍生物 |

## 3. 配方转化
- **光防护升级**：防晒 + 日间抗氧化之外，加入 cGAS-STING 抑制剂（绿原酸/三七皂苷）→ 从"挡紫外线"升级到"挡住后还能消炎症"。
- **抗衰双轨**：传统抗氧化（VC/VE/辅酶Q10）+ 抑制天然免疫过度激活，形成"抗氧化 + 抗天然免疫"双轨抗衰。
- **敏感肌维稳**：慢性敏感肌的"低度炎症状态"部分由 cGAS-STING 驱动，抑制该通路可作长期维稳新策略。

## 4. 评价端点
- IFN-β 分泌量（cGAS-STING 活化标志）
- MMP-1/-3 表达（胶原降解）
- 红斑 / TEWL（屏障与炎症）

## 5. 宣称合规
- 不写"修复 DNA 损伤" → "帮助皮肤抵御环境压力"
- 不写"阻断炎症" → "舒缓肌肤不适感"
- cGAS-STING 属机理描述，对外宣称须转译为消费者语言（如"抵御光损伤""维稳"）
