# 敏感肌三型分型 · 神经源 / 血管 / 免疫 · 配方设计

> 学习卡片：把"敏感肌"从笼统概念拆成三型，对应不同核心靶点与成分组合，避免"一瓶通治"。对接 敏感皮肤机理与舒缓成分（TRPV1/神经源性敏感）、屏障笔记（3:1:1）、美白低刺激（08-04）。

## 1. 为什么分型
敏感肌的本质不是"皮肤薄"，而是**感觉神经-角质细胞-肥大细胞三角轴**正反馈 + 屏障缺损。单一靶点（只补神经酰胺）对神经源性敏感"治标不治本"；按**神经源 / 血管 / 免疫**三型分型，才能精准配方（来源：文档5 §4、§6）。

## 2. 三型分型与配方靶点
| 类型 | 主诉 | 客观特征 | 核心靶点 | 代表成分 |
|---|---|---|---|---|
| **神经源型**（刺痛为主） | 刺痛、灼热、遇温差/风吹/情绪波动加重 | 辣椒素试验阳性 | TRPV1 / TRPA1 | 4-叔丁基环己醇(SymSitive)、乙酰二肽-1 鲸蜡酯、麦角硫因/虾青素(抗氧化间接抑 TRPA1) |
| **血管型**（潮红为主） | 阵发性红斑、遇热/情绪/饮酒潮红 | 客观红斑明显(a*值高) | CGRP / VIP 神经肽、血管扩张 | CB2 受体激动植萃、羟苯基丙酰胺苯甲酸、棕榈酰三肽-8(下调 SP/CGRP) |
| **免疫型**（炎症为主） | 丘疹、脱屑、反复发作 | 伴炎症细胞浸润 | IL-1α / TNF-α、肥大细胞 | 甘草酸二钾、红没药醇、益生元、马齿苋/燕麦 |

> 三型常叠加（如神经源+血管）：配方宜**多靶点协同**——屏障脂质 + TRPV1 抑制剂 + 抗炎植萃 + 益生元。单靶点产品的舒缓天花板很低。

## 3. 三角轴级联（降敏须同时压三方）
刺激 → TRPV1/TRPA1 开放 → Ca²⁺内流 → 神经末梢释放 P 物质/CGRP → 肥大细胞脱颗粒(组胺) → 血管扩张/红斑/水肿 → IL-1α/IL-6/TNF-α 抑制角质细胞分化与脂质合成 → 屏障更弱 → 通道持续敏化。
关键：**角质细胞本身是神经肽旁分泌工厂**（IL-1β 下 TRPV1↑3-5×、SP↑2-4×、组胺酶↑、FLG/IVL↓），故降敏不能只押 TRPV1 拮抗，须同步压角质细胞源 SP/组胺自分泌（甘草次酸衍生物等）。

## 4. 成分-靶点速查
| 靶点 | 代表成分 | 机制 |
|---|---|---|
| TRPV1 | 4-叔丁基环己醇 | 选择性阻断辣椒素诱导激活，IC50≈34μM |
| TRPA1 | 麦角硫因 / 虾青素 / 姜黄素衍生物 / 白藜芦醇 | 抗氧化间接抑制 / 直接阻断化学性刺激 |
| P 物质释放 | 甘草酸二钾 / 鼠尾草多酚 / 棕榈酰三肽-8 | 抑制肥大细胞脱颗粒 / 下调 SP-CGRP |
| 神经源性炎症 | 红没药醇 / SymCalmin® | 多靶点舒缓，降 CGRP |
| 角质细胞自分泌 | 特定甘草次酸衍生物 | 同步压 SP/组胺/TRPV1 |

## 5. 评价端点（升级）
- 辣椒素试验 VAS 评分（TRPV1 即时舒缓）
- a* 值（红斑指数）、TEWL（屏障）
- **SP/TRPV1 共下调率**（IL-1β 应激 HaCaT 中 SP 与 TRPV1 同降）——比单测 TEWL 更贴近"换季不刺"
- 乳酸刺痛试验（敏感筛选金标准）

## 6. 宣称合规
- 不写"修复神经" → "舒缓肌肤不适感 / 帮助肌肤放松"
- 不写"阻断炎症" → "帮助减少外界刺激带来的不适感"
- 不写"治疗敏感肌" → "适用于脆弱易泛红肌肤的日常护理"
