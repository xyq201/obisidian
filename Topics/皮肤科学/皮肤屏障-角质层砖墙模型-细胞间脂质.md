# 皮肤屏障生理学 · 角质层砖墙模型与细胞间脂质

> 学习笔记：把皮肤屏障的"结构—功能—受损—修复"梳理成对配方有指导意义的结论。直接桥接：神经酰胺/屏障修复、乳化与层状液晶、递送系统、功效评价（TEWL）。

## 1. 砖墙模型（Brick-and-Mortar）
- 角质层（SC）由**角质细胞（"砖"）** 与填充其间隙的**细胞间脂质（"灰浆/水泥"）** 构成，限制水分在细胞内/外及细胞间流动，维持屏障功能（来源[2] 百度百科·皮肤屏障 2026-07-31，https://baike.baidu.com/item/皮肤屏障/10431908）。
- **Peter M. Elias 教授（UCSF）最早提出**"砖墙结构"：表皮细胞将板层小体（lamellar granules / Odland bodies）释放到细胞外，转化为神经酰胺+游离脂肪酸+胆固醇的细胞间脂质，以自己为砖完成屏障"砌筑"（来源[4] 知乎·皮肤屏障是怎么形成的 2021-06-28，https://zhuanlan.zhihu.com/p/384600604）。
- 最外层**皮脂膜（"石膏"）** 由皮脂+汗液乳化形成，辅助抵御外界侵蚀（来源[1] 企鹅号·全方位了解皮肤屏障 2022-04-20，https://so.html5.qq.com/page/real/search_news?docid=70000021_318625f821c47152）。

## 2. 角质层"三明治"结构（层状液晶）
- 角质层中存在约 **13 nm 的"三明治"结构**：第一、三层为晶状体网格结构，中间为液相，由类脂构成，主要含**不饱和脂肪酸及胆固醇**（来源[2] 百度百科·皮肤屏障）。
- 这一层状液晶相是屏障功能与保湿/缓释的物理基础 —— 也解释了为什么**仿生层状液晶（如聚甘油-10 二硬脂酸酯）递送系统**能与角质层脂质相容、提升活性物透皮（与[[递送系统-脂质体纳米乳液晶微囊]] 桥接）。

## 3. 细胞间脂质的组成（关键数据）
- 角质层细胞间脂质由约 **50% 神经酰胺、25% 胆固醇、15% 游离脂肪酸**（极少量磷脂及其他）组成（来源[2] 百度百科·细胞间脂质 2023-04-02，https://baike.baidu.com/item/细胞间脂质/1922922）。
- 另一组常见质量占比：**神经酰胺 40–50%、脂肪酸 20–30%、胆固醇 20–30%**（来源[5] xjishu 专利·神经酰胺组合物 2023-10-16，https://www.xjishu.com/zhuanli/05/202310858682.html；[1] 企鹅号）。
- 神经酰胺含量最高、**对屏障性能最关键**；酰基链长度（天然多为 18-C）影响脂质排列密度与屏障功能（来源[2] 细胞间脂质）。

## 4. 屏障修复的"黄金比例"：两种说法需区分
- **生理学等摩尔比（Elias 原始观点）**：板层小体释放的神经酰胺:胆固醇:游离脂肪酸 按摩尔比 **1:1:1** 组成细胞间脂质（来源[4] 知乎）。
- **化妆品宣称"3:1:1"**：神经酰胺:胆固醇:游离脂肪酸 = **3:1:1**，被多篇配方科普/产品（如 NARUD 多效修复精华霜实测配比=3:1:1，含 CerAP/CerEOP/CerNP+胆甾醇+游离脂肪酸+角鲨烷+卵磷脂）引用（来源[3] 39健康网 2025-03-20，http://askar.39.net/a/230714/x38socl.html；[6] 知乎·NARUD 2021-10-21，https://zhuanlan.zhihu.com/p/423948443；[7] 搜狐·脂质修屏 3:1:1 黄金比例 2025-03-15，https://www.sohu.com/a/871477156_121081803）。
- ⚠️ **比例冲突待核实**：1:1:1（mol，生理）与 3:1:1（化妆品宣称，多按质量/经验）并不完全一致；化妆品外涂补充通常以"神经酰胺主导+胆固醇+脂肪酸协同"思路设计，**优先参考原料商 COA 与已上市配方**，并标注"是否为摩尔比/质量比、是否有临床屏障修复终点（TEWL↓）支持"。用户神经酰胺笔记已采用 **3:1:1** 作为黄金比例，沿用但需补权威来源。

## 5. 神经酰胺亚型与组合（桥接原料笔记）
- 神经酰胺由鞘氨醇骨架 + 脂肪酸经酰胺键连接而成；酰基链长度分布影响屏障（来源[2] 细胞间脂质；[8] 百度百科·神经酰胺 2025-03-24，https://baike.baidu.com/item/神经酰胺/10859103）。
- 专利案例：神经酰胺组合物采用 **CerNS:CerNP 质量比 1~10:1** 的配比（来源[5] xjishu 专利）。
- 常见化妆品用神经酰胺：CerNP（神经酰胺 3）、CerAP（神经酰胺 2）、CerEOP（神经酰胺 1）、植物鞘氨醇、胆甾醇（胆固醇）等（来源[6]）。
- 与[[神经酰胺-油溶性-PuriActives]] 桥接：油溶性 PuriActives 通过 NDS 纳米递送提升生物利用度（2.3×），配方上以"仿生比例 + 液晶递送"复刻细胞间脂质。

## 6. 屏障受损与修复动力学（配方启示）
- 屏障功能 = 防止水分流失（TEWL↑ 即受损）+ 阻挡外界刺激 + 维持表面微生态（来源[3] 企鹅号 2026-07-20，https://so.html5.qq.com/page/real/search_news?docid=70000021_5546a5ddbad46652）。
- **修复周期**：过敏性皮炎/屏障受损期以含 Cer:Chol:FFA（3:1:1）保湿霜为最佳，**急性缓解后需持续使用至少 28 天**以巩固屏障（来源[3] 39健康网）。
- 屏障受损诱因：年龄增长、环境、不当护肤（过度清洁/强酸强碱/高浓度刺激性活性物堆叠）（来源[9] 企鹅号·神经酰胺纳米液晶乳 2026-04-27，https://so.html5.qq.com/page/real/search_news?docid=70000021_33369ef574943252）。

|---|---|---|
| 屏障修护配方核心 | Cer + Chol + FFA 三者协同，不能只上神经酰胺 | [2][3][5] |
| 比例 | 化妆品常用 3:1:1（Cer:Chol:FFA），原理论证见 1:1:1 摩尔；以 COA/上市配方为准 | [3][4][6][7] |

| 配伍避坑 | 避免与过强去脂力表活、极端 pH、高浓度 AHA/BHA/VC/视黄醇同期强刺激堆叠（分阶段/分时） | [3] + 酸类/VC/视黄醇笔记 |
