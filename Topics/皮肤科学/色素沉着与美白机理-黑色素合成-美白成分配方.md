# 色素沉着与美白机理 · 黑色素合成 · 美白成分配方

> 学习笔记：把"皮肤为什么会黑/长斑"的生理学机理，映射到配方可操作的美白路径（抑制合成 / 还原已生成 / 阻断转运 / 加速代谢 / 抗炎 PI H）。对接 法规笔记（祛斑美白=特殊化妆品注册）、烟酰胺/VC/酸类笔记，支撑美白产品开发。

## 1. 黑色素合成与转运机理（配方干预的 5 个靶点）
黑色素在**黑素细胞**（位于基底膜带）内合成，经黑素小体转运至周围角质形成细胞（来源[1] 好大夫在线·PIH机制）：

| 步骤 | 生化路径 | 配方干预点 |
|---|---|---|
| ① 启动 | 紫外线/炎症刺激 → 黑素细胞活化（α-MSH/CRH/NO 通路） | 防晒 + 抗炎（甘草/氨甲环酸） |
| ② 合成 | **酪氨酸 →(酪氨酸酶 TYR)→ 多巴 → 多巴醌 → 吲哚醌 → 聚合黑色素** | **抑制 TYR 活性**（377/曲酸/熊果苷/VC/光甘草定） |
| ③ 糖基化/稳定 | TYR 糖基化影响活性 | 抑制 TYR 糖基化（部分植物多酚） |
| ④ 转运 | 黑素小体经树突转移至角质形成细胞（PAR-2 受体介导） | **阻断转运**（烟酰胺抑制黑素小体转移） |
| ⑤ 代谢 | 含黑素角质细胞随角质层脱落 | **加速剥脱**（AHA/BHA 焕肤） |

> 关键酶：**酪氨酸酶（TYR）是黑素合成的决定性限速酶**，美白原料大多以抑制 TYR 为核心（来源[4] 妆合规/瑞旭 2026-06-12）。
> 五条美白技术路线：①抗炎抗氧化 ②下调 TYR 活性 ③抑制 TYR 糖基化 ④促进黑素降解/转运抑制 ⑤加速角质代谢（来源[1]）。

## 2. 炎症后色素沉着（PIH）—— 美白配方的"抗炎"刚需
PIH 是炎症刺激黑素细胞过度合成，是痘印/医美术后色沉的主因（来源[2] 普慈健康）：
- **表皮型 PIH**：炎症产物（前列腺素/白三烯）刺激黑素细胞 → 黑素转移至角质形成细胞 → 表皮色沉。
- **真皮型 PIH**：基底细胞层破坏 → 黑素脱落真皮 → 巨噬细胞吞噬（"色素失禁"）→ 更难消退。
- **自限性**：一般 1 个月可消，慢则 3–6 个月（来源[3] 美咯）。
- **配方启示**：美白/淡印产品必须配抗炎舒缓（甘草提取物/氨甲环酸/神经酰胺/泛醇），仅抑制 TYR 不够；痘印配方＝美白+抗炎+屏障修护三合一。

## 3. 美白成分分类与配方速查（机制 → 用量 → 配伍）
### A. 酪氨酸酶抑制剂（抑制合成）
| 成分 | 机制/强度 | 用量（标"以《规范》为准"） | 配伍/稳定性 | 来源 |
|---|---|---|---|---|
| **377 / 苯乙基间苯二酚** | 强效抑制 TYR，文献称强于曲酸 10–22× | **中国《规范》限用 0.5%**（⚠️ 部分文章称"市售高达 1.8%"与《规范》冲突，以 NMPA 原文为准，标"待核"） | 光稳定性一般；避光、后段加入；配 VE/VC/谷胱甘肽抗氧化协同 | [7][8] 搜狐/今日头条 |
| **熊果苷（α/β-Arbutin）** | 氢醌糖苷前体，缓释抑制 TYR；相对温和 | 《规范》限用（α-熊果苷更稳，常用 1–2%） | 避免长期高温/酸性水解游离氢醌；配抗氧化剂 | [9] 复禾 |
| **曲酸（Kojic Acid）** | 螯合 Cu²⁺抑制 TYR | 限用（历史日本曾禁用后恢复，常用 ≤1–2%，以《规范》为准待核） | 易氧化变色；配 VE/柠檬酸稳定 | [8] |
| **光甘草定（Glabridin）** | 甘草提取物，抑制 TYR + 抗炎 | 植物提取，温和，常用 0.1–0.5%（纯品），提取物更低 | 脂溶，需增溶；配伍广、低刺激 | [6] 企鹅号 |
| **维生素 C / 衍生物** | ①还原已生成黑色素 ②抑制 TYR ③抗氧化 | 原型 5–15%（需低 pH）；衍生物 MAP/SAP/酯化VC 中性友好 | 原型不稳定见 §4；衍生物稳 | [9][4] |

### B. 黑素转运抑制
| 成分 | 机制 | 用量 | 配伍 | 来源 |
|---|---|---|---|---|
| **烟酰胺** | 抑制黑素小体向角质形成细胞转移（PAR-2 途径），同时控油/促屏障 | 2%–5%（3% 起有淡斑感，5% 常用峰值） | 推荐 pH 6.0–7.5；**避免与强酸(pH<3)同罐**会水解成烟酸刺激；不与高浓度酸同用 | [10][12] 知乎/今日头条 |

### C. 抗炎 / PIH 专用
| 成分 | 机制 | 说明 | 来源 |
|---|---|---|---|
| **氨甲环酸（传明酸 Tranexamic Acid）** | 抑制纤溶酶/炎症介导的黑素活化 | 常用于痘印/PIH 配方，温和 | [1][2]（机制综述） |
| **甘草提取物（光甘草定/甘草酸）** | 抗炎 + 抑制 TYR | 与 377/烟酰胺 复配降刺激 | [6] |

### D. 角质代谢加速
- **AHA/BHA**：加速含黑素角质脱落（见酸类笔记）；中国《规范》α-羟基酸 ≤6% / pH≥3.5、水杨酸 ≤2%（来源：法规笔记 08-03）。

## 4. 配伍 / pH / 稳定性（配方师高频坑）
1. **VC 与烟酰胺的 pH 冲突**（来源[10] 知乎）：VC 需酸性 pH<3 才起效（否则只是保湿剂），且光敏感、易变色失活、需避光充氮后段加入；烟酰胺推荐中性 pH 6–7.5，与 VC 直接混合（pH≈3）会部分水解为烟酸致刺激。**方案**：①"日间 VC + 夜间烟酰胺"分时；②分两个剂型；③用 VC 衍生物（MAP/SAP）在中性和烟酰胺同罐。
2. **足量才有效**（来源[11] 知乎）：VC/果酸/烟酰胺均须加足量（概念性添加无效）；非 VC 主打产品多用衍生物，但抗氧化力会打折。
3. **377 光稳定 + 复配**：377 见光易失活，需避光包装 + 配 VE/VC/谷胱甘肽抗氧协同 + 后段/冷却加入。
4. **氢醌（对苯二酚）= 化妆品禁用**（来源[1] 把氢醌列为"美白药物"属药品视角）：中国《禁用原料目录》含氢醌，化妆品禁用；熊果苷是其糖苷前体（相对安全但谨防水解游离）。**配方红线：绝不在化妆品中使用氢醌**。
5. **多种机理复配**是主流高效方案（抑制合成 + 还原 + 阻断转运 + 加速代谢 + 抗炎），比单成分堆叠更稳更有效。

## 5. 法规红线（对接 08-03 法规笔记）
- **祛斑美白 = 特殊化妆品**，须注册取得注册证、须人体功效评价试验（来源：法规笔记 08-03 第9-10条）。
- **限用/禁用**：377《规范》限用 0.5%；氢醌禁用；熊果苷/曲酸限用（具体以《规范》为准待核）；氨甲环酸须在三表内核查（待核是否在已使用目录）。
- **宣称**：普通化妆品不得宣称祛斑美白；须有人体试验报告支撑（来源：法规笔记）。
- **防晒协同**：美白产品必须强调防晒（UV 是黑素主要诱因），AHA≥3% 或宣称 AHA 须标"与防晒同用"。

## 6. 国人肤质适配（差异化配方，来源[6] 企鹅号 2026-07-01）
东亚人群：角质层更薄、黑素体呈混合分布、敏感性发生率更高 → 照搬欧美高浓度方案风险大。
- **低浓度起步 + 舒缓打底**：377 从 0.3% 起、配神经酰胺/泛醇降刺激。
- **抗炎优先**：PIH 高发，配方重抗炎（甘草/氨甲环酸）。
- **严格防晒**：UV 触发强，日防护不可省。
