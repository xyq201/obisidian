# 痤疮与油性皮肤机理 · 毛囊角化 · 皮脂氧化 · 痤疮丙酸杆菌 · 控油/祛痘成分配方

> 学习笔记：把"痤疮为何起"的生理学（毛囊角化+皮脂分泌+菌群+炎症 四因素），映射到配方可操作的控油/抑菌/抗炎/角质代谢/屏障修复体系；对接 07-25 酸类（07-25 AHA/BHA）、07-31 屏障、08-05 敏感（祛痘产品容易破坏屏障）、08-02 功效评价、08-03 法规（**祛痘属第10条须人体功效试验**）。

## 1. 痤疮发病四因素（业内公认）
| 因素 | 机理 | 配方干预靶点 |
|---|---|---|
| **皮脂分泌过多** | 雄激素→5α-还原酶→DHT↑ →皮脂腺活跃；T区与下颌最重（来源[1][2]） | 抑5α-还原酶 / 抑皮脂腺 / 收敛吸油 |
| **毛囊角化异常** | 毛囊导管角质细胞过度增生/脱落不全→角栓堵塞→白头/黑头粉刺（来源[2][3]） | 溶解角质 / 促角质代谢 |
| **痤疮丙酸杆菌（C. acnes）增殖** | 厌氧菌利用皮脂甘油三酯→游离脂肪酸（FFA）→刺激炎症+粉刺破裂（来源[2][3]） | 抑菌（BPO/壬二酸/皮傲宁/季铵盐-73） |
| **炎症反应（贯穿全程）** | 菌+FFA+IL-6/TNF-α→红/肿/痛/化脓；后期可致PIH（接 08-04） | 抗炎舒缓（甘草酸二钾/红没药醇/PCA锌） |

> **配方启示**：痤疮是"四因素连环扣"，单靶点无效；须"控油 + 疏通角质 + 抑菌 + 抗炎 + 屏障保护"五位一体。

## 2. 油性皮肤与激素
- **DHT（双氢睾酮）↑**：经5α-还原酶催化睾酮而来，是皮脂腺主刺激物
- **食物因素**：高糖/高GI/奶制品（尤其脱脂奶）→ 刺激 IGF-1 通路→ 加重痤疮（来源[1]）
- **配方启示**：控油成分需抑制 5α-还原酶（PCA锌/壬二酸/烟酰胺/SU 衍生物）

## 3. 控油/祛痘成分速查表（机制 → 用量 → 配伍）

### A. 溶解角质/疏通毛孔类（治"毛囊角化"）

## 4. 经典祛痘组合（处方/护肤级）
- **中轻度粉刺**：水杨酸 0.5–2% + 烟酰胺 2–5% + PCA锌 0.5–1% + 泛醇 2–5%（驻留）｜pH 3.5–4.5
- **炎症性红肿痘**：壬二酸 10–20% + 红没药醇 0.3% + 甘草酸二钾 1% + 烟酰胺 2–5%｜pH 4.5–5.5
- **重度囊肿/聚合**：BPO 2.5–5% + 壬二酸 10% + 红没药醇/PCA锌（须医师指导）；护肤不可替代处方
- **油皮日常**：氨基酸/APG 洁面 + PCA锌收敛水 + 烟酰胺 2% 控油乳 + 防晒
- **敏感油痘**：氨基酸洁面 + 壬二酰二甘氨酸钾 2–5% + 神经酰胺乳 + 物理防晒（07-31+08-05）

## 5. 配方设计要点（祛痘产品）
1. **pH 平衡**：水杨酸/果酸 pH 3.5–4.5（07-25 规范 ≥3.5）；壬二酸 4.5–5.5；烟酰胺 pH 6.0–7.5（07-23）；**敏感油痘 pH 上调到 5.0–6.0**。
2. **BPO 与强活性成分分时**：BPO 早晨 + 视黄醇/烟酰胺/水杨酸 晚间（避免氧化应激叠加）。
3. **稳定性与包装**：
   - 水杨酸需稳定 pH（缓冲体系 + 适当醇类溶解）；
   - 壬二酸难溶需微晶/脂质体工艺；
   - 抗氧剂易氧化（充氮/避光/不透明包装，对接 08-06）。
4. **防腐体系**：高活性酸+BPO 体系下微生物不易滋生，但仍需温和防腐（多元醇+对羟基苯乙酮/辛酰甘氨酸防腐增效）。
5. **屏障保护**：酸/BPO 必配神经酰胺+泛醇；"刷酸后 24h 屏障脆弱期"避免强清洁。
6. **禁忌与雷区**：
   - 高浓度酸+BPO+VA 同时叠加 → 屏障崩溃
   - 皂基+磨砂+高 pH → 皮脂腺负反馈→更油
   - 痤疮脓疱破损期禁用 BPO/酸 → 改用抗生素/医用敷料（医疗）
7. **敏感肌 + 油痘 配方**：壬二酰二甘氨酸钾 + 烟酰胺（低浓度 1–2%） + 神经酰胺 + 红没药醇 + 物理防晒；避开原型 VC/VA/BPO/高浓度酸。

## 6. 控油/祛痘功效评价（对接 08-02）
- **皮脂分泌**：Sebumeter（5min/30min/60min 测量）；Casio 油脂测试片
- **毛孔**：Visioscan/VISIA；图像分析（毛孔数量/面积）
- **痤疮分级**：Pillsbury 分级（I–IV）+ 反常性痤疮/CASS 分级；炎性/非炎性计数
- **PIH（对接 08-04）**：VISIA 紫外；Mexameter
- **菌群**：PCR/培养（医疗评估）
- **人体试验**：28天/56天 D0/D14/D28/D56；皮脂+痤疮计数+PIH 同步；**法规要求祛痘须人体（第10条）**

## 7. 法规红线（对接 08-03 第 10 条）
- **祛痘（宣称"抗痘/祛痘/去粉刺"）→ 须人体功效评价试验**，并出具检验报告。
- **水杨酸**（07-25）：驻留类 ≤2%；含水杨酸产品须标警示语。
- **AHA/果酸**（07-25）：驻留 ≤6%，pH≥3.5；≥3% AHA 或宣称时须标"与防晒同时使用"。
- **壬二酸**：化妆品中作为祛痘活性物添加限值/列名待核（欧盟 CosIng 待核）；高浓度属药品（医疗指导）。
- **BPO**：化妆品中浓度限值待核（《规范》+《已使用目录》）；高浓度属 OTC/处方。
- **烟酰胺**：07-23 已入《已使用目录》；无特殊限值。
- **儿童/孕妇**：BPO/水杨酸/壬二酸/视黄醇均需特殊警示。
- **宣称避雷**（08-03）：禁"医学/治疗/处方"等医疗词；"祛痘"可，"治愈痤疮"等被禁。
