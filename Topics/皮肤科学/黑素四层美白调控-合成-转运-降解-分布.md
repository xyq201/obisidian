# 黑素四层美白调控 · 合成 / 转运 / 降解 / 分布 · 配方设计

> 学习卡片：美白不是"杀死黑色素细胞"，而是精确调控黑素小体从黑素细胞向角质形成细胞的**转运**全过程。阻断转运比抑制酪氨酸酶更精准安全。对接 色素沉着与美白机理、美白淡斑精华实战。

## 1. 黑素生成与转运路径
黑素细胞（基底层）→ 树突将成熟黑素小体传给 ~36 个角质形成细胞：
1. **合成**：酪氨酸 →(TYR/TYRP1/TYRP2)→ 黑色素
2. **成熟**：阶段 I→IV（PMEL17 蛋白水解）
3. **树突转运**：Rab27a / Melanophilin / Myosin Va 三元复合物沿微管运输
4. **细胞间传递**：旁分泌"注射"入角质形成细胞 → 形成"黑素帽"护核 DNA

## 2. 美白四层靶点
| 层次 | 靶点 | 代表成分 | 优势/局限 |
|---|---|---|---|
| **① 合成抑制** | 酪氨酸酶(TYR) | 氢醌 / 曲酸 / 熊果苷 / VC 衍生物 | 抑制率有限，刺激性风险（氢醌慎用） |
| **② 转运阻断** | Rab27a / Melanophilin | 烟酰胺、大豆提取物 | 精准阻断，安全性高（烟酰胺不抑 TYR，阻转移） |
| **③ 降解加速** | 自噬诱导 | 低浓度视黄醇 / 某些肽类 | 促黑素小体降解 |
| **④ 分布调控** | PAR-2 拮抗 | 大豆胰蛋白酶抑制剂 | 阻止角质细胞摄取 |

> **烟酰胺**是转运阻断层经典代表：2–5% 即显著改善肤色不均，耐受性远优于氢醌；不抑制酪氨酸酶，而是阻断黑素小体向角质形成细胞转移。

## 3. 四层协同美白
合成抑制(VC 衍生物) + 转运阻断(烟酰胺) + 降解加速(低浓度视黄醇) + 分布调控(大豆提取物)。
- **避免过度美白**：完全阻断黑素合成会削弱皮肤对 UV 的内源防护，应保留基础黑素生成。
- **防晒是美白先决**：UV 激活 MITF → 全面上调黑素合成；不防晒的美白是"边加水边放水"（PIH 同理：紫外线把色素"焊死"，防晒 > 美白）。

## 4. PIH / 痘印关联（文档2）
- 红印（血管扩张，可压白）vs 黑印 PIH（压仍褐，3-6 月+）。
- 居家 SOP：止损(不抠+控痘+神经酰胺) → 严格防晒(硬防晒优先) → 温和美白(红印退后加 VC/烟酰胺/壬二酸，一次一种)。
- 核心：防晒是分水岭；给皮肤时间（月为单位）。

## 5. 宣称合规
- 不写"美白" → "改善肤色均匀度" / "减少色素沉着"
- 不写"阻断黑色素" → "减少色素沉着"
- 氢醌等属特殊/限用，须核对《已使用目录》与法规限值
