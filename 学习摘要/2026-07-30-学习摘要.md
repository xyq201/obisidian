# 每日学习摘要 · 2026-07-30

## 今日主题
**递送系统专题 —— 脂质体 / 纳米乳 / 纳米液晶 / 微囊**。把"活性物送达角质层/真皮并保持稳定"这件事的工程化方案梳一遍，并直接桥接到你关注的神经酰胺 NDS、蓝铜肽保活、视黄醇降刺激、原型 VC 稳态化、玻色因防结晶等具体痛点。

## 关键知识点（结论 + 配方启示 + 来源）
1. **脂质体经典膜材**：大豆/蛋黄卵磷脂 + 胆固醇，**磷脂:胆固醇 ≈ 3:1**（如 0.9 g + 0.3 g）溶于无水乙醇，65–70℃水浴旋转成膜（来源[10]）。
2. **脂质体制备工艺四件套**：① 薄膜分散法（操作简便、包封率偏低）；② 乙醇注入法（55–65℃ 滴入水相、蒸乙醇、搅拌 1–2h，小试首选）；③ 逆相蒸发法（包封率高）；④ 高压均质+挤出/超声（工业化大生产）。**乙醇残留对膜形成/稳定性/包封率均有重大影响**（来源[6][7][9]）。
3. **纳米乳 10–100 nm**：**热力学不稳定但动力学稳定**，需乳化剂维持；四类 O/W / W/O / O/W/O / W/O/W。**核心工艺 = 高压均质（500–5000 psi）/ 高压微射流**，温度 60–80℃、乳化剂 1–2%（如 TWEEN80+SPAN80）（来源[11][13][15]）。
4. **W/O 纳米乳特别适合包裹水溶性活性物**（HA、神经酰胺溶液），形成真皮层"储库"；多层乳剂 W/O→O/W 双重包裹亲水+亲油（来源[2][3]）。
5. **纳米液晶（NDS / 层状液晶）**：聚甘油-10 二硬脂酸酯构建层状液晶网络；**神经酰胺纳米液晶乳案例：生物利用度提升至传统乳剂 2.3×，TEWL 28 天 ↓47%**（来源[1]）。
6. **壳聚糖包覆可显著提升脂质体稳定性**：桂花苯乙醇苷案例包埋率 35%–88%、粒径 74–116 nm、60 天保留率 39.84%（来源[8]）。
7. **痛点-载体对应速查**：蓝铜肽→脂质体+充氮+双剂分装；视黄醇→微囊/环糊精；原型 VC→W/O 纳米乳+VE+阿魏酸；神经酰胺→纳米液晶乳 NDS；玻色因→凝胶骨架锁相（与既有笔记桥接）。
