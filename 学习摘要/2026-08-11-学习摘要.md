## 关键知识点（结论 + 配方启示 + 来源）
1. **敏感肌 4 类分别配方**（08-05）：①基因敏感（多通路 SymSitive+泛醇+红没药醇）/ ②屏障受损（神经酰胺 3:1:1+角鲨烷+泛醇）/ ③玫瑰痤疮（SymSitive 0.1%+七叶树皂苷+假叶树根+物理防晒理念，**避 A 醇/酸/BPO/EDTA**）/ ④痤疮后敏感（壬二酰二甘氨酸钾+神经酰胺+角鲨烷）。**4 类同一套配方不可通用**。
2. **黄金比例 Cer:Chol:FFA = 3:1:1**（07-31 + 来源[1][2]）：多源印证"神经酰胺+角鲨烷+积雪草苷+泛醇"为经典敏感肌骨架；来源[8]专利配方神经酰胺复合物 10%；来源[9]专利工艺神经酰胺 2/3 添加量最高 8%（油溶载体=角鲨烷+硅油+乳木果油，80℃ 加热乳化）。**配方启示**：3:1:1 折算到常规修护霜中**神经酰胺总量 5–8%**（含水分散 4.5%+油溶 1.5%+二裂酵母+乳木果油）。
3. **"褪红公式" 神经酰胺 NP × 积雪草 × 六肽-9**（来源[6]抖音·2025-04-10）：**褪红急救+屏障修护+维稳** 三合一；5 分钟降温退红（SymSitive 快速）+ 重构微生态防御网（神经酰胺 + 二裂酵母）。**配方启示**：神经酰胺 NP + 积雪草 + 六肽-9 三者协同可作为褪红舒缓霜精简骨架。
4. **三大经典敏感肌体系**（来源[5]博客园·2026-02-04）：①薇诺娜（马齿苋+青刺果油，表皮+物理舒缓）；②玉泽（单一脂质补充，单一表皮修护）；③屏障强化（龙爪粟发酵物 BIO-Revive + 小分子 III 型胶原，填补肌底空洞）。**配方启示**：3 套配方思路可作"敏感肌修护谱系"参考；本笔记 A/B/C 三方分别对接三类敏感肌（屏障/极简/玫瑰）。
5. **3 套成品配方速览**：
   - **A 神经酰胺屏障修护霜 pH 5.0–5.5**（高神经酰胺 8% + 黄金比例 3:1:1）：Cer NP 3.0% + Cer AP 1.0% + Cer EOP 0.5%（水分散） + Cer 2 1.5%（油溶）+ 胆固醇 1.5% + 游离脂肪酸 1.5% + 角鲨烷 8.0% + 乳木果油 3.0% + 二裂酵母 2.0% + VE 0.5% + 泛醇 5.0% + 透明质酸 0.3% + 水解透明质酸 0.3% + 积雪草苷 0.5% + 红没药醇 0.3% + 甘草酸二钾 0.3% + SymSitive 0.05% + 螯合植酸钠避 EDTA + 多元醇防腐；
   - **B 极简敏感肌乳 pH 5.0–5.5**（配方精简 ≤14 种，无香精无色素无酒精）：Cer NP 1.0% + 角鲨烷 4.0% + 二裂酵母 1.0% + 泛醇 5.0% + 透明质酸 0.3% + 积雪草提取物 1.0% + 红没药醇 0.3% + 糖脂乳化剂 + 多元醇防腐；
   - **C 玫瑰痤疮舒缓乳 pH 5.0–5.5**（SymSitive 0.1% 强化 + 七叶树皂苷 + 假叶树根 + 物理防晒理念）：Cer NP 2.0% + Cer AP 0.5% + 角鲨烷 5.0% + 乳木果油 2.0% + 泛醇 5.0% + 积雪草苷 0.5% + 红没药醇 0.5% + 甘草酸二钾 0.5% + SymSitive 0.1% + 七叶树皂苷 0.3% + 假叶树根 0.3% + 螯合植酸钠避 EDTA + 多元醇防腐。
6. **⚠️ 敏感肌专属工艺避坑清单**（08-05 + 08-07 + 08-10 + 来源[2][5]）：
   - **禁用 A 醇/视黄醇**——TRPV1 激活刺痛+泛红 → 神经酰胺+SymSitive 替代；
   - **禁用 AHA/BHA/壬二酸**（屏障受损时）——暂缓使用，屏障修复后低浓度起步；
   - **禁用 BPO/过氧化苯甲酰**——强氧化剂+TRPV1 激活 → 物理方式/壬二酸替代；
   - **禁用 EDTA**（08-07 壬二酸+EDTA 禁忌）——改植酸钠；
   - **禁用 MIT/CMIT/尼泊金酯/甲醛释放体**——防腐剂过敏率高 → 多元醇路线（1,2-己二醇 1%+对羟基苯乙酮 0.5%）；
   - **禁用 香精/色素/酒精**——刺痛+敏感 → 完全去除（来源[2]无防腐剂原则）；
   - **慎用 化学防晒**（苯酮类/奥克立林）——部分敏感肌/玫瑰痤疮过敏 → **物理防晒（二氧化钛+氧化锌）**（来源[5]）；
   - **避用 SLS/SLES 洁面**——强清洁破坏屏障 → 糖脂/氨基酸类洁面。
7. **油脂优选**（来源[9]专利工艺）：神经酰胺油溶载体 = **角鲨烷 + 硅油 + 乳木果油**；**油脂 80℃ + 水相 75℃ 加热→80℃ 高温乳化**→ 5000rpm 5 min 高速剪切 → 降温 50℃ 加增稠剂 → 40℃ 加舒缓剂 → 35℃ 加防腐 → NaOH 调 pH 5.0–5.5 → **真空灌装**。
8. **10 条工艺铁律**：
   - **温度**：油相 80℃ 溶解神经酰胺→80℃ 高温乳化；水相 75℃；50℃ 增稠；40℃ 舒缓剂；35℃ 防腐
   - **pH**：5.0–5.5（贴近皮脂膜 4.5–6.5；08-05）；NaOH/三乙醇胺调 pH
   - **加料顺序**：A 75℃→B 80℃ 乳化→50℃ 增稠→40℃ 舒缓（SymSitive+积雪草+红没药醇+甘草酸二钾）→35℃ 防腐→NaOH 调 pH→真空
   - **螯合剂**：植酸钠 0.05–0.1%（避 EDTA；08-07）
   - **预溶**：神经酰胺 2/3 预溶 80℃ 角鲨烷+硅油+乳木果油（来源[9]）；SymSitive 预溶丁二醇/乙醇；积雪草苷/红没药醇 预溶丁二醇
   - **过滤**：O/W 乳霜可不终端过滤
   - **防腐**：1,2-己二醇 1%+对羟基苯乙酮 0.5%；**避 MIT/CMIT/尼泊金酯/甲醛释放体**（08-05）
   - **包材**：真空泵/软管/不透明管；避空气氧化
   - **配方精简**：B 极简乳 ≤14 种全成分（A 修护霜 ≤20 种，C 玫瑰 ≤20 种）；**LLS 原则（Less is More）**（来源[2]）
   - **生产环境**：GMP 10万级；金属离子控制
9. **稳定性和功效**：
   - **稳定性**：40℃/75%RH 4 周 + 冻融 -10~25℃ 3 循环 + 光照 4500 lux 28 天 + 离心 3000rpm 30 min + 防腐挑战；监测外观/pH/黏度（O/W 乳霜 Brookfield RV 50000-100000 cP）/神经酰胺 HPLC/防腐挑战
   - **功效评价**（08-02 + 08-05）：人体 ≥30 人/半脸 28–56 天 D0/D14/D28/D56；**TEWL 经皮水分丢失**（屏障功能核心，下降 30%+）+ **Corneometer CM825 含水量**（上升 30%+）+ **Cutometer 弹性** + **Mexameter MX18 红斑 EI**（玫瑰痤疮核心，下降 20%+）+ **VISIA 红色区** + **Lactic Acid Sting Test（LAST）乳酸刺痛试验**（敏感肌分型）+ 受试者自评；双臂对照防晒配套；体外 **TRPV1 拮抗**（SymSitive 抑活）+ 3D 皮肤 TEWL 模型
   - **法规**：**舒缓属第9条须人体功效**（非第10条特殊化妆品，08-03 第9条）；"舒缓/修护/保湿"普通品可用；禁"医学/治疗/治愈"医疗词
10. **配方决策树**：
    - 屏障受损/干敏肌 → **A 修护霜 pH 5.0–5.5**（高神经酰胺 8%+3:1:1+SymSitive 0.05%）
    - 基因敏感/换季/孕哺/极简 → **B 极简乳 pH 5.0–5.5**（≤14 种全成分+LLS 原则）
    - 玫瑰痤疮/高度敏感 → **C 玫瑰舒缓乳 pH 5.0–5.5**（SymSitive 0.1%+七叶树皂苷+假叶树根+物理防晒理念+避 A 醇/酸/BPO）
    - 油敏痘肌 → 08-10 修护乳 + 本方 A 修护霜 叠加（局部点涂）
    - 敏感肌美白 → 08-09 敏感肌美白精华（VC乙基醚+低377+谷胱甘肽+舒缓）+ 本方 B 极简乳
    - 儿童/婴儿肌 → B 极简乳（无烟酰胺/无SymSitive/无视黄醇，配方最精简 ≤12 种）
