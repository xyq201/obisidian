# 每日学习摘要 · 2026-07-31

## 今日主题
**皮肤屏障生理学 —— 角质层砖墙模型与细胞间脂质**。补齐"配方骨架之外最底层的科学地基"：角质层如何构成屏障、细胞间脂质到底是什么比例、屏障修复为什么强调 Cer+Chol+FFA 协同。直接桥接神经酰胺/屏障修复、层状液晶递送、乳化体系与功效评价。

## 关键知识点（结论 + 配方启示 + 来源）
1. **砖墙模型（Elias/UCSF）**：角质细胞=砖，细胞间脂质=灰浆；板层小体释放转化为 Cer+FFA+Chol；皮脂膜=最外层石膏（来源[4] 知乎 2021-06-28）。**配方启示**：屏障是"结构+脂质"共同决定，单点补神经酰胺不够。
2. **角质层"三明治"层状液晶（约13nm）**：中间液相由不饱和脂肪酸+胆固醇构成。**配方启示**：仿生层状液晶（聚甘油-10 二硬脂酸酯等）能与角质层相容、提升活性物透皮（桥接递送系统笔记）。
3. **细胞间脂质组成（质量比）**：神经酰胺 40–50%、脂肪酸 20–30%、胆固醇 20–30%；神经酰胺含量最高、对屏障最关键（来源[2][5]）。**配方启示**：原料选型以神经酰胺主导。
4. **屏障修复比例冲突需核实**：生理学等摩尔 **1:1:1（mol，Elias）** vs 化妆品宣称 **3:1:1（Cer:Chol:FFA）**；上市产品（NARUD 精华霜）实测 3:1:1（来源[3][4][6][7][10]）。**配方启示**：沿用用户神经酰胺笔记 3:1:1，但需补权威来源/标注摩尔vs质量比。
5. **神经酰胺亚型组合**：CerNP/AP/EOP + 植物鞘氨醇 + 胆固醇；专利 CerNS:CerNP 质量比 1~10:1（来源[5]）。**配方启示**：多亚型复配比单一更有效。
6. **修复周期 ≥28 天**：屏障受损需持续使用含 Cer:Chol:FFA 保湿霜至少 28 天巩固（来源[10]）。**配方启示**：功效评价以 28 天人体为最低观察窗。
