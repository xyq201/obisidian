# 每日学习摘要 · 2026-07-28

## 今日主题
**肽类（胜肽 / Peptides）配方档案** —— 抗衰"信号类"活性物核心族群（信号肽 / 神经递质抑制肽 / 载体肽）；配方核心难点在"娇贵"：酶解/热/金属离子/极端 pH/氧化易失活（蓝铜肽最敏感）。

## 关键知识点（结论 + 配方启示 + 来源）
1. **三大类选法**：①信号肽（棕榈酰五肽-4/Matrixyl/KTTKS）促 ECM 胶原；②神经递质抑制肽（乙酰基六肽-8/Argireline）放松表情肌平动态纹；③载体肽（三肽-1铜/GHK-Cu 蓝铜肽）修护（来源[3][6][11] 搜狗百科/百度百科/今日头条）。
2. **信号肽 KTTKS**：棕榈酸化增强透皮，作用于成纤维细胞促 I/III/IV 胶原与透明质酸；NMPA《已使用目录(2021)》记为棕榈酰五肽-4（来源[1] 济南多聚元；[2] 搜狐 2025-02-19；[4] 百度百科·棕榈酰五肽 2022-03-18）。配方启示：稳定度较好，常规后段加入即可。
3. **Argireline 类肉毒**：结构类似 SNAP-25 竞争 SNARE 位点、抑制乙酰胆碱释放→平表情纹；INCI Acetyl Hexapeptide-8（CAS 616204-22-9），常 98%–99% 粉或 450–550 ppm 液（来源[6][7][8][9][10] 百度百科/zhaoyl/合肥国肽）。配方启示：针对"表情纹"，与信号肽互补（动态纹+静态纹双通道）。
4. **蓝铜肽 GHK-Cu 最娇贵（核心痛点）**：INCI 三肽-1铜，须与"多肽铜盐酸盐"类含铜物区分；易失活——**禁配原型 VC、AHA/BHA、EDTA/螯合剂、多价金属、强碱**；建议双剂分装（三肽-1 + 葡糖酸铜现混）保活（来源[11] 今日头条 2021-11-01）。研究提示低浓度效率可能更高。
5. **通用工艺**：所有肽类建议**后段/降温加入**、避高温均质、避光充氮延稳定期；蓝铜肽须弱酸-中性（pH≈5.5–7）缓冲体系（来源[11] + 蛋白类活性通性）。
6. **合规**：三者均收录于 NMPA《已使用化妆品原料目录（2021 版）》（棕榈酰五肽-4 明确在册[4]）；其余二者为通用已使用原料（待补目录页直连核验）；**EU CosIng 条目本次未直连，标"待核实"**。

## 与用户需求的关联
- 补全抗衰活性矩阵：神经酰胺(屏障)+烟酰胺+视黄醇+VC+酸类+泛醇 之后，补齐**信号类抗衰（肽）**；与视黄醇"抗老双通道"（刺激胶原），与酸类/VC 形成配伍边界（蓝铜肽禁配）。
- 直击用户"稳定性/结晶难题"：肽类的酶解/热/金属失活是典型稳定性痛点，给出后段加入、双剂分装、缓冲 pH 的可执行 SOP。
- 桥接递送（与神经酰胺 NDS 呼应）：蓝铜肽可用脂质体/环糊精包裹降失活。
